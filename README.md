# Hive

[![OpenSSF Best Practices](https://www.bestpractices.dev/projects/14261/badge)](https://www.bestpractices.dev/projects/14261)
[![License](https://img.shields.io/badge/license-Apache--2.0-blue.svg)](LICENSE)

You know the one. Reads every pull request. Never lets red merge. Sends it back with one line, and the line is right. Hive puts that person between your coding agents and main.

If you run CI you know the shape. The job is an AI coding agent. The gate is an AI review plus your own CI.

## Security

We planted 63 texts that try to redirect an agent in issues and files. Hive caught 61 before an agent read a word. One harmless text in 12 got flagged by mistake. Agents run as a GitHub App, not on your token.

## Cost

Agents spent about $6,125 to merge 2,869 pull requests. Call it $2 a merge, our estimate (aug–oct '26).

## And the rest

Every pull request gets the same one-line review, in your style guide's voice. It adds about 15 minutes to a merge.

<picture><source media="(prefers-color-scheme: dark)" srcset="src/docs/benchmarks/assets/outcomes-2026-10-card-also-dark.png"><img alt="Also consistent, readable, efficient and fast." width="880" src="src/docs/benchmarks/assets/outcomes-2026-10-card-also-light.png"></picture>

Humans still merge. Start with "open PRs only". When you trust it, [turn it up](src/docs/acmm-policy-matrix.md) and it merges on green, like a merge queue that reads the code.

Reverts are too new to report. [How we count →](src/docs/benchmarks/outcomes-2026-10.md)

## Run it

```bash
git clone https://github.com/hivecommons/hive.git && cd hive
cp src/hive.yaml.example src/hive.yaml   # set project.org, project.repos and dashboard.port 3002
printf 'HIVE_GITHUB_TOKEN=ghp_...\nHIVE_DASHBOARD_TOKEN=%s\n' "$(openssl rand -hex 32)" > src/.env && chmod 600 src/.env
docker compose -f src/docker-compose.yaml up -d
```

The [quick start](src/docs/quickstart-docker-compose.md) explains each line. [Podman and Kubernetes](src/docs/what-is-hive.md#run-it) too.
