# Hive Code of Conduct

Hive follows the [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).

As contributors, maintainers, and participants, we pledge to make participation in this project open, welcoming, inclusive, and harassment-free for everyone. Examples of positive behavior include empathy, respectful disagreement, constructive feedback, accountability, and focusing on what is best for the community.

Unacceptable behavior includes harassment, discriminatory language, personal attacks, publishing private information without permission, threats or violence, sustained disruption, or other conduct that would be inappropriate in a professional open source community.

## Scope

This code applies in Hive project spaces, including GitHub issues, pull requests, discussions, meetings, events, and project-operated communication channels. It also applies when an individual's words or actions are directed at Hive, CNCF, or another community participant.

## Reporting

- **Project contact:** [conduct@hivecommons.dev](mailto:conduct@hivecommons.dev).
- If your report concerns a project Maintainer, or you are not comfortable reporting to the project, contact the CNCF Code of Conduct Committee directly at [conduct@cncf.io](mailto:conduct@cncf.io), per the [CNCF CoC incident resolution procedures](https://github.com/cncf/foundation/blob/main/code-of-conduct/coc-incident-resolution-procedures.md).

Reports are handled confidentially by the Maintainers, excluding anyone who is a subject of the report.

## Enforcement

Maintainers may remove, edit, or reject comments, commits, issues, pull requests, and other contributions that do not align with this Code of Conduct. Enforcement decisions concerning a Maintainer require a 2/3 supermajority of the other Maintainers, per the [Hive Commons Code of Conduct](https://github.com/hivecommons/.github/blob/main/CODE_OF_CONDUCT.md). Escalation follows the CNCF Code of Conduct.
