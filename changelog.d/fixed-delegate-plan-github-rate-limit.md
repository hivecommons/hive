- "Let hive decide" now says why a preview failed instead of "hive unavailable". While the hive's GitHub App was out of quota, every preview failed with "Could not preview owner/repo#N (hive unavailable)": the server answered 502, and the hosted Ingress replaces every 502 with its own "hive is restarting" body. The preview now answers 429 with a `Retry-After` header and reads "GitHub API rate limit for this hive is exhausted; resets at 17:32Z" (or the secondary limit's retry time); other GitHub refusals (a 404, a permission 403), a closed item or a missing dashboard snapshot answer 424 with the real message. 502 is left for a GitHub that could not be reached at all.
