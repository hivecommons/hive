- The spoke dashboard (`/api/status`, SSE, and the agent card) now escalates a crash-looping agent to `structuredStatus: BLOCKED` with the rolling-24h restart count and the last crash reason, instead of reporting the same `state=running / busy=working` as an agent doing real work. A live spoke hid a total seven-agent outage (restart_count 918, empty panes, zero transcripts) behind an all-green dashboard for hours; the escalation trips at the same threshold the hub's fleet verdict already uses (`HIVE_HUB_AGENT_RESTART_PROBLEM_THRESHOLD`, default 5), so the local card and the fleet view can no longer disagree about the same agent ([#6237](https://github.com/hivecommons/hive/issues/6237)).
