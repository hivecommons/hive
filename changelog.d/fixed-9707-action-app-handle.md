- The `hivecommons/hive/.github/actions/hive` comment relay (and the `hive-action-smoke` workflow) now @-mentions the hive's actual GitHub App handle instead of a hard-coded `@hive`, so relayed commands are recognised when the App is named something else (for example `@hivecommons-hive`). Set it with the new `app_handle` input or the `HIVE_APP_HANDLE` repository/organization variable; the default stays `hive`, and `@` and `[bot]` spellings are accepted (#9707)
