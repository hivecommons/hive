- The gh wrapper's identity-footer injection now understands every spelling of a body that `gh` accepts — `--body`/`-b` and `--body-file`/`-F`, separated, attached or `=`-joined, including `-F -` for stdin ([#7937](https://github.com/hivecommons/hive/issues/7937)). It previously recognised only `--body` and `--body=`, and added a second `--body <footer>` when it saw neither: `gh pr comment -F notes.md` was refused outright by `gh` ("specify only one of --body or --body-file") so the comment was never posted, and `gh pr comment -b 'text'` posted the footer *alone* because `gh` keeps the last of two `--body` flags — silently dropping the agent's text. A file or stdin body is now read by the wrapper and re-emitted as a single `--body` carrying the caller's text plus the footer.
