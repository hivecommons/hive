- The contributor relay's PR review cycle no longer stalls waiting for a human to approve extra commands: its prompt no longer restricts the agent to the PR-listing commands, names the `gh` reads it needs to check review comments, reviews, checks and an UNKNOWN merge state, and tells the agent never to ask for permission. If a command is unavailable, the agent skips that check and names it in the `HIVE_VERDICT` ([#13787](https://github.com/hivecommons/hive/issues/13787)).
