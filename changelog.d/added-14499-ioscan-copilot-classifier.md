- The ioscan semantic classifier can now run through Copilot CLI tool-less (`ioscan.classifier.backend: copilot`), alongside `claude`: copilot is launched with `--available-tools` set to a sentinel that names no tool, `--disable-builtin-mcps`, `--no-custom-instructions` and `--no-ask-user`, in an empty working directory with no hive token in its environment, and the prompt is passed as the `-p` value since copilot does not read stdin. When `classifier.backend` is empty and no model endpoint is configured, boot now falls back to the tool-less CLI the hive's own agents run on, so a Copilot-only hive at ACMM L5–L6 gets a classifier without extra configuration instead of silently withholding every kick that carries untrusted text. When the classifier is required at the current level but still cannot run, the dashboard shows a persistent `ioscan-classifier-blocked` alert saying kicks are being blocked and how to fix it (set an endpoint, set `ioscan.classifier.backend`, or `ioscan.classifier.fail_mode: open`); the fail-closed default is unchanged. `codex` and `gemini` remain refused (hivecommons/hive#14499).
