- `has-open-pr` now comes off an issue once no open PR links it. The pre-dispatch open-PR guard added the label when it refused a dispatch, but nothing ever removed it, so after the linking PR merged or closed the issue kept saying "An open PR already links this issue" beside `stage/010` or `stage/045`. The issue stage-label sweep now asks the guard's own open-PR listing for every open issue wearing the label and removes it in the same write as the stage, without a comment, only when the listing succeeds and shows no linking PR. A failed listing keeps it, `scanner.skip_issues_with_open_pr: false` leaves it alone, and if another writer puts it back while still no PR links the issue, the hive leaves it there.
