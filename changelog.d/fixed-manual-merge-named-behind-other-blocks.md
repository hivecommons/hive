- A contributor PR that edits workflow / action files (or removes tests) and is also parked for a sentinel alert, a hold label or a `requires_human` verdict now gets a `stage/085-needs-decision` comment that says from the start that a maintainer must merge it by hand, and why. The lane stops at the first thing that blocks a PR and reaches those blocks before its diff fence, so the comment used to ask a trusted merger to approve the head "and the hive re-evaluates". No approval can merge such a PR, and the manual-merge rule only appeared once the first block was cleared. Human routing now reads the head's diff fence itself (once per head) and names it alongside the other blocks. A clean diff, or one that cannot be read, leaves the comment unchanged.
