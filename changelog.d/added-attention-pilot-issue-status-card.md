- `github.notifications.attention_pilot` (default off) opts a hive in to the attention pilot ([#16358](https://github.com/hivecommons/hive/issues/16358), part of [#16270](https://github.com/hivecommons/hive/issues/16270)): routine issue notes — partial work, close/auto-close narration (merged fix, decomposed parent), reopened-after-merge, stage regressions, the covering-PR note and the blocker-settled note — fold into the issue's single `hive:status` card through the shared status writer, and a newly required action (confirming a merged fix) is still announced by exactly one notifying write. With the flag off nothing changes.
