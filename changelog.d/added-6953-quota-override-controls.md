- Contributor quota guard: add scoped override controls and a cross-process quota-pool store (kubestellar/hive#6953). `ask` mode now presents four scoped controls when it holds — continue-once, continue-until-reset, disable-session, and pause-until-reset — reachable on a detached relay through the new `just contribute-quota …` command path, and each expires mechanically (one assignment, the window's reset epoch, or session exit) so no override silently becomes a standing authorization to spend. An optional pool store, enabled with `HIVE_CONTRIBUTOR_QUOTA_POOL_DIR`, keys guard state to the local quota pool via atomically-written files so two relays sharing one provider account reserve against each other instead of independently oversubscribing the configured reserve; the pool key is a hash that exposes no raw account identifier. Overrides never bypass an unknown/unreadable reading and never enable paid credits.
