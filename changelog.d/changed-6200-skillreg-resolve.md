- Removed the unused skill-version constraint lookup from `pkg/skillreg`: `Registry.Resolve(name, constraint)` and its private helpers `satisfies` and `sameMajor` (the `^X.Y.Z` / `>=X.Y.Z` / exact grammar) had no production caller on v5; `ResolveRequested` resolves through `Get` (highest version) and never honoured a constraint, so the grammar advertised version-pinning semantics the system did not implement ([#6200](https://github.com/hivecommons/hive/issues/6200)). The live surface (`NewRegistry`, `Add`, `Load`, `Get`, `List`, `Search`, `LoadAgentSpec`, `ResolveRequested`, `InjectionText`) is unchanged; `docs/skills.md` drops the `Resolve` row and `docs/design/knowledge-system.md` no longer lists the `curator.go` pipeline removed in #5786 ([#6225](https://github.com/hivecommons/hive/issues/6225)).
