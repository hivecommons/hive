- New `pkg/search` core for portfolio search (#14634, part of #14491): a `Backend` interface (`Index`, `Delete`, `Query` with hits and facets, `Stats`) and a dependency-free embedded inverted-index backend modelled on `pkg/codeindex`. Every document carries `repo`, `kind`, `at`, `url` and `visibility`; queries return ranked hits with highlight spans and facet counts by `kind`, `repo` and any keyword field. Per-repo snapshots are immutable, persisted to `/data/search/<owner>/<repo>.idx` via temp file and atomic rename, capped at 32 MiB per repo (exceeding it is a per-repo coverage error that keeps the previous snapshot), and held in memory under a 256 MiB budget with least-recently-queried eviction. Corrupt index files are ignored and rebuilt on the next update. Nothing uses the package yet, so operators see no change; ingest, APIs and the `search.*` settings land in follow-up issues.
