- `hivectl hives web` now rejects requests whose `Host` is not a loopback host on the listening port (DNS-rebinding protection) and cross-origin browser requests (`Origin` / `Sec-Fetch-Site`), sends `Cache-Control: no-store`, `Referrer-Policy: no-referrer` and `X-Content-Type-Options: nosniff` on every response, and the page removes the launch token from the URL and browser history once loaded. Token auth is unchanged. ([#13178](https://github.com/hivecommons/hive/issues/13178), part of [#13153](https://github.com/hivecommons/hive/issues/13153))
