- **Settings → Hub → Dashboard URL** is read-only on a hub-managed spoke, with its provenance shown ("Owned by the hub (heartbeat)") and a pointer at `dashboard.public_url` for a genuine local override ([#7451](https://github.com/hivecommons/hive/issues/7451)). The field rendered as an ordinary input, but on a hosted spoke the hub owns `hub.dashboard_url`: the heartbeat's project-config push reverts any edit, and until it does the edited value is the second-choice OAuth callback origin (`oauth_origin.go`), so a typo could lock the operator out of the dashboard they typed it into. The governor config now reports `hub.dashboard_url_owner` (`hub` on a hub-proxied spoke or once a heartbeat has delivered a vanity URL, else `spoke`) and `hub.public_url`; `PUT /api/config/governor/hub` refuses a hub-owned `dashboard_url` change with `409` before applying any field; self-hosted spokes registered with the hub keep the editable field, since there it is how the spoke tells the hub where its dashboard lives. Namespace was already read-only and the Snapshot/Preview URL is already locked while auto-publish is on.
