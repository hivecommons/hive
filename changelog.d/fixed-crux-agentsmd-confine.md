- `crux` `agentsmd.ParseNearest` now resolves and confines the starting directory to the repository root before its first `os.Stat`, so a relative path escaping the root (or a sibling such as `repo-other` next to `repo`, which the old separator-less prefix check admitted) falls back to the root `AGENTS.md` instead of parsing a foreign file as the repository's own ([crux#50](https://github.com/hivecommons/crux/issues/50)).
