- Agents now commit as this hive's own GitHub App bot instead of a hardcoded `kubestellar-hive <hive-bot@kubestellar.io>`. The entrypoint wrote that public identity into `/etc/gitconfig` (and the dev user's global config) on every hive, so a self-hosted hive with its own App authored commits nobody on GitHub could attribute, and rulesets that require attributed changes or a recognised author blocked them — while each agent improvised a different fix per kick (one set the App login by hand, the next committed as `hive-quality <quality@hive.local>`, the next as the hardcoded default). Both config layers now derive the identity the way `Config.EffectiveAIAuthor()` does: `project.ai_author` wins, otherwise a usable App's `<app_slug>[bot]`, otherwise the legacy pair — with the matching `<login>@users.noreply.github.com` address GitHub attributes to the bot. Hives that never opted in, or have no installed App, are unchanged.
