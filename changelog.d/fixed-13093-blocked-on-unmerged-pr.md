- Review-backlog findings whose evidence file exists only on the reviewed PR (absent on its base branch) are filed `blocked` with a `<!-- hive:blocked-on pr=owner/repo#N -->` marker and without `help wanted`; a `blocked` issue derives no stage label and refuses every automated claim, and a sweep lifts the label once the PR merges or closes. `hive-open-issue comment --blocked-on-pr <n>` posts the same neutral note with `@`-mentions stripped, so the scanner no longer pings a fork's author to do the hive's work. The contributor relay keeps a session off an issue it just failed or abandoned for `governor.claims.reclaim_cooldown_s` (default 6h) instead of handing it back every ten minutes.
