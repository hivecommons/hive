- Standalone hives (no hub link) can send dashboard NPS responses to a hivecommons-operated relay when the operator opts in and configures `hub.nps_relay_url` / `HIVE_NPS_RELAY_URL` plus an install token (`hub.nps_relay_token` / `HIVE_NPS_RELAY_TOKEN`); a hub with a pull secret (`hub.nps_relay_pull_secret` / `HIVE_NPS_RELAY_PULL_SECRET`) periodically pulls, deduplicates and acks those entries, which appear in `GET /api/admin/nps` tagged `source: relay`. Everything defaults off; see `src/docs/nps.md` (#9619).
