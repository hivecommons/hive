- Task MCP: the `knowledge` tool, which worker agents call to look up the hive's knowledge for their task, now finds facts for a query of several words and for a word that comes later in a page, and it returns each fact's complete body. Before, it kept a fact only when the whole query was one unbroken piece of the title, the first 200 characters or the tags, so most lookups came back empty although the knowledge store's own search had found the fact, and the body it served was that 200-character snippet with no tool to read the rest. A body longer than 16 KiB is cut and ends with a marker that says so. `repo_conventions` now also returns a fact typed `conventions` for the task's repository when the word is not in its text. Both tools now check the page they read for a body: when a page of the same name in another knowledge channel was a draft or belonged to another repository, `repo_conventions` could serve that page's text, and it now serves the listed fact instead.
