- Human-filed bug reports are no longer auto-closed by the App bot on PR merge unless the reporter opts in. `pkg/github.validatePRRequestClaims` now downgrades `Closes #N` to `Refs #N` in an outgoing PR body when the referenced issue carries a bug-family label (`bug`, `kind/bug`, `type/bug`, `type:bug`, `adoption-blocker`), lacks the `— hive:` attribution trailer, and is not authored by a `Bot`. The reporter (or a maintainer) can opt back into auto-close by adding `hive: reporter-confirmed` to the issue body or applying the same label. This closes the failure mode from #6500 → #6762/#6767 (tracked as #6781) where the App bot merge-closed a maintainer's still-symptomatic bug and the reporter could not reopen it — GitHub only allows reopen by users with write access or by whoever closed the issue.
