- An issue labelled `blocked` now reaches the person who can lift it (#12376). `blocked` is a default dashboard waiting label (server and browser), so a blocked issue shows in the Parked band and a PR labelled `blocked` is Gated. The un-park sweep treats `blocked` as a parking label: it keeps the "What to reply" notice on the issue, `/hive approve` lifts the label and re-offers the issue, `/hive decision <text>` lifts it with instructions, and label approval removes it only when the App bot applied it. A contributor's blocked verdict whose reason says a person must act (an admin, maintainer, owner or operator, with no other item, upstream or release named) is now labelled `needs-human` instead of `blocked`, so it is that person's turn in the inbox.
