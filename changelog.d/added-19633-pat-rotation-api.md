- A hive that authenticates with a personal access token can now rotate it without a restart through the owner-only `PUT /api/github-token` route. The new token is checked against the configured GitHub API first (it must sign in, read every project repo and carry the scopes the hive's ACMM level needs); a token that fails is refused and the current one keeps working. A verified token is saved like any other setting, takes effect at once for the hive, its agents and relays, and is recorded in the audit log by fingerprint. The token is never shown back; `GET /api/github-token` reports only its fingerprint, login and when it was verified. The route is refused on GitHub App hives. The Settings field and `hivectl` command (#19633) are not part of this change.
