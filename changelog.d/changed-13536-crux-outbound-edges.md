- The Crux agent runtime (`pkg/agent`) no longer imports `pkg/github`, `pkg/agentaudit` or `pkg/tracing` (RFC #13536, Stage 2 prerequisite): the created-PR shape and the per-agent token-cache path moved into the stdlib-only `pkg/crux/types` leaf as `PRResult` and `AgentTokenCachePath` (with `github.CreatePRResult` now an alias, so `*github.Client` still satisfies the sandbox executor's `PRCreator`), the runtime-emitted audit vocabulary, `AuditSink` and `Fields` moved there too (`pkg/agentaudit` aliases them; `pkg/toolapprove` imports the leaf), and the `agent.send_kick` trace span is opened through a new `Manager.SetSpanStarter` seam that `cmd/hive` wires to `tracing.StartSpan`, so reach bookkeeping is unchanged for the hive binary while an embedding without `pkg/tracing` still gets OpenTelemetry spans on the global tracer. The review-prompt restart-trigger test moved from `pkg/agent` to `pkg/review` against the new `crux.FatalNetworkErrorPatterns()` accessor. A new fail-closed ratchet, `src/internal/testutil/crux_outbound_ratchet_test.go`, records every remaining import from the Crux package set to the rest of Hive (dominated by `pkg/config`) and only lets the list shrink. No user-visible behaviour change.
