- The advisor lane can run on the hive's Claude subscription. A new `advisor.backend` setting (fleet, or per agent) picks how a review reaches the model: `http` (the reviewer endpoint and its API key), `claude-cli` (the Claude CLI on the hive's own Claude sign-in, with every tool, MCP server and hook off), or `auto` (the endpoint when one is set, else the Claude sign-in). Unset follows `governor.reviewer_backend`. It is in the dashboard's Advisor Lane panel, in `hive.yaml`, and in the admin MCP's `advisor.settings` and `advisor.agent`. Each advisor record names its route; a route that cannot run is recorded as `skipped: unreachable` with route `none`. Codex and Copilot subscriptions are not offered: neither CLI documents a mode with every tool off.
