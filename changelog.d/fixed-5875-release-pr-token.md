- The Tagged Release workflow's "Open and merge a PR" step now honors an optional `RELEASE_PR_TOKEN` secret, falling back to `GITHUB_TOKEN` when unset ([#5875](https://github.com/hivecommons/hive/issues/5875)). The hivecommons org's Actions policy denies `GITHUB_TOKEN` the `createPullRequest` mutation — a repo/org setting that did not survive the kubestellar→hivecommons transfer — which stranded v4.8.0 (rescued by hand as #5872) and v4.9.0 (rescued as #5878) at a green gate with no PR. Until an org admin re-allows "Allow GitHub Actions to create and approve pull requests", a PAT or App token in `RELEASE_PR_TOKEN` lets releases open their own PR again; once the policy is restored the secret can simply be removed.
