- A failed `check_run`, `check_suite` or `status` webhook now reacts within seconds instead of waiting for the next governor sweep: the head SHA is resolved to its open PR from the PR detail cache, recorded as a CI failure signal (`/api/status.ci_failure_signals`), and a hive-authored PR's owning agent is kicked at once with the check name and log URL while a contributor PR gets a targeted automerge/contributor-lane pass — gated by `governor.ci_failure_webhook_kick` (default on), repo/agent pauses and a per-head cooldown (`governor.ci_failure_kick_cooldown_s`, default 600). Agents still never watch or poll CI themselves.
