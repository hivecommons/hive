- **A failed CI check now reaches the right agent within seconds of the webhook, not on the next sweep** ([#15291](https://github.com/hivecommons/hive/issues/15291)). A verified `check_run` / `check_suite` (`failure`, `timed_out`) or `status` (`failure`, `error`) delivery resolves its head SHA to open PRs from the existing PR detail cache (no extra GitHub call), records a CI failure signal deduplicated per head and check (`/api/status` `webhooks.ci_failures`: `count`, `last`), and reacts at once: a hive-authored PR's owning agent gets a targeted FIX-BEFORE-NEW kick naming the check and its log, any other PR gets an automerge pass, and the activity log reads `CI failed on #N (check) - kicked agent X`. New `governor.ci_failure_webhook_kick` (default `true`) and `governor.ci_failure_kick_cooldown_s` (default `600`, one reaction per PR head) control it; paused repos, an engaged fleet breaker and paused agents are respected.
