- The automerge sweep lanes (self-authored, trusted-author, contributor lane) share one cached open-PR set from the ForgeState cache and run event-driven when `forgestate.enabled` is on ([#13377](https://github.com/hivecommons/hive/issues/13377), part of [#13373](https://github.com/hivecommons/hive/issues/13373)): no `/pulls` list per 10 s tick, a `check_suite`/`check_run`/`status`/`pull_request_review`/`pull_request` webhook triggers a pass for the affected PR only, a 5-minute floor pass covers the no-events case, and every merge first re-reads the PR through the cache with a 60 s freshness bound; a stale snapshot never merges. Review gate, required checks and hold labels are unchanged, and the legacy listing ticker remains the default.
