- The Hive activity monitor's header now carries its own live item count pill next to the title — the sidebar badge's twin, written by the same render call with the same ↑ +N / ↓ −N cue and `prefers-reduced-motion` handling — so kiosk (`?kiosk=1`), pop-out (`?popout=1`), display mode (`?display=1`) and browser full screen, which all hide the sidebar, still show how many items the monitor is tracking. The pill is enlarged in the chrome-less views so it reads at 1920×1080 ([#16243](https://github.com/hivecommons/hive/issues/16243)).
