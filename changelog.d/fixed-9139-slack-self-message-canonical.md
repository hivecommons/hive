- The Slack single-user message route (`POST /api/saas/slack/user/{username}`) now enforces its self-only rule for non-admins with `canonicalEqual` instead of a flat `strings.EqualFold` ([#9139](https://github.com/hivecommons/hive/issues/9139)). Previously, on a hub using a custom/OIDC provider that issues subjects differing only by case, a non-admin `custom:AbC` could DM the distinct user `custom:abc` through the hub — the spam-relay floor the handler exists to enforce. OIDC subjects now compare exactly, as every other owner check has since the F17 audit; GitHub logins still match case-insensitively.
