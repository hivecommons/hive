- Fixed pi accumulating context across tasks because `quitLiveCLI` did not kill the pi process (kubestellar/hive#6776). The two `C-c` sequence exits claude/codex/agy but not pi, so the previous pi instance kept running and `relaunchCLI` typed its launch command into a live pi as a chat message — every task ran in the same session with the previous task's conversation history and scoped GitHub token still in scope, until pi compacted. `quitLiveCLI` now issues `tmux respawn-pane -k` after the C-cs when `BACKEND === 'pi'`, which unconditionally terminates the pane's foreground program and re-executes its default shell. Each task therefore starts pi in a fresh context — no leaked history, no leaked token. The other backends are unchanged.
