- Close-on-merge no longer closes an issue a merged PR only references. The backfill sweep passed the configured short repository name (`utah-packages`) into the close path, and the `Refs` guard compared it with the parsed `owner/repo`, so `Refs #490` on projectbluefin/utah-packages#860 looked like no reference and #490 was closed with "Fixed by #860". References now compare as `owner/repo`. The close path reads the same non-closing decision as the coverage comment (`Refs`/`Part of`, or "#N stays open"). An issue carrying `hive/verified-open` or `hive/partially-addressed` is closed only by a PR whose own text closes it. `GET /api/close-on-merge/wrong-closes?days=N` lists issues closed the wrong way for maintainers to reopen.
