- Pending tool approvals now expire ([#19446](https://github.com/hivecommons/hive/issues/19446)). Previously an operator-lane entry waited forever, so an approval granted days later still released a request made in a context nobody remembered. Entries older than `tool_approval.pending_ttl_seconds` (default 900) are swept and can never be approved; resolving one returns HTTP 410. Existing config keys are unchanged.
