- Staff agents can now list a repo's merged pull requests with `gh pr list --state merged` (any `--json` fields, no `--search`). Before, the gh wrapper refused every `gh pr list` from a non-contributor agent, so ci-maintainer could not run a repo's own agent-audit script (`gh pr list --state merged --json … | node scripts/ai-audit-report.mjs`) and parked "open the run summary and say which PR it flags" for the owner on Danathar/dns-failover#152 and Danathar/openaudible-autoupdate#169. Merged PRs are not work to pick, and the same set was already readable through `gh search prs --merged` and a GET of `repos/<owner>/<repo>/pulls`. Open, closed, all and `--search` listings stay refused, and the refusal now names the reads that still work.
