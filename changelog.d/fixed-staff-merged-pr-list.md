- The gh wrapper's refusal of `gh issue list` / `gh pr list` for staff agents now names the reads that still work: merged PRs through `gh search prs --repo <owner/repo> --merged --json …` or a GET of `repos/<owner>/<repo>/pulls?state=closed`, any authorless `gh search`, and `gh pr view` / `gh issue view`. Agents read the old "listing is blocked" as "there is no way to look up merged PRs", so ci-maintainer parked red audit-trail checks for the owner instead of diagnosing them (Danathar/dns-failover#152, Danathar/openaudible-autoupdate#169). The gate itself is unchanged.
