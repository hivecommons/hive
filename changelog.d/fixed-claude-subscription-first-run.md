- A `claude` agent signed in with a subscription no longer opens on Claude Code's first-run screens when its HOME has never run Claude Code. Before each launch hive now adds `hasCompletedOnboarding` and workspace trust for the agent's work directory (and the repos under it) to the agent's own `~/.claude.json`, as it already did for inference agents, so the "Security notes" screen and the "Quick safety check" trust dialog (whose default answer, "No, exit", quit the CLI when an early Enter reached it) no longer appear. The seed only adds those keys, keeps the file's owner and mode, and leaves a file it cannot read, parse or safely replace untouched. The trust watcher also now recognises the "Security notes … Press Enter to continue" screen and answers it with Enter, for any HOME the seed did not reach.
