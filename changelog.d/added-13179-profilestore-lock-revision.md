- `hivectl hives`, the TUI's Hives pane and the Commons web UI (`hivectl hives web`) now commit `profiles.yml` under a shared cross-process lock (`profiles.yml.lock`, mode 0600) and only if the file is still the revision they loaded. An edit made from one surface while another changed the hives is refused with nothing written — the CLI/TUI ask you to re-run, the web UI returns 409 "requires renewed review" — instead of one writer silently overwriting the other. ([#13179](https://github.com/hivecommons/hive/issues/13179))
