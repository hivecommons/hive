- The `hive-merge` relay now enqueues a PR through GitHub's native merge queue on a repo opted into `auto_merge.native_merge_queue`, the same way the auto-merge lanes do, instead of sending a direct merge that GitHub refuses with 405 "Changes must be made through the merge queue". An opted-in repo no longer raises the "Merge blocked" merge-queue banner. On other repos the banner now suggests opting into the native queue, enqueueing the PR or merging it by hand, and no longer suggests removing the merge-queue rule from branch protection.
