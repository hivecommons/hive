- **Settings can now switch the ioscan semantic classifier off, and "open" fail mode sticks at L5–L6.** On an L5–L6 hive with no model endpoint (any hive whose agents all run on a subscription CLI such as Copilot), the classifier that became default-on in #13858 fails closed and withholds every piece of untrusted issue and comment text. The fixes the boot log names (`ioscan.classifier.enabled: false` or `ioscan.classifier.fail_mode: open`) had no dashboard control, and choosing **ioscan fail mode → open** silently saved as unset, which reads back as closed at L5–L6. Settings → Security → Input Defense now has **Semantic classifier** (level default / on / off) and **Classifier fail mode** (follow ioscan fail mode / open / closed), "open" is stored as written, and switching the classifier off takes effect on the next scheduler pass without a restart ([#14025](https://github.com/hivecommons/hive/issues/14025), [#14027](https://github.com/hivecommons/hive/issues/14027), [#6685](https://github.com/hivecommons/hive/issues/6685)).
