- `GET /api/contribute/activity` now honours its `limit` parameter, and says how much history it actually has ([#5704](https://github.com/kubestellar/hive/issues/5704)). The parameter was accepted and silently ignored: `limit=5` and `limit=300` both returned the same fixed 50 events. The response now returns the requested number of most-recent events, preserves oldest-first order within that window, and adds `retained` plus `capacity` so callers can distinguish a truncated response from a full ring with older entries evicted or a genuinely short history. Omitted, invalid, or non-positive limits still return everything retained, and requests above the ring size clamp visibly rather than pretending to serve history the hub never kept.
