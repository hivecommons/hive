- Headless contributor tasks are no longer killed by the hub at 30 minutes ([#7778](https://github.com/hivecommons/hive/issues/7778)). The hub keeps a task assigned only while the relay keeps reporting progress, and the headless relay sent exactly one progress report — when its child process started — so any headless task longer than 30 minutes was revoked mid-run, its work lost and its issue put in failure cooldown, well inside the relay's own 4-hour headless ceiling. The headless path now reports progress on the same 2-minute cadence as the interactive path for as long as its child is alive, and stops the moment the child exits or the task is revoked.
