- A reviewer on a Forgejo-only hive can now record its verdict: the forge request relay serves `hive-review --record-verdict` with the same checks as the GitHub review relay (request-file owner and review authorizer, lane write allowlist, repo pause, `review.require_labels`, repo and number match, dispatch binding and the advisory rule), reading the PR from Forgejo, so the PR gets its `[hive-reviewed: ...]` annotation instead of returning on every kick. Approve, request-changes, comment and thread requests are still refused on a Forgejo-only hive. ([#20292](https://github.com/hivecommons/hive/issues/20292))
