- `bin/test_git_credential_hive.sh` no longer tests the live host instead of itself on per-UID hives. Run as an agent UID (>= 2001), the credential helper derives the agent name from the uid-map — deliberately ignoring the `HIVE_AGENT` the harness sets — and reads that real agent's live `/tmp/.hive-mode-<agent>`, so the two mode-notice assertions failed (or passed vacuously) with the host's deployment state. The harness now stubs `id -u` to a sub-2001 UID so the helper takes the env-var path the harness controls; the helper's own uid-map trust model is untouched.
