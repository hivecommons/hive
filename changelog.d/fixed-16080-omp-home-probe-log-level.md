- An omp agent HOME without a sign-in no longer files a repeated fleet defect: both the per-HOME "omp model discovery found no models for this HOME" line and the all-homes-failed "omp model discovery unavailable, serving static fallback" line are logged at Info instead of Warn, matching the goose/agy/claude backends. A HOME with no sign-in contributes nothing by design, and the degraded-discovery transition is already audited once by the discovery tracker ([#16080](https://github.com/hivecommons/hive/issues/16080)).
