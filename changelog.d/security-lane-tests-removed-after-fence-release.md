- **An owner's approval of a workflow-file change no longer merges a head that also deletes tests.** The contributor lane's diff check names only its first fence, and the owner-approval release ([#14664](https://github.com/hivecommons/hive/issues/14664)) lifts the workflow-path fence alone, so a PR that edited `.github/workflows/**` and removed tests merged on that approval with the test removal never checked. Such a head now stops at `contributor-lane:tests-removed`, which no approval overrides, before any release is read.
