- The `hive-serialized` merge lane and the ACMM `acmm:merge-queue` credit no longer treat a ruleset-only branch's required checks as unknown when the GitHub App lacks the Administration permission ([#10984](https://github.com/hivecommons/hive/issues/10984)). A 403 from classic branch protection now falls back to the rulesets' required checks (GitHub still enforces classic rules at merge time), and a lane repo that earns no ACMM credit shows the reason on its row.
