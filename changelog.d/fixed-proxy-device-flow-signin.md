- The bundled proxy no longer rejects device-flow sign-in on direct-route spokes: `POST /api/gh-user-auth/start` and `/poll` (exact paths) are forwarded without the shared token, and mutating requests carrying a `hive_session` cookie reach the Go API, which authenticates the session itself. Neither gets `X-Hive-Internal`; all other unauthenticated mutations still return 401 ([#15872](https://github.com/hivecommons/hive/issues/15872)).
