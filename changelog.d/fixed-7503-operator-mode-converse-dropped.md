- Fixed an agent's configured `mode` and `converse` being silently dropped between config load and the running process, so an agent the ACMM pack does not manage ran at the level default with more authority than any config file granted it ([#7503](https://github.com/hivecommons/hive/issues/7503)). Two paths were responsible: the pack apply that runs on every restart (and on an explicit level change) cleared `mode` for *every* agent in the process table, not just the pack's roster, so an operator's `mode: ADVISORY` on a dashboard-created `reviewer` became `ISSUES_AND_PRS` at L5; and the dashboard-overlay reload replaced each agent entry wholesale, so a `converse: true` set only in the per-agent overlay file was lost whenever the dashboard overlay was silent on it. Pack applies now re-derive `mode` only for pack agents, a silent dashboard overlay no longer revokes a lower layer's `converse` (an explicit `converse: false` still wins), and `SyncModeFiles` logs when an agent falls back to the level default so the gap is a grep rather than a by-hand comparison of `/tmp/.hive-mode-<agent>`.
