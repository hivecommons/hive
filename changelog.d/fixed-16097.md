- **A wedged tmux server can no longer stall the whole governor tick through the watchdog** ([#16097](https://github.com/hivecommons/hive/issues/16097)). `watchdog.Reconciler.Tick` runs inline in the steady-state governor loop on the promise that every probe carries a deadline, but `WatchdogFleet.Observe` shelled out to `tmux has-session` and `tmux capture-pane` with no timeout — so one agent's hung tmux server (socket accepted, never answering) froze the eval cycle, rotation, automerge sweep and state persistence until tmux recovered or hive restarted, and shutdown could not interrupt it. Observe's tmux probes now share a short deadline (`agent.ObserveProbeTimeout`, 5s); a probe that times out reports the agent as unobservable for that sweep (never as "no session", which would trigger a restart), and `Tick` stops early once its context is cancelled. The `watchdog.Source` interface is unchanged.
