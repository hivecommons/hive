- `crux/api/client.Runtime` implements every `crux.Runtime` family over the `crux serve` API (Crux sidecar plan, stage 3): `crux/runtime.New` returns it in `CRUX_MODE=sidecar` (connecting to `$CRUX_SERVER` or the serve socket) instead of `ErrModeUnavailable`, and `NewWatchdogFleet` composes a watchdog fleet for it from the wire watchdog source plus the runtime's Lifecycle. Kick and Host observer events ride one reconnecting `/v1/events` stream; the Resumer sentinels (`ErrResumeBusy`, `ErrResumeSessionGone`, `ErrResumeUnsupported`) round-trip from the server's status codes; Authorizer refusals and transport failures fail closed. A parity test holds `crux.Runtime` and `api.RuntimeRoutes` to each other in both directions so a method cannot be added without a route.
