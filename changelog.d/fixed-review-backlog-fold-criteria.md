- The review backlog no longer folds a finding into an open issue just because both cite the same file: it folds only when the category (review perspective) matches and the finding cites the same symbol or a nearby line; otherwise it files a new issue cross-linked with "Same file as #N" ([#13906](https://github.com/hivecommons/hive/issues/13906)). The same check now applies to an open issue matched only by its "Review backlog (<perspective>)" title prefix, and scanner-filed issues without a "Review backlog (…)" title or "Perspective:" line no longer receive folded review findings (retiring the [#11578](https://github.com/hivecommons/hive/issues/11578) behaviour).
