- Hive PR notifications no longer spam authors and watchers: the stage stalled/regressed notes, the trusted-human 071 note and the duplicate-PR redirect share one `<!-- hive:status -->` comment per PR that is edited in place instead of appending a comment per event; "**Reviewed** — no findings" reviews are recorded as verdicts without a GitHub review and a head carries at most one hive review; the 071 note @-mentions the author once per cause instead of once per head; a check returning to pending after a push is no longer a regression and a merge-train queued/rebasing wait is never stalled. New knob `github.notifications.mode` (`quiet` default, `normal` restores the old behaviour) ([#15875](https://github.com/hivecommons/hive/issues/15875)).
