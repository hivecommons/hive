- The Hub's GitHub browser login now uses PKCE (S256) as defence-in-depth, binding the authorization code to the browser that started the login: the authorize redirect carries a `code_challenge`, the matching `code_verifier` lives in a short-lived single-use HttpOnly cookie and is sent in the token-exchange form body. A callback with a missing or malformed verifier is rejected with 400 before any code exchange or session is minted; logins started before the upgrade must be restarted (#14633).
