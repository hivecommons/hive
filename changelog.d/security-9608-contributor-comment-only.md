- **The review swarm never approves or requests changes on a PR the hive did not open** ([#9608](https://github.com/hivecommons/hive/issues/9608)). With `review.all_authors` on, a reviewer's `approve` or `request_changes` on a person's PR could previously land as a formal GitHub vote from the App bot. The review relay now reads the PR's author before any formal verdict and, unless it is the hive's App bot, `project.ai_author` or another bot account, submits the review as a `COMMENT` with a leading line naming the intended verdict. It fails closed: a PR whose author cannot be read is treated the same way. The recorded verdict is unchanged, the agent's `.result.json` carries a `note` explaining the downgrade, and the `agent_pr_reviewed` audit entry adds `requested_state` and `downgraded=contributor_pr`. Hive-authored and bot PRs are reviewed exactly as before. First-time contributors are deliberately not gated behind a label; the reasoning is in `src/docs/review-swarm.md`.
