- Serialized merge lane: a pull request that only an automerge sweep lane would merge, and whose branch update and merge writeback containment refuses (for example an auto-promoted contributor PR without `hive-review` at L6), no longer takes the lane front. It used to reach the front and hold it for the full front timeout, refused every round with `writeback: unsolicited write suppressed`, while owner-queued pull requests waited behind it; with several such PRs the lane made no merges for hours. The lane now asks containment before the PR takes a place, so it is refused without being recorded (no front churn), and a front whose sweep writes become refused leaves on its path's next call. The lgtm queue, `/hive merge` relay and dashboard paths are not asked and behave as before.
