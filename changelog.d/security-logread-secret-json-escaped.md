- `log_read` (admin MCP) and `GET /api/logs/read`: one of the hive's own secret values is now redacted when it holds a quote, a backslash or a control character. The hive log, the request log and the output sources are stored as JSON, so such a value is on disk only in its JSON-escaped form (`pa\"ss\\word`). The read-time redaction looked for the plain, URL-encoded and base64 forms only, so it missed it and the value came back readable in the returned line. The JSON-escaped form, with and without HTML escaping, is now redacted as well. Values made only of letters, digits and ordinary punctuation were always redacted.
