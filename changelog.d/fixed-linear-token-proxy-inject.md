- Agent writes to Linear no longer fail with `401 AUTHENTICATION_ERROR` the day after the connected app's OAuth token rotates. Hive refreshes the token and re-pushes it into each agent's tmux session environment hourly, but a running CLI keeps the environment it was forked with, so from the first rotation after launch every Linear call from inside the pane carried a dead token — observed for two days on a live hive, during which the agent had silently fallen back to the operator's personal `LINEAR_API_KEY` and every issue it filed showed the operator as its creator. The egress proxy, which already terminates every agent request to `api.linear.app` for the tier gate, now replaces the `Authorization` header of every ISSUES_ONLY+ request with the hive's current credential (the same resolver the session-env push uses), so the copy in the agent's environment — stale, absent, or a placeholder — no longer matters. Requests below the ISSUES_ONLY floor and requests the gate refuses are untouched.
