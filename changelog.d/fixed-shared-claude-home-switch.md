- Claude agents on hives with per-agent users no longer have to log out about every 8 hours: set `HIVE_SHARED_CLAUDE_HOME=1` to keep every agent's `~/.claude` as one whole-directory link to the shared `/data/home/.claude`, the layout from before [#17031](https://github.com/hivecommons/hive/issues/17031). Claude Code saves a refreshed token by renaming a file over `.credentials.json`; in a per-agent `~/.claude` that replaced the credential link, so the refresh never reached the shared login and the other agents were left on a rotated grant. With the directory linked, the refresh lands in the shared login. The switch is off by default. While it is on, Claude agents share `CLAUDE.md`, history, todos and memory again, a per-agent `.claude` is moved aside (never deleted) on the next launch, and `clear_on_kick` skips Claude. See `src/docs/agent-configuration.md`.
