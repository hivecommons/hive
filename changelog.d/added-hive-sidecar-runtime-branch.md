- `cmd/hive` boots against a sidecar `crux serve` when `CRUX_MODE=sidecar`: the sidecar client is wrapped so the Host observers (kick outcomes, pause transitions, relaunches, prompts, audits, conditions) are fed from the runtime's event stream, and hive serves its capabilities to the runtime over the hive callback endpoint (`$CRUX_HIVE_SOCKET`).
