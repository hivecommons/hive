- Customers: the hub's customer match endpoint now answers only the project hives named in `HIVE_HUB_CUSTOMERS_PROJECT_HIVES` (by default the project's own hive), the one trust domain the hub shares customer data with. Every other hive is refused with `403` and no data, even with `customers.hub_import.enabled` on and a person's consent, and records only its own interactions. For a project hive the labeled public country and organization now cross for every hub person it asks about, not only its grant holders, and an organization from the hub's affiliation lookup crosses labeled by how it was found (`profile_company`, `org_membership`, `identity_provider`, `ghe_account`); a contributions-only affiliation never crosses. Real name still needs consent. See `src/docs/design/customers-hub-consent.md#project-hive-gate-2026-11-25`.
