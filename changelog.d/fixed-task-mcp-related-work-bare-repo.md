- Task MCP: `related_work` (and the `related_work` part of `context_bundle`, and `history`) works on hives that list their repositories by bare name. Most hives write `project.repos: [console]` with `project.org`, and every issue and pull request in the hive's snapshot is stamped with that spelling, while a task is always scoped to `owner/repo`. The tool compared the two spellings, matched nothing, and answered with an empty list for every task on such a hive. An item that carries its repository's bare name is now read as that repository's full name. An item that names a different repository is still left out.
