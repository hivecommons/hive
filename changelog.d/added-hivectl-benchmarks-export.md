- `hivectl benchmarks export` converts the local evidence tree (`--root`, default `/data/evidence`) into benchmark schema records offline, with the same converter as `GET /api/benchmarks/export`. The hive is identified only by `--hive-id` (hashed locally) or `--hive-hash`; repo names appear only for `--public-repo owner/name`, cost stays `unknown`, and `--since`, `--until`, `--out` and `--by-month DIR` (`<hash>/<YYYY-MM>.json`) shape the output (#18990).
