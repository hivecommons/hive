- Input Defense settings saved from the dashboard now actually unblock kicks at ACMM L5+ ([#16973](https://github.com/hivecommons/hive/issues/16973)). Saving ioscan fail mode "open" was stored as unset, which at L5+ falls back to the ACMM pack's fail-closed default, so the setting snapped back to "closed" and kicks carrying untrusted text stayed withheld. "open" is now stored as given, and every ioscan save in Settings → Security → Input Defense rebuilds the semantic classifier from the new backend and fail mode immediately, clearing the blocked-kick alert when it no longer applies. The alert no longer tells operators to restart for changes the dashboard now applies live.
