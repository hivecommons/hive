- Added an opt-in code scanning sweep (`code_scanning`, off by default, per repo): it files a repository's open GitHub code scanning alerts (CodeQL, OSSF Scorecard, Trivy, …) at or above `min_severity` (default `high`) as grouped `[governor] Code scanning: …` issues sized for one PR, at most five new issues per repo per hourly pass, updates them as alerts are added, fixed or dismissed, and closes them when every alert is gone. OSSF Scorecard's repo-posture checks are left out by default. It needs the GitHub App permission "Code scanning alerts: Read-only"; without it the dashboard shows a notice for the repo. See `src/docs/code-scanning.md`.
