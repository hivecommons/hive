- Log sources `proxy`, `litellm` and `hive-output` (read with `log_read`): a line that never ends is stored in records of at most 64 KiB, and the split no longer cuts a multi-byte character in half. Before, a character that straddled the 64 KiB mark was lost: its two halves were stored as replacement characters (`�`) in two records. The Go writer and the Node auth proxy's writer now both move the split back to the start of that character. ASCII output was never affected.
