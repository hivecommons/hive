- The contributor lane now binds an unmarked owner approval (a typed `/hive decision approve`, or a dashboard `/approve` posted without a head marker) to the time GitHub first showed the PR's current head, never to the head commit's committer date. That date is written by the pusher's git, so a later push carrying a backdated commit could inherit an approval given on the head before it and release the workflow-path fence for a diff the approver never saw. An approval older than the observed head now leaves the fence armed, exactly like an APPROVED review on a stale commit; the approver re-approves the new head to release it.
