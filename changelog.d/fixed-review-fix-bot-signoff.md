- The review-fix kick no longer pushes a hive-signed commit onto a PR the hive did not open, even with `review.fix_human_prs` on ([#12897](https://github.com/hivecommons/hive/issues/12897)). Such a commit carried the hive App bot's `Signed-off-by` while the squash merge is attributed to the contributor, so the `Sign-off survives the squash` check failed the PR as `bot-signoff` — a red only the contributor could clear by re-signing a commit they did not write (#12858, #12880). The proposed change is now always delivered as a ```` ```suggestion ```` or ```` ```diff ```` block in the review (and in in-thread replies to review-bot threads), the same path already used with the setting off; the `review_fix_withheld` audit entry records whether the setting was on. The hive's own PRs are fixed exactly as before.
