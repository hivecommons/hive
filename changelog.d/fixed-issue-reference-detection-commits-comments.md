- **A PR that names an issue only in a commit message or a PR comment now counts as linked to it** ([#14859](https://github.com/hivecommons/hive/issues/14859)). The contribute view's issue→PR resolver checked only the PR title and body, so it dropped any search hit that mentioned the issue elsewhere and missed commit-only references entirely. The same title/body-only view let a scanner note claim that a PR "does not reference" an issue when two of its commits said `Fixes #N`. The resolver now also reads the issue's timeline `cross-referenced` events, a single API call that covers commits and comments. The scanner and dedupe policies now tell agents to check that timeline and the PR's commits and comments before saying a PR does not reference an issue, and to say "no closing keyword in the PR body" when only the body lacks one.
