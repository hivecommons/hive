- **A PR that names an issue in its title, body or a comment now counts as linked to it** ([#14859](https://github.com/hivecommons/hive/issues/14859)). The contribute view's issue→PR resolver checked only the PR title and body, so it dropped any search hit that mentioned the issue elsewhere. The same title/body-only view let a scanner note claim that a PR "does not reference" an issue when two of its commits said `Fixes #N`. The resolver now also reads the issue's timeline `cross-referenced` events (up to five pages of 100, under the existing 4s lookup timeout), which cover title, body and comment references (a commit-message-only reference is a `referenced` event and is not matched). The scanner and dedupe policies now tell agents to check that timeline and the PR's commits and comments before saying a PR does not reference an issue, and to say "no closing keyword in the PR body" when only the body lacks one. The added policy section grows the largest shipped policy past the 2x headroom the prompt-size cap requires, so `promptsrc.DefaultMaxPromptBytes` rises from 64 KiB to 96 KiB; `HIVE_PROMPT_SOURCE_MAX_BYTES` still overrides it.
