- **Hub GitHub login no longer puts the OAuth client secret in a URL.** The browser sign-in token exchange (`exchangeGitHubLogin`) now sends `client_id`, `client_secret` and `code` in a form-encoded POST body, together with the exact `redirect_uri` used in the authorize redirect, instead of in the request URL query where proxy and request logs could retain them. Requested scopes are unchanged. The new `src/docs/hub-login-token.md` records who consumes the stored login token and its lifetime. ([#14631](https://github.com/hivecommons/hive/issues/14631), [#14632](https://github.com/hivecommons/hive/issues/14632))
