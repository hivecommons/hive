- A pull request that waits on you now says how to answer it. While a PR at `stage/085-needs-decision` or `stage/070-fixing` is parked for your decision, or held by the review for a person, the hive status comment at the top of the PR carries a **Your move** section. It lists the `/hive` replies that answer it (`/hive approve`, `/hive decision approve <why>`, `/hive decision <what to change>`) and the GitHub review that does the same. The section is edited in place, so it sends no notification, and it is removed once the wait ends. Before this, such a PR only said "review and approve it" in prose.
