- **Activity Monitor URL views and display mode.** Every Activity Monitor filter can now be described in `am.*` URL parameters (`am.kind`, `am.repo`, `am.q`, `am.labels`, `am.group`, …), so a link reproduces the same view in a fresh browser profile; a tab opened with `am.*` keeps its filter to itself and never overwrites the saved one. A new 📺 header button (or `?display=1`) turns the monitor into an attended wall view with no row actions, left with Esc or `d`; it never requests full screen or a wake lock, grants nothing, and `?kiosk=1` is unchanged ([#15924](https://github.com/hivecommons/hive/issues/15924), [#15925](https://github.com/hivecommons/hive/issues/15925)).
