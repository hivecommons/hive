- Contributor quota guard: the enforcing (relay) implementation no longer skips quota windows whose kind this build does not recognize, so an exhausted window of a newly-introduced kind holds work instead of admitting it. A guarded relay now re-reads the quota and asks for work again once every reserve is clear, an unreadable or partially-written reading file can no longer terminate the relay, and the idle `ready` hold is evaluated against the base window reserve rather than the simple-complexity reserve. The unwired duplicate `src/pkg/contributorquota` has been removed so there is a single authoritative guard. (#6951)
