- A contributor relay that drops an issue now says why, and the hub keeps and shows the reason. A task that ended with no pull request and no `no_work_needed` / `blocked` / `wrong_base` verdict reached the hub as `verdict=idle verdict_reason=""`: the issue showed "Completion cooldown until …" in the Withheld list, was offered again, and was dropped again, and nobody could tell why without the relay's own pane. The relay now sends a `verdict_reason` on every completion without a PR and still no `verdict`, so the completion is booked idle exactly as before: `agent reported complete without a pull request: <the agent's own sentence>` for a `HIVE_VERDICT: complete` with nothing behind it, and `agent exited without a conclusion` for a chrome-idle or headless exit with no verdict. The hub never records an empty reason for a no-PR idle (a relay that sends none gets `agent exited without a conclusion`, `agent reported complete without a pull request and gave no reason` or `no reason given`, by completion signal), keeps the latest one per issue across a restart, and shows it on the Withheld list's `cooldown` row (`… — last relay: <reason>`) and on the Activity monitor's issue row (`last_idle`, in the dashboard tooltip and in `stage_tracker_read`). A verified PR or a no-work verdict clears it. Cooldowns, the no-PR streak and the evidence-less rule are unchanged.
