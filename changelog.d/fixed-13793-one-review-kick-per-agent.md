- Review dispatch no longer stacks several review kicks on one agent ([#13793](https://github.com/hivecommons/hive/issues/13793)). With `review_heads` replicas, the replica picker counted distinct PR heads per agent, so replicas holding the same PR tied and one PR's remaining perspectives all went to the first replica. On a two-replica Sonnet head, four kicks reached one Claude session within three minutes; it ran one turn, the other verdicts never arrived, and they expired and were re-sent to the same replica. The planner now sends a review kick (per-perspective, head, combined or decision) only to an agent with none in flight, picks the first free one in name order, and lets work wait for a later cycle when every candidate is busy. Waiting costs no `max_redispatch` or `head_max_retries`.
