- Crux stage 2 (#14138): `crux/api/callback` is the stdlib-only wire contract a sidecar runtime uses to call back into hive for scoped GitHub tokens, REST accounting, usage, canary/text scans, conditions, the Linear credential and PR creation (HTTP+JSON over a hive-served 0600 Unix socket, fail closed when hive is unreachable); `crux/hivecap` adapts it onto the ring's existing seams and `pkg/cruxhost` is the hive-side mount over hive's existing implementations. The runtime never holds the App private key.
