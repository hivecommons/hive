- The ntfy rate-limit cooldown now caps a server-sent `Retry-After` at the same one-hour ceiling the fallback backoff already uses. Before, a single 429 carrying a large value (a day, a year) set a deadline the cooldown logic never shortens, so ntfy notifications were silently dropped until the process restarted; the default server is the public ntfy.sh, so that value was not under the operator's control (#16871).
