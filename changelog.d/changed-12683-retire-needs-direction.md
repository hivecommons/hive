- **`needs-direction` is retired in favour of `needs-decision`.** The two labels had identical hard-suppress gates, un-park handling and derived `stage/085-needs-decision`, differing only in which policy paragraph named them. The "Escalate Instead of Stalling" policies now tell agents to label `needs-decision`, and the issue stage reconciler performs a one-shot migration on every open issue it plans a stage for: `needs-direction` present → add the configured needs-decision label, then remove `needs-direction`. Readers (enumeration hard-suppress, un-park sweep, label approval, agent-start triage detection, dashboard bucket, stage 085 derivation) keep accepting `needs-direction` as a legacy alias so an issue mid-migration never un-parks, and the `hard_suppress_labels.needs_direction` config key and dashboard bucket stay (deprecated) so operator YAML keeps working. Docs and an ADR-0019 amendment mark the label retired. (#12683)
