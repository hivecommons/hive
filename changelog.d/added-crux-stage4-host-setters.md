- Crux sidecar runtimes (`CRUX_MODE=sidecar`, [#14138](https://github.com/hivecommons/hive/issues/14138) stage 4) now reach two more `crux.Host` setters over the hive callback endpoint: the manager's inference routes go to hive's proxy over `PUT`/`DELETE /v1/inference/routes/{agent}` (pushed by a non-blocking worker with retry and a one-minute resync, so a restarted hive relearns them) and sandbox branch pushes run through hive's journaling mutation boundary two-phase over `POST /v1/effects` / `POST /v1/effects/{id}/end` (an unreachable hive refuses the push; a denial is `effects.ErrDenied`; a sidecar that dies mid-push is journaled as abandoned after 15 minutes). `SetSpanStarter` is documented in-process-only. `api.HostSetters` is the disposition table (callback | event | route | config | in-process-only) for every `Host` setter and `crux/api/client`'s parity test fails when a setter is added without a row. In-process mode is unchanged.
