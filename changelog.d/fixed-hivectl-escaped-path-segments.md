- `hivectl` and the stdio admin MCP (`hive-admin-mcp`): a name that needs percent-encoding in a request path now reaches the hive as named. Callers escape each path segment, and the shared client then escaped the whole path a second time, so `/` went out as `%252F` and the hive read a literal `%2F` in the name. Over stdio the `agent.model` write with a model id such as `kiro-api-key/claude-opus-5:high` asked the hive for the model `kiro-api-key%2Fclaude-opus-5:high`; `hivectl` commands that take a name with a `/`, a space, `#`, `%` or a non-ASCII letter had the same fault. Names without such characters were never affected, and run keys only worked because the run endpoints decode twice. The HTTP admin MCP endpoint was not affected.
