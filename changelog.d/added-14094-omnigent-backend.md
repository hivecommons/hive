- **`omnigent` contributor backend (T3 experimental).** Registered the Omnigent meta-harness CLI ([omnigent-ai/omnigent](https://github.com/omnigent-ai/omnigent), Apache-2.0) across `KNOWN_BACKENDS`, `CLIBackends`, local confinement matrix tests, and contributor preflights. Omnigent orchestrates Claude Code, Codex, Cursor, Pi, and custom agent harnesses; on the local CLI path it exposes no OS-level sandbox wired by Hive and requires explicit opt-in via `HIVE_OMNIGENT_DANGEROUSLY_RUN_UNCONFINED=1`. Every launch is `omnigent run --server local [--model <id>]` (`run` opens the agent REPL; `--server local` pins a local Omnigent server, so remote-server mode is unsupported), and container mode stages only `auth_tokens.json` and `config.yaml` from `~/.omnigent`, never session history. Omnigent's internal policy engine and sandboxing compose additively, while Hive's proxy remains strictly authoritative for all GitHub writes and push operations.
