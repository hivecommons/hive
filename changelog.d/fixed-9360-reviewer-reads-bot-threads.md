- The review swarm's read step now also fetches a PR's open, unresolved inline threads from the configured `classification.review_bots` logins (Codex, Copilot code review, …) and asks the reviewer to say — for each one — whether it agrees, disagrees, or cannot verify it. A confirmed P0/P1 finding now blocks a clean or "safe" verdict exactly like a defect the reviewer found itself, in-scope rules and all; previously the reviewer never saw these threads at all, so it could (and did) call a PR safe with an open, unanswered bot finding sitting on the same commit ([#9360](https://github.com/hivecommons/hive/issues/9360)). The reviewer still never replies in or resolves these threads itself.
