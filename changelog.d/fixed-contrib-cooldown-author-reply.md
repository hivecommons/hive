- A contributor task that ends without a pull request because the agent asked the issue's author a question no longer leaves the issue withheld for the whole no-PR completion cooldown once the author answers. When a hive-marked comment (the `— hive:` trailer or the 🐝 **Hive Agent** footer) was posted during the task and the issue's author comments after it, the hub ends that cooldown on its next once-a-minute sweep and offers the issue again; the next task reads the answer through the prompt's existing `gh issue view --comments` step. One question earns one release (kept in `author-reply-releases.json`, so a restart or a chatty thread cannot loop the issue), only the issue's author counts, and with-PR, verdict, failure and quarantine cooldowns are untouched. The sweep reads an issue's comments only when the queue's `updated_at` shows activity since the completion, and does nothing when `contribute_cooldown_enabled` is off. Seen on projectbluefin/gutenprint-printer-app#238.
