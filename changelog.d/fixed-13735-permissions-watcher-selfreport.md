- The selfreport slog feed treats the permissions watcher's `fixed …` lines (file/directory permissions, ownership) as benign self-healing and no longer files `unclassified_error_repeated` issues for them. On v5 the `fixed file permissions` line is already Info-level and never reached the feed, so this is a guard against re-promotion there; the `fixed ownership` line still logs at Warn and is now suppressed too ([#13735](https://github.com/hivecommons/hive/issues/13735)).
