- The admin MCP can now say what merged over a longer window. The new read tool `merged_prs_read`, and the new `GET /api/merged-prs` behind it, list the PRs the hive saw merge from its merged ledger (kept 90 days), with `since`, `repo`, `merged_by` (`hive`, `human` or a login), `lane`, `author`, `exclude_author` and `approved` filters. Each entry has counts by merger, and new merges also record the PR's `author`, `author_kind` (agent / bot / human) and the human approvals the hive recorded on the merged head, so "what did the hive merge on its own in the last day" is one call. Older entries read as unknown for those fields. The Activity monitor's Merged list gains the same since / merged-by / repo filters, and `stage_tracker_read`'s `recent` now says it covers the last 30 minutes.
