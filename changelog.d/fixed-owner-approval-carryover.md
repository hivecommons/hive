- An owner's approving review counts for a PR head only when it approved that content. GitHub moves an existing review onto a later merge of the base, so on projectbluefin/utah#1078 a review submitted 2026-11-04 01:17Z was read as approval of 9d8ceab, a commit made the next day, and released the workflow-path fence. Now the review counts when it was submitted at or after the head commit's date, or when the head adds only base merges that leave the PR's diff unchanged; the fence comment then says the approval was carried over a base merge. The same rule lets an approval on the previous head answer `requires_human` after such a merge (it is no longer re-asked), and the 085 **What to do** no longer asks for an approval that is already recorded.
