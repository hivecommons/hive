- Historical PR accounting (the merged- and closed-PR enrichment worker that reads each settled PR's merger and reviews) now pauses while the GitHub API budget is in `conserve` or `critical` mode, keeps its queue, and catches up once the budget is back to `normal`; the pause and the resume are each logged once. Before this it kept running a batch every ten seconds whatever the budget said. After a restart the 72-hour settle replay re-queues every recent merged or closed PR, about two REST calls each, and on a hosted hive with 20 repos on 2026-11-07 that replay spent about 400 calls in five minutes while the hourly budget was already under the conserve threshold, helping push it to `critical` and then to an exhausted bucket. Nothing plans, claims or dispatches from this accounting, so delaying it is safe.
