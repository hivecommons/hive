- Report-only per-repo health score on spokes with `search.enabled`: each search index rebuild scores CI pass rate (90d), median time-to-merge, revert/follow-up rate, review verdict mix, stale-issue ratio, sign-off rate, dependency freshness and security-doc rot, and `GET /api/repos/{owner}/{repo}/health` returns the 0–100 weighted score with every component's inputs and `n` so it can be disputed. Components with fewer than 10 samples or no local data are `not_reported`, never zero; weights and ages are tunable under `search.health` (`stale_after` default 60d, `security_doc_max_age` default 365d). The score is never an ACMM input and is not read by merge decisions or Governor priority ([#14638](https://github.com/hivecommons/hive/issues/14638)).
