- Report-only per-repo health score on spokes with `search.enabled`: each search index rebuild scores CI pass rate (90d), median time-to-merge, revert/follow-up rate and review verdict mix from local review evidence, and `GET /api/repos/{owner}/{repo}/health` returns the 0–100 weighted score with every component's inputs and `n` so it can be disputed. Components with fewer than 10 samples or no local data are `not_reported`, never zero; the stale-issue ratio, sign-off rate, dependency freshness and security-doc rot components are always `not_reported` in this release because no local signal source feeds them yet (`search.health.stale_after` and `security_doc_max_age` are accepted but have no effect until one is wired). Weights are tunable under `search.health.weights`. The score is never an ACMM input and is not read by merge decisions or Governor priority ([#14638](https://github.com/hivecommons/hive/issues/14638)).
