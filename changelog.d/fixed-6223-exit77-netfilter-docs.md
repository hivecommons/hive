- The exit-77 documentation now matches what the entrypoint actually does since the #6003 netfilter-module preflight ([#6223](https://github.com/hivecommons/hive/issues/6223)). `manual-provisioning.md`, the standalone overlay README, and the Podman rootful/rootless baseline docs still said exit 77 meant exactly "grant `CAP_NET_ADMIN`" and that every other cause exited 1, so an operator on a node missing `xt_mark` or `xt_REDIRECT` would grant the capability and keep crashlooping. They now describe both causes, the log lines that tell them apart (the module case names the module and never prints `Grant NET_ADMIN`), the node-side `/etc/modules-load.d/` fix, and `net-admin-requirement.md` gains the full check order (binary selection, preflight, real ruleset, fail-closed decision) with which tests and CI lanes exercise each cause.
