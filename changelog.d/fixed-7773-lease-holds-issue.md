- A contributor whose connection drops for between ten and thirty minutes no longer has its in-flight issue handed to a second contributor while it can still resume: the hub now treats an unexpired task lease as a hold on its issue for exactly as long as the lease is re-adoptable, closing the gap between the ten-minute release cooldown and the thirty-minute lease that let both contributors end up on one issue with duplicate PRs. A relay that never returns parks its issue for the lease's length rather than the cooldown's ([#7773](https://github.com/hivecommons/hive/issues/7773)).
