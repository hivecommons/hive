- crux: command log, the fourth work service of the Crux work-services RFC ([hivecommons/crux#114](https://github.com/hivecommons/crux/issues/114) S4). The runtime, not the command, appends a `started` and an `ended` line for every command a contained run dispatches to `<workdir>/runs/<id>/commands.jsonl`. `GET /v1/runs/{id}/cmdlog?since_seq=N&limit=M` (owner or operator) and `crux --server … cmdlog list|show <run>` return one record per command, with its command line, working directory, start and end, exit code, duration, status, output byte counts and the head and tail of each stream, all scrubbed. Each record is marked `capture: "runner"`: commands that a shell or build tool starts inside the sandbox are not listed one by one.
