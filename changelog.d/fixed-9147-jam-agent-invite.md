- Inviting an agent into a campaign Jam thread now actually invokes a model ([#9147](https://github.com/hivecommons/hive/issues/9147)). Previously `POST /api/campaigns/{id}/jam/agents` recorded caller-supplied `reply`/`proposed_text` (or a canned echo of the maintainer's prompt) under agent/model attribution without calling anything. The invite now sends the thread context — ioscan-gated — to the hive reviewer endpoint using the agent's configured model (reviewer model for Spektacular), records only the model's reply and proposed spec text, attributes them to the model actually called, and rejects caller-supplied `reply`, `proposed_text` and `model` with `400`. With no reviewer/LiteLLM endpoint configured the invite fails with `503` instead of posting placeholder text.
