- Fix the task MCP going dead 30 minutes into a remote contributor's task on hives with `task_mcp.remote_enabled`: the per-task MCP token expired with the first task-lease window even though the hub kept renewing the lease, so every task that ran longer got HTTP 403 from its task MCP for the rest of the task. The token now works for as long as the hub's lease on the task is alive, is still refused as soon as the task is released, completed, failed, yanked or its lease lapses, and has a hard cap of 24 hours after assignment.
