- **The `gh` wrapper no longer posts empty or blanked bodies for contributor agents.** A `gh pr create -F -` whose body already closed the task issue, or that targeted a non-default base, opened the PR with the hive footer alone: the auto-close step read stdin and did not hand the body on. The labeled try of `gh issue edit -F -` consumed stdin, so its unlabeled retry blanked the issue. Both now read the body once. The wrapper also refuses a create or comment whose body is empty (`empty_body`), a body that is only an `@path` (`body_file_reference`, gh posts it literally) and an edit that would blank the body (`blanking_edit`), and the auto-close step no longer appends `Closes #N` to a body that says the issue stays open (`Refs #N — partial … remains open`).
