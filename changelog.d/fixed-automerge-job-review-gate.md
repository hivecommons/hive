- `governor.review_gate.mode: enforce` (and `review.require_approval`) now holds on every automerge engine. The 1-minute automerge job built its engine without the review gate, so on its passes the trusted-author lane merged heads an enforcing gate should have held; only the main engine's passes held them ([#19421](https://github.com/hivecommons/hive/pull/19421)). That job's engine now gets the same gate, with the same `review_evaluated` audit line. In the default `shadow` mode nothing merges differently: the job now also records what the gate would have held.
