- An issue parked at `stage/045-needs-decision` is re-checked when the work its park depends on moves: if a PR or issue the park text names merges or closes, or a PR that refers to the issue ("Refs #N", a closing keyword) merges, Hive posts one note listing what changed and keeps it current, so a maintainer does not decide from a premise that no longer holds. The note never un-parks the issue. `/hive approve` on a park that names no recommendation and no options now gets a reply saying so and leaves the issue parked, instead of un-parking it with the decision "go with the recommendation"; with options and no recommendation it records "go with option A: …", as the notice already offered.
