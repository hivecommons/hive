- An owner's approval of a contributor PR that edits `.github/workflows/**` or `.github/actions/**` now survives the hive's own base refresh: when the only commits since the approved head are App-authored merges of the base branch and the PR's diff is unchanged, the workflow-path fence stays released instead of re-arming, so a strict up-to-date branch rule no longer needs a fresh approval every time the base moves. Any contributor push still re-arms it.
