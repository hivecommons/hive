- The spoke dashboard version badge now shows image tracking (`floating`, `pinned`, or `tracking unknown`) beside its linked commit and release channel/build branch ([#6321](https://github.com/hivecommons/hive/issues/6321)). The tooltip includes the validated Deployment image reference. Channel and tracking use one cached server-side lookup and shared upgrade/drift classification, so malformed or unavailable image references cannot invent a pin; failed discovery can recover on later polls. This change targets v5.
