- Fleet report: the Copilot hang detector's repeated `copilot hung with no CLI prompt, running diagnostic` WARNs — a Copilot agent showed no CLI prompt 180 s after launch, so the hive killed its session, ran a bare `copilot` diagnostic and relaunched it — and the diagnostic's own `timed out waiting for copilot error output` WARNs are now classified as `copilot_cli_hung` (medium, component `agent-runtime`), so a hive whose Copilot agents keep failing to reach their prompt files one self-report that names the condition instead of `unclassified_error_repeated` ([#17353](https://github.com/hivecommons/hive/issues/17353)).
