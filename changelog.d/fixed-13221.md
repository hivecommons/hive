- A `backend` hand-set in `hive.yaml` is no longer shadowed on the next start by the pack-owned (`backend_owner: pack`) value a previous ACMM pack apply wrote to the per-agent overlay (`data.agents_dir`) or dashboard overlay; the pack apply then stamps it operator-owned and reports it as `preserved` (#13221). The hand edit is recognised only when the base entry carries no `backend_owner:` line at all — a saved runtime file carries one (`backend_owner: pack` before the first apply, `backend_owner: operator` after it), so delete that line alongside every `backend:` edit.
