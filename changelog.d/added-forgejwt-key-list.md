- `hive forge key-list --issuer https://keys.example.org --key /secrets/forgejo/jwt-signing.pem --out DIR` writes the two static files a Forgejo 17 authorized integration fetches to verify hive's JWTs: `.well-known/openid-configuration` and `jwks.json`. Serve `DIR` at the issuer URL over https. Pass `--key` once per key to publish the old and the new key during a rotation. The command refuses a key file that group or other can read, and never prints the private key. The new `crux/forgejwt` package signs the tokens: RS256, `kid` set to the key's RFC 7638 thumbprint, `iat` 60 s in the past, and `exp` one hour after minting. Nothing reads it from config yet. Refs [#19494](https://github.com/hivecommons/hive/issues/19494).
