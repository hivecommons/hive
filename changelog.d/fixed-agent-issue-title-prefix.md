- Every issue the hive files now starts with its `[<agent>]` tag, with no producer left out: one `issueshape.AgentIssueTitle` function is the choke point for every issue-creation path — `CreateIssue`, the review-backlog, dedupe, hotspot (`[ci-maintainer]`, matching its `agent/ci-maintainer` label), self-report, upstream-watch, advisory and recommendations filers, and the proxy's `gh issue create` — puts the tag first (ahead of any emoji), never doubles it, and a guard test fails any new raw create that skips it. The Activity Monitor draws the tag as a chip ahead of the title instead of repeating it. Existing issue titles are left as they are; dedupe ignores the tag so they still match their tagged successors.
