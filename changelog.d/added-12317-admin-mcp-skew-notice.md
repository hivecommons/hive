- The stdio `hive-admin-mcp` binary now warns when it is out of step with the hub ([#12317](https://github.com/hivecommons/hive/issues/12317), part of [#12316](https://github.com/hivecommons/hive/issues/12316)). At startup and on `select_hive` it reads the active hive's `/api/version`; when the short SHAs differ it sends a one-line notice naming both builds and the update steps in `src/docs/admin-mcp.md` as the `initialize` instructions, and appends it to `unsupported admin MCP read tool`, `unknown tool` and hub 404 errors. Previously a stale binary failed new tools with no hint that it needed re-extracting or rebuilding. Nothing changes when the builds match or either SHA is unknown. The binary also identifies itself with `User-Agent: hive-admin-mcp/<version>+<short sha>`, and hivectl's client User-Agent is now configurable.
