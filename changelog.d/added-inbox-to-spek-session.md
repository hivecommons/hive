- Inbox: **🔗 Share ▾ → Hive → spek…** sends one recording, or a selection, into a new or running Inception (spek) session. The hive writes each item to `.hive/inbox/<source>-<id>.md` in the session's workspace (as the session's user, mode 0640, inside the untrusted-data envelope with provenance outside it), queues a fixed Send that asks the CLI to start a spec from those files with the spek-new skill (it names only the files, never the recording's text), opens the session's tab and marks the item `routed: session/<id>`. API: `POST /api/sessions/{id}/seed` and `seed_items` on `POST /api/sessions`, audited as `inbox_to_session`. An item that already has a machine transcript no longer also shows the source's "not transcribed yet" line.
