- Dashboard: the infinite "pulse" indicators (working-agent dots, status dots, stale agent cards; the activity monitor chevrons are handled separately) now animate only `opacity` on an overlay instead of `filter`, `box-shadow` or `border-color`, so they run on the compositor thread. An idle dashboard tab with the activity monitor open was spending ~70% of a CPU core re-styling, painting and layerizing the whole page every frame; measured with ~70k DOM nodes and 113 running animations, animations accounted for the bulk of main-thread time. Knowledge-base fact cards also use `content-visibility: auto`, so the thousands of cards scrolled out of the 500px list no longer get laid out and painted.
