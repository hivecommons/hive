- The hub orphan sweep no longer abandons an upgrade 20 minutes in when the spoke is alive, still on its old build and reports no drain: a spoke on a build that predates drain reporting drains in-flight kicks silently for the default 45-minute window, and clearing the latch there left the instruction only in memory, so the next merge-driven hub restart lost it and daily-window `:stable` hives missed every window. The latch is now held for the default drain window plus the usual grace, which keeps re-delivery alive across hub restarts ([#14856](https://github.com/hivecommons/hive/issues/14856)).
