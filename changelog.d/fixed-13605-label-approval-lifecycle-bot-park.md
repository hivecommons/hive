- Label-driven approval no longer deadlocks on a lifecycle bot's park label: a repository can list automation accounts in `label_driven_supersede_park_actors` (project-wide or per repo) so that a trusted `triage/accepted` added after such a bot's `needs-human` removes it, says so in the release comment, and releases the issue; park labels added by people, by unlisted bots, or by a listed bot after the acceptance still block, `hold` is never superseded, and the list is empty by default ([#13605](https://github.com/hivecommons/hive/issues/13605)).
