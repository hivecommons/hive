- Claude credential bridge: on a per-UID hive the hive server cannot read the private `0600` file an agent's token refresh leaves in place of its credential link, and the repair took that read error for "no token". It moved the agent's fresh token aside and relinked the agent to the shared login, whose grant the refresh had just rotated, so Claude agents logged out about 8 hours after each sign-in. At launch and on the credential watchdog, the repair now leaves a private file it cannot read where it is and logs one WARN per agent and file version with the path and errno; the agent keeps its private copy until the file is readable or the operator signs in again. The repair that follows a dashboard sign-in still moves such a file aside and relinks the agent, because the new shared login is newer than any private copy. `claude.WriteCredentials` now refuses a credential with no access token (#17253, #17590).
