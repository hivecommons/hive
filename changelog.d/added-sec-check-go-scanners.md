- **sec-check now ships and runs `govulncheck` and `gosec` in the agent image.** The policy used to tell the agent to scan with trivy, semgrep or grype "as available", none of which exist in the pod, so the scan step silently degraded to the Dependabot API. `src/Dockerfile` now builds govulncheck v1.1.4 and gosec v2.29.0 (named build args matching `go-security-analysis.yml`) in a builder stage and copies the static binaries into the runtime stage. The `sec-check-full` and `sec-check-holdgated` policies (and their `src/policies/` mirrors) run them on Go targets with CI-aligned thresholds (reachable govulncheck results and HIGH/HIGH gosec issues are findings, the rest advisory), forbid the agent from installing scanners itself, and no longer name trivy, semgrep or grype. ([#18192](https://github.com/hivecommons/hive/issues/18192))
