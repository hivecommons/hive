- The Crux module ships its own `crux` binary, `src/crux/cmd/crux`, buildable from the nested module alone (`cd src/crux && make build`, or `GOWORK=off go build ./cmd/crux`) with the same `run`, `ps`, `logs`, `kick`, `stop` and `serve` verbs, `--server` / `CRUX_SERVER` remote mode and a `--version` flag. It loads agent definitions from plain YAML files with the new `crux/defs` package (`--defs <dir|file>` / `CRUX_DEFS`: portable `kind: AgentDefinition` documents or bare per-agent overlays); the root `cmd/crux` stays as a thin host that reads `hive.yaml`. `src/crux/Makefile` adds `build`, `test`, `vet` and `smoke` (starts `crux serve` on a private socket and drives it over the API), which CI runs; `src/crux/README.md` documents the module ([#14138](https://github.com/hivecommons/hive/issues/14138)).
