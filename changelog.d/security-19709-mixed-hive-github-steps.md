- On a hive with repositories on GitHub and on another forge, the eval cycle's GitHub-client steps no longer act on the other forge's pull requests. Review-thread collection, PR follow-up resume (its branch updates and stale-head notes), linked-issue title lookups and the hold guard's held-branch upkeep now see only GitHub PRs. The hold guard no longer reads commits, gate-lift provenance or self-authorization history for a non-GitHub PR from a same-named GitHub repository, so that repository can no longer clear a drifted hold. A moved head on such a PR fails closed into the drift path, and its notice still goes through the PR's own forge. GitHub-only hives behave exactly as before. Fixes [#19709](https://github.com/hivecommons/hive/issues/19709).
