- Fixed the chrome-idle fallback ending live tasks that were still producing output (kubestellar/hive#6775). `recordChromeIdleTick` now requires the pane to be byte-identical between consecutive credited IDLE_COMPLETE ticks; a pane whose bytes moved between ticks cannot be idle, whatever `classifyPane()` read about any single frame. The observed case was pi rendering progress as `\d+\.\d+%`, which the classifier's `pi` branch matches against both `hasIdlePrompt` and `hasCompletionMarker` while its narrow verb list finds nothing to catch on — three such frames in a row used to end a task in flight with `signal=chrome_idle`, no `HIVE_VERDICT` and no PR. The stability gate is orthogonal to the #6733 activity check (which asks whether the agent ever DID something) and to the #6730 hub-side demotion (which downgrades an evidence-less `chrome_idle` completion): together they close the fallback in three independent directions.
