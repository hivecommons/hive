- The selfreport slog feed no longer files `unclassified_error_repeated` issues for the expected, self-healing "continuous re-kick backed off after failed kick" warning (for example a backend CLI slow to reach its input prompt); it is now recognised by the `kick_failed_repeatedly` class keywords, which only reports after the restart recovery fails ([#13732](https://github.com/hivecommons/hive/issues/13732)).
