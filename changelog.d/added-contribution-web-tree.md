- `hivectl hives web` now renders a Hub → Hive → Repository contribution tree with staged *Apply* and truthful receipts. The loopback Commons page shows every configured hub, the hives it offers and their repositories as an accessible, keyboard-driven tree with tri-state checkboxes; edits (select/deselect current, follow new repositories, enable/disable, exclude/clear exclusion, legacy *Review and restrict*, hub enable/disable) are staged in the page and written only on *Apply*, which lists the complete diff — exclusion effects, branches shared across hubs, legacy conversions — then reports *Saved* / *Relay reload* / *Acknowledged* separately so a saved-but-not-yet-adopted change is never shown as live. Apply reuses the shared `profiles.yml` lock and expected-revision check, so edits made by `hivectl` or the TUI since the page loaded return `409` with a fresh tree instead of being overwritten, and discovery outages are labelled per branch rather than rendered as an empty hive. Refs #13153.
