- An @-mention that arrives while its target agent is still starting up is now queued and delivered once the agent is up, instead of being silently discarded when a governor cadence kick lands in the same startup window. Mention and action kicks go into a small per-agent FIFO (deduped by source, capped at 8) that a later cadence kick can no longer evict; the oldest queued mention is typed at startup and any leftovers replace later governor cadence kicks only — one-shot kicks from other callers (planning, dashboard, hooks, restart-with-message) are always delivered as sent. A queued mention is dropped only on FIFO overflow or when the agent is stopped; both are audited and report `kick-dropped`, so the mention store no longer keeps a stale pending entry and 👀 ack (#12982, #13055).
