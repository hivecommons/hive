- **The repeated-failure check now sees commands run by openhands agents** ([#14748](https://github.com/hivecommons/hive/issues/14748), part of [#14550](https://github.com/hivecommons/hive/issues/14550)): with `repeat_failure.enabled` on, Hive reads the conversation events the OpenHands CLI saves under `~/.openhands/conversations` and records each finished `terminal` command with its exit code (route `openhands_events`), writing nothing into OpenHands' files; openhands is marked covered with a committed, re-runnable real-CLI harness (OpenHands CLI 1.16.0).
