- `hive-baseline-check.sh` can reach a shared-CI verdict again from inside an agent session ([#11608](https://github.com/hivecommons/hive/issues/11608)). Its sibling-PR lookup used `gh pr list`, which the agent `gh` wrapper refuses for staff agents, so every run ended in "could not read open PR checks", every failing PR landed in the unknown bucket, and `DEFER_TO_INCIDENT` / `RERUN_BASELINE` were never reached — shared CI breakage was handed out as one repair target per PR. The helper now lists open PRs with a read-only REST `GET repos/<repo>/pulls` and reads the exact named check per PR head (check runs first, commit statuses only when no check run carries the name); an unreadable sibling still makes the verdict unknown rather than PR-local.
