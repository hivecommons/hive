- RFC notices in rich mode (`rfc_format: card` or `rfc_threads: true`) now announce open-decision count changes (at most one per RFC per 30 minutes), target and status changes, and an added `stage/045-needs-decision` or `needs-human` label into the RFC's thread. A retitle edits the card and renames the thread instead of posting. A same-author RFC with the same title within an hour gets no card, only one note in the first RFC's thread. Line mode is unchanged.
