- krun mode (`HIVE_CONTAINER_OCI_RUNTIME=krun`) now accepts interactive launches, so interactive-only backends such as `omp` can run in the microVM: the contributor container gets a TTY, the session is shown on the VM console, and the recipe prints `podman attach <container>` and the detach keys (Ctrl-P Ctrl-Q) instead of an `exec` command or tmux hint, because the krun handler refuses `podman exec`. Headless krun launches are unchanged, and krun still never falls back to a plain container, docker or local mode (#12202).
