- **Spektacular hub executor hardening (#10104, #10095, #10100, #10130, #10098):** the per-generation CLI log is capped at 32 MiB and `/api/runs/{key}/log` reads only the last 4 MiB; run artifact slugs are capped at Spektacular's 64-character name limit so `spec new`/`plan new` no longer fail for long repo names; `file list` and workdir-resolution errors are surfaced instead of swallowed; and `PUT /api/config/governor/features` rejects `spektacularInterview` values other than `auto`/`human` instead of silently storing `human`.
