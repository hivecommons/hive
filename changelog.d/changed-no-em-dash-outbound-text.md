- **Hive no longer writes em-dashes into anything it sends.** Text that leaves the hive for a forge (PR and issue titles and bodies, issue and review comments, and the commit message of a re-authored signed commit) now passes through one shared filter, `pkg/prosefilter`, that turns an em-dash, and an en-dash used as a dash, into a plain hyphen. Fenced code blocks, inline code and quoted lines are left untouched. The attribution trailer hive appends to PRs and issues now starts `-- hive:` instead of with an em-dash; readers still recognise the old spelling on existing PRs. The level-hold notice, the reporter-trust hold reason, the contributor-relay footer and the contributor prompt's trailer instruction are reworded the same way, every agent kick carries a one-sentence "no em-dashes" rule, and a ratchet test (`TestNoNewDashesInEmittedText`) fails when a new em-dash appears in the strings hive emits.
