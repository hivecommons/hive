- Sentinel's `remote_code_execution` rule no longer flags local `bash -c` test runners, `sha256sum -c` or plain `chmod 755 /path` ([#18957](https://github.com/hivecommons/hive/issues/18957)). The `subprocess ... -c` alternative was removed (a fetch or decode inside the string is still caught by the curl/wget/base64 alternatives) and `chmod` now matches only setuid/setgid modes, so PRs with these ordinary lines stop parking behind `sentinel-alert` until a maintainer clears them.
