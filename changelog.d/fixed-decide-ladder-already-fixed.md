- **Let hive decide** no longer adopts a contributor PR whose issue another merged PR already fixed: it closes the PR as superseded naming the merging PR and commit (recommend-only while the repo is paused), hands a mergeable green head to the merge gate, nudges a connected author, and only then adopts; the decide response carries `decision`, `reason` and `ruled_out`, and the text says "the author's clanker", "the author's hive" or "the author" to match who relays the PR ([#15289](https://github.com/hivecommons/hive/issues/15289)).
