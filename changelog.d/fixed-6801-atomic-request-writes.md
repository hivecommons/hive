- fix(github): stop agent request watchers from permanently losing valid requests (#6801). Request and result files were published with `os.WriteFile`, whose `O_CREATE|O_TRUNC`-then-write leaves the final `*.json` name holding zero bytes; a watcher tick landing in that window read an empty file and renamed it to `.bad`, destroying the request with no retry. Writes now go to a scanner-invisible `*.json.tmp` and are `rename(2)`d into place, and watchers no longer quarantine a file that is empty or was modified within the last few seconds — the queues are drop-boxes, so a torn read must be retried rather than treated as malformed.
