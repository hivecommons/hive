- `hive-open-pr` now corrects a PR-title emoji that contradicts the Conventional Commits type (`📝 docs: …` → `📖 docs: …`, `📖 fix: …` → `🐛 fix: …`) before the PR is opened, the agent instructions spell out the convention (✨ feature, 🐛 fix, 📖 docs, 📝 proposal, ⚠️ breaking, 🌱 chore) and the review-priority classifier names 📝 as the proposal emoji, so a hive-authored docs PR no longer fails the repository's required `PR Type` check on the emoji swap.
