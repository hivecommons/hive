- The adjudicator can now hand an escalated pull request to a maintainer ([#13183](https://github.com/hivecommons/hive/issues/13183)). Previously its contract offered only REPAIR, DE-ESCALATE and RECOMMEND-CLOSE, so when a PR was fine but needed a maintainer-only action (for example dispatching a workflow with `rebuild_akmods=true`) the agent improvised an unrecorded "HOLD", and the dashboard kept the PR in "waiting on someone else" with an empty reason for four hours before blaming the adjudicator for not acting. The reviewer lane now has a fourth verdict, HAND-OFF: the audited comment starts with a single `**Next step for a maintainer:**` line and the PR gets the `reviewer-handoff` label (needs-human stays). The dashboard makes such a PR your turn immediately with reason code `adjudicator_handed_off`, adjudicator-wait rows now say "Waiting for the adjudicator (escalated 14:32Z); your turn at 18:32Z if it doesn't act", and the timeout reason reads "Escalated over 4 hours ago and no verdict Hive recognises was recorded".
