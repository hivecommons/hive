- `crux serve --listen` now refuses a non-loopback bind (`0.0.0.0`, `::`, `:port`, or a remote address) even when a bearer token is set, and `crux/api.ParseAddress` refuses `http://` or bare `host:port` for a non-loopback host: the TCP listener is plain http, so the token would otherwise cross the network in cleartext. Expose the API remotely through a TLS-terminating proxy that dials the loopback listener, or reach it with `https://`. The shared rule is `api.LoopbackHost`.
