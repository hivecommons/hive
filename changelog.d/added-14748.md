- The repeated-failure check now has a record route for `aider` agents ([#14752](https://github.com/hivecommons/hive/issues/14752)): aider runs each command in an interactive `$SHELL -i -c`, which ignores `BASH_ENV`, so while `repeat_failure.enabled` is on Hive replaces the agent's `~/.bashrc` link (Hive-managed per-agent homes only, never contributor local mode) with a per-agent file that sources the shared rc file plus a guarded line loading the route script, and exports `SHELL=/bin/bash`; turning the check off restores the link at the next launch. The coverage table now records why `openhands` ([#14748](https://github.com/hivecommons/hive/issues/14748)) and `muse` ([#14749](https://github.com/hivecommons/hive/issues/14749)) stay not covered: Hive has no launch or hook wiring for either and writes none of their settings files.
