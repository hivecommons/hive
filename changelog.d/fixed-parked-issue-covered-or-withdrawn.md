- A parked issue no longer stays in the owner's your-turn queue after the hive has answered it ([Danathar/openaudible-autoupdate#177](https://github.com/Danathar/openaudible-autoupdate/issues/177)). A decision park (`stage/045-needs-decision`) that an open or held PR authored by the hive's App closes now reads "Waits on hive PR #N, which closes it" instead of `DECIDE`; the park label stays, so the ask returns if the PR closes unmerged, and a closing PR from anyone else leaves it your turn. The agent that parked an issue can also take the ask back with `hive-open-issue comment <n> --withdraw-decision`: the relay checks that the newest Hive park text is that agent's, that the park is a decision and not `needs-human`, then posts the comment with a `<!-- hive:park-withdrawn by=<agent> -->` marker, lifts the park through the stage engine (040 when an open PR covers the issue, else 010) and deletes the "What to reply" notice, which until now kept recommending the option the agent had withdrawn. All lane policies tell agents to withdraw a park whose question has gone away.
