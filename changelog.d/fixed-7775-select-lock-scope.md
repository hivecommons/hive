- The hub no longer holds its fleet-wide task-selection lock while it talks to GitHub ([#7775](https://github.com/hivecommons/hive/issues/7775)). Minting a contributor's scoped token and looking up its push permission used to run inside that lock, so every other contributor's `ready` waited on one contributor's GitHub latency; a contributor queued there stopped reading heartbeat pongs, was disconnected as timed out, and had a task assigned to its dead socket — which the disconnect path then "released", booking a cooldown on an issue nobody worked. The lock now covers only the in-memory claim, and a claim whose token mint or `task_assign` send fails is rolled back in full (no lease, no rate-window slot, no cooldown), so the issue is offerable again at once.
