- `crux serve` exposes the agent runtime over a local HTTP+JSON API (Crux Stage 3, [#13536](https://github.com/hivecommons/hive/issues/13536)): a unix socket (`$CRUX_SOCKET`, default `$XDG_RUNTIME_DIR/crux/crux.sock`, created 0600) and optionally TCP with `--listen`, which is refused without a bearer token (`--token` / `$CRUX_TOKEN`). The routes under `/v1` mirror the CLI verbs — list, get, run from a definition, logs (pane, buffer, full, or followed as SSE), kick, stop — plus an SSE event stream of starts, stops, kicks and observed state changes. The wire contract is the stdlib-only `crux/api`; the server is `crux/serve`.
