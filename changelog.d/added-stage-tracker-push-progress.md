- Stage tracker PR rows now carry push progress from the stage record ([#15784](https://github.com/hivecommons/hive/issues/15784)): `waiting_push_since` (when a 071 / 072 wait on the author began), `last_push_at` / `last_push_sha` (recorded from the webhook re-read after a `pull_request` synchronize, with the enumeration's head change as a fallback) and `pushed_since_waiting`, so the dashboard can tell a contributor who pushed from one who has not.
