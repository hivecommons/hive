- A `pull_request` webhook now records the issues the PR claims (`Fixes #N`, branch name, references) into the duplicate-PR claim ledger and filters the cached actionable snapshot on the event, releases them when the PR is edited to drop them or closes unmerged, and converts them to merged claims on merge; the dispatch gate also refuses an issue the confirming read says is closed. Before, the PR→issue link was only made on the full reconcile pass (~1h apart on a busy spoke), so an owner PR opened with `Fixes #N` between passes left #N offerable and the `/contribute` lane handed it to a contributor minutes later ([#14814](https://github.com/hivecommons/hive/issues/14814)).
