- Made the contributor quota reading publisher default-on for supported subscription backends (kubestellar/hive#6987, #6967 criterion 1): the Go rotation probers and the JS relay now derive a per-install pool directory (`$XDG_CONFIG_HOME`/user-config-dir → `hive/contributor-quota`) when `HIVE_CONTRIBUTOR_QUOTA_POOL_DIR` is unset, so a default install of a supported backend gets a real reading with no hand-configured env var. An explicit `HIVE_CONTRIBUTOR_QUOTA_POOL_DIR` still overrides the location. A missing default reading stays `unprovisioned`/admit (non-stranding) and only a present-but-unhealthy reading holds; the `unprovisioned`→hold flip is deliberately not shipped here so default installs cannot hold forever, and unsupported backends are unchanged.
