- Issue-claim side effects on GitHub (the `stage/020-claimed` write, the claimed-by / preempted labels and their removal on release) now retry transient failures — timeouts behind the per-repo label writer, network errors, rate limits, 5xx, or a journaled attempt whose outcome was uncertain — up to four times with a doubling pause, instead of giving up after one 15s attempt and leaving an issue an agent is already working at `stage/010-actionable`. Claim, takeover and release comments are still posted once, so a timed-out comment is never duplicated (hivecommons/hive#14766).
