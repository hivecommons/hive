- A pack agent that an ACMM level adds to a hive whose operator moved their agents onto one inference gateway (e.g. the L2 `reviewer` on a LiteLLM hive) now joins that gateway with its default model instead of the pack's Copilot CLI, and a pack-owned agent that already exists on a CLI — or on a gateway the hive has since moved off — is moved there on the next restart. The gateway is the one every operator-picked backend names, provided the agents already on it are a majority of the other enabled agents; pack-owned CLI agents such as the L2 `supervisor`/`brainstorm` do not veto the move and follow it, and once moved they count toward that majority so the next level's agent (the L3 `ci-maintainer`) follows too. A hive with an operator-picked CLI agent, or with only a minority of agents on a gateway, is left as is, and an operator-owned or legacy unowned `backend:` is never moved (#14678).
