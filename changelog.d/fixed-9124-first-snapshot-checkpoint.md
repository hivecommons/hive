- The chat bot now announces a run that is already waiting on a human approval the first time it sees it — including right after a restart — instead of silently treating it as the diff baseline ([#9124](https://github.com/hivecommons/hive/issues/9124)). A bare `approve`/`reject` sent when no checkpoint is tracked for the author now gets an explicit-form hint (`!runs approve <key>` / `!runs reject <key> <reason>`) instead of no reply at all.
