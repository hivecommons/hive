- Dashboard GitHub login requests **no** OAuth scope again — #11051 had switched the device flow to `public_repo`, which pushed every viewer through GitHub's "read and write repository data" consent page just to look at a hive. Dashboard feedback no longer files the issue with any hive-held credential: the hive stores the diagnostic bundle on a `hive-feedback` branch using its GitHub App installation token and opens a prefilled `issues/new` page (summary ≤ 6 KB plus a link to the bundle) that the user submits as themselves. Operator PATs still never author feedback. A source-level guard test keeps the login path scope-free ([#1927](https://github.com/hivecommons/hive/issues/1927)).
