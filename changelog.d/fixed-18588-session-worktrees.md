- Each Sessions pane now opens in its own git worktree of the hive's one shared clone (`<workspace>/.sessions/<id>/<org>/<repo>`, branch `hive-session/<id>`) instead of the shared checkout itself, so two people running different specs on the same hive no longer see, block or discard each other's Spektacular workflow, and a branch switched in one session no longer moves the others; deleting a session removes its worktree after committing any uncommitted work onto its branch (kept when the clone's `HEAD` lacks it), and the session sweep removes worktrees of deleted sessions ([#18588](https://github.com/hivecommons/hive/issues/18588)).
