- The push broker's outgoing-diff gate now consults every exact-shape credential pattern `logscrub` knows — the hive canary marker, GitHub tokens, JWTs, AWS access keys, Slack and Discord webhook URLs, Slack tokens and private-key blocks — through the new `logscrub.FindSecret`, instead of only the GitHub-token/JWT `TokenPattern`. A committed AWS key, private key or planted canary used to be brokered and published; it is now refused, and the error names the category (`contains a private-key-shaped secret`) without echoing the value. The heuristic shapes `ScrubString` masks in logs (`sk-…` keys, `Bearer …`, `Basic …`) stay out of the gate because they match fixtures and documentation too readily to block a push on (#16966).
