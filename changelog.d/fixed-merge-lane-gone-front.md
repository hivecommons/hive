- Serialized merge lane: a front pull request that is closed, merged outside the lane, turned into a draft or retargeted now leaves on the next automerge sweep pass, with a `front check: …` exit reason, and the next waiting pull request is promoted. The sweeps list open pull requests only, so no merge path ever called in for such a front again and it held every waiter until the front timeout (up to four timeouts when its checks were last seen pending). Each pass now reads every front of a `hive-serialized` repository once; open fronts are unchanged.
