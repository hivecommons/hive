- The scanner, issue-request watcher and `/contribute` relay lane no longer dispatch an issue an open pull request already fixes: a live open-PR check (`scanner.skip_issues_with_open_pr`, default on) skips the claim, labels the issue `has-open-pr` and logs `claim skipped: open PR already linked`; and a duplicate-fix sweep resolves two open PRs fixing one issue without an owner decision — the earlier green/pending PR stays, the later hive PR is closed as `duplicate-of:<keeper>` with one comment, a person's later PR is commented on and left open, and only an earlier red/stale PR facing a later green one is escalated to `stage/085` ([#14799](https://github.com/hivecommons/hive/issues/14799)).
