- Make the shared Jam store (`campaign-jam.json`) write crash-durable: the temp file is now fsynced before it is renamed over the store, and the directory after, so a power loss can no longer leave a zero-length store that fails every campaign's Jam. Each write uses a unique temp file that is removed on any failure, instead of a fixed `campaign-jam.json.tmp` that a failed write could leave behind (#10083).
