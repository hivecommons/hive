- A red check run another PR produced on a shared head no longer counts against a PR. projectbluefin/utah-packages#890, an in-repo copy of the fork PR #878 at the same SHA, went to `stage/072-returned-to-contributor` for "Failing checks: Canary" on #878's fork Canary run, 41 seconds after it opened and before its own Canary had started. Check runs are now attributed by PR: a run naming other PRs, or a run naming none whose workflow run had a different head repository or branch (the branch alone for another app's suite), is not this PR's. Failed lookups keep the run.
