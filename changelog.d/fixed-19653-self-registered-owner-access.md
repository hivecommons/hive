- **A self-registered spoke's heartbeat-reported owner can no longer grant hub access** ([#19653](https://github.com/hivecommons/hive/issues/19653)). The registry Owner comes from the spoke's own unverified heartbeat, so the access handlers now treat a self-registered spoke as having no owner. Only the hub admin and users holding a stored `owner` grant can grant, revoke or approve access on it; hosted hives are unchanged.
