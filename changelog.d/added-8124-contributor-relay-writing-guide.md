- `project.writing_guide` now reaches the contributor relay's task prompt, so an owner who sets a guide gets it on the PRs contributors open for their repos and not only on the PRs their own agents file ([#8124](https://github.com/hivecommons/hive/issues/8124), extending [#7667](https://github.com/hivecommons/hive/issues/7667)). The relay's prompt is built in Go rather than from a policy file, so it never expanded `${WRITING_GUIDE}`; it now takes the rendered guide from the assigning hub and places it immediately before the instruction to open the PR — the same position that made the setting work on the template path, next to the step that writes the body it governs. The guide belongs to the hive that owns the task, so a relay subscribed to two hives gets each hive's guide on that hive's tasks. A hive that sets no guide ships a byte-identical prompt.
