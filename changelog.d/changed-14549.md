- The retro lane now counts repeat lessons instead of discarding them (#14549). When a new retro lesson matches an existing approved or draft retro lesson, the existing lesson records the new source bead and PR in a bounded `sources:` list (newest 20), increments an `observations:` count (older lessons count as 1), and raises its stored confidence by `retro.lesson_confidence_step` (default 0.05) up to `retro.lesson_confidence_cap` (default 0.9), so recurring lessons rank above one-offs. Only those fields change — body, lifecycle state and other front matter are preserved, superseded/deprecated lessons and non-retro facts are left untouched, and a repeat from an already recorded bead is ignored. Repeats on a remote project knowledge layer are skipped and logged. See `src/docs/retro-lane.md`.
