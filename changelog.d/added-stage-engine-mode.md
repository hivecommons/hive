`governor.labels.stage.engine.mode` (`off` / `shadow` / `enforce`, default `shadow`; Settings → Labels) switches the ADR-0025 central stage engine at runtime: one reconciler shared by the issue and PR sweeps, `off` = legacy pass-through, `shadow` = count disagreements, `enforce` = engine writes. `/api/status.stageEngine`, the activity tracker's status strip and `hive_stage_*` series on `/metrics` report mode, derivations, mismatches and anomalies. Rollout runbook in operator-reference.md. (#13010)
