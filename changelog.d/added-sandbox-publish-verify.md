- Sandboxed kicks gained a deterministic publish preflight that does not trust the agent's report: `sandbox.publish.verify` (per agent) or `agent_sandbox.publish.verify` (global) lists shell commands hive runs in the same sandbox image/workspace after the run (with `HIVE_CHANGED_FILES` / `HIVE_CHANGED_TESTS` exported), and the first non-zero exit withholds the push and the PR with the command's output tail on the card (`no PR opened: verify failed (1/2): uv run pytest --collect-only -q (exit 2) …`) and in the kick log. A whole-suite `pytest --collect-only` there would have stopped a test-gap PR whose new test file's basename clashed with an existing one and broke collection for every CI shard.
