- A contributor relay running on a fine-grained personal token, the kind the start-up warning and `contribute-setup` recommend ([#18238](https://github.com/hivecommons/hive/issues/18238)), now gets the fork workflow on every repository the contributor does not own. The hub chose between pushing upstream and forking from what the contributor's account could write, so a maintainer following that advice was told to push upstream, and every push failed with 403. The relay declares the new `fork_only_token_v1` capability when its token carries no `X-OAuth-Scopes` header; older hubs ignore it. Setup now also says to fork a repository once before its first task.
