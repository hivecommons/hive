- `crux serve` exposes the watchdog fleet ([#14138](https://github.com/hivecommons/hive/issues/14138), stage 3): `GET /v1/watchdog` lists the agents the watchdog reconciles, `GET /v1/agents/{name}/watchdog` returns one agent's observation (pane verdicts, auth, pause state, last production), and `PUT`/`DELETE /v1/agents/{name}/watchdog/conditions` publish or clear its conditions. `api.Client` has the matching `WatchdogAgents`, `WatchdogObserve`, `SetWatchdogConditions` and `ClearWatchdogConditions` methods. A parity ratchet now checks that every `crux.Runtime` method and CLI verb has an API route, or is on an explicit allowlist of families that have not landed yet.
