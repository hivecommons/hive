- Spektacular hub executor hardening: the hub-launched agent CLI no longer inherits the hive process's inheritable/ambient capabilities (it is started through `setpriv`, and the stage is refused when that is not possible) ([#10054](https://github.com/hivecommons/hive/issues/10054)); it now receives the proxy CA paths `NODE_EXTRA_CA_CERTS`/`GIT_SSL_CAINFO` so proxied Copilot/Claude TLS works ([#10076](https://github.com/hivecommons/hive/issues/10076)); clone credential files left behind by a hub that died during clone/fetch are removed by the executor sweep after an hour ([#10109](https://github.com/hivecommons/hive/issues/10109)); and the prompt/log writes and stage transcript capture no longer follow symlinks in the worktree, with captured documents scrubbed like CLI output ([#10078](https://github.com/hivecommons/hive/issues/10078)).
