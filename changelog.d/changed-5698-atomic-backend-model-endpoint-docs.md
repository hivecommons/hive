- Documented `PUT /api/config/agent/{name}/models` as the path to use when changing an agent's backend **and** model together, and why doing it as two calls is a live footgun ([#5698](https://github.com/kubestellar/hive/issues/5698)). `POST /api/switch/{agent}/{backend}` followed by `POST /api/model/{agent}/{model}` has no transaction across the two requests: if the second fails, times out, or is never made, the agent is left holding the new backend and the previous backend's model. The docs now spell out that the atomic route applies the pair in one request, does not restart the agent, and still has the phase-2 model-validation gap called out by the RFC.
