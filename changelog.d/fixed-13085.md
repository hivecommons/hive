- An owner's `/hive approve` reply (or a trusted merger's approving review) posted after the review swarm's `requires_human` verdict now releases a contributor-lane PR, including one the owner opened under their own login, the same way it already did on the self-authored lane. The release is written to the same `review-hold-releases.json` ledger, so the PR leaves the dashboard's "your turn" inbox and `stage/085-needs-decision` instead of sitting there with no command able to clear it. Only a trusted merger's release counts on that lane. The merge-request relay agents use to land PRs now also refuses a PR whose latest decisive review verdict is `requires_human` or `reject` until a trusted merger has released it, so an agent can no longer merge a PR past a verdict that says it will not merge unattended ([#13085](https://github.com/hivecommons/hive/issues/13085)).
