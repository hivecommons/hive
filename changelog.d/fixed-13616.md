- Queuing a PR for auto-merge with the default `lgtm` label now also sets the `prow/lgtm` commit status on the approved head commit, so repos running prow-github-actions v3 no longer strip the label and silently drop the PR from Hive's merge queue ([#13616](https://github.com/hivecommons/hive/issues/13616)). If the status can't be written (the App needs `statuses: write`), Hive logs a warning and comments on the PR; other labels such as `hive/auto-merge` are unaffected.
