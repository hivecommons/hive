- Sentinel now honours a maintainer's removal of `sentinel-alert` on a head it never alerted on: when the label was removed by a non-Hive human after the current head was pushed (a rebase between the alert and the review), the current head counts as cleared, the marker comment is rewritten for that head so the clearance survives a restart, and the label is not re-applied; a push after the removal still re-alerts. The push time is read only from signals GitHub stamps server-side — the `head_ref_force_pushed` event for the head, or the earliest check suite / commit status created for it — never from the commit's committer date, so a backdated commit cannot ride a stale clearance; a head with no such signal is re-alerted as before ([#13602](https://github.com/hivecommons/hive/issues/13602)).
