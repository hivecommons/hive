- The hub's per-hive dropdown menu now has a **⏸ Pause hive** / **▶ Resume hive** item for the hive's owner (or a hub admin) ([#15092](https://github.com/hivecommons/hive/issues/15092)). It drives the same fleet breaker as the spoke's own top-bar ⏸ button: `POST /api/saas/hives/{id}/breaker` queues the request and the spoke applies it on its next heartbeat, so a spoke can be paused without opening its dashboard.
