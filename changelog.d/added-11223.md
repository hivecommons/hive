- The watchdog's "alive but not producing" dashboard warning now names what is queued ([#11223](https://github.com/hivecommons/hive/issues/11223)). The existing text stays as the prefix, followed by "hive-wide" (the count is the governor's hive-wide queue, not that agent's own) and up to three queued items as `owner/repo#N` links to the forge, with "+N more" for the rest — so an operator can open the waiting issue or PR straight from the banner instead of hunting for it across repos.
