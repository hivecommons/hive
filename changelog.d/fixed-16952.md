- `native-queue-policy` no longer spends its ~22-minute evidence wait on label flips it never reads (`size/*`, `dco-signoff`, `hive/claimed-by-*`, `copilot`, stage labels); instead it replays the latest successful `native-queue-policy` run on the same head rather than fabricating a pass, still applies the live hold/draft/head-move check, and falls through to the full exact-head evidence wait when there is no prior success to replay (the head was never evaluated, or the last wait failed or timed out) or GitHub returns a 5xx, so a stale red verdict is never pinned onto later cosmetic flips. Flips of `hold`, `needs-human`, `release-in-progress` and `do-not-merge` always run the full wait ([#16945](https://github.com/hivecommons/hive/issues/16945)).
