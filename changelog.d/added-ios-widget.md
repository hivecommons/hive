- iPhone Home Screen widget for a hive (`src/contrib/ios-widget/hive-widget.js`, docs in `src/docs/ios-widget.md`): open issues, open PRs, actionable issues and actionable PRs, each with a sparkline; small, medium and Lock Screen sizes; tap opens the hive. Runs in Scriptable and authenticates with a GitHub token through the hub's existing bearer auth-check, so no spoke or hub change is required.
