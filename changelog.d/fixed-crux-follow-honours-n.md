- `crux serve` now honours `n` on `GET /v1/agents/{name}/logs?follow=1`, replaying only the last `n` buffered lines (none for `n=0`) before streaming, and `crux --server ADDR logs -n N -f` sends it, so the follow no longer prints the whole 200-line window regardless of `-n`; without `n` the replay is unchanged ([hivecommons/crux#70](https://github.com/hivecommons/crux/issues/70)).
