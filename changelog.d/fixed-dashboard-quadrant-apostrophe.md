- The hub dashboard stuck at "Loading your hives..." for every signed-in operator after the Fleet quadrant column shipped: the Quadrant header's tooltip text contained a bare apostrophe ("the hive's own evidence") inside a single-quoted JavaScript string, which ended the string early and failed the entire inline `<script>` block with `SyntaxError: Unexpected identifier 's'` — nothing on the page ran. The apostrophe is now an HTML entity, and a new test (`TestDashboardScriptStringsTerminate`) lexes every script block in `dashboard.html` and fails CI on any quoted string still open at end-of-line, so a stray quote can no longer reach a released image.
