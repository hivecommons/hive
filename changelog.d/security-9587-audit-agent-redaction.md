- **Write-surface audit entries now redact the typed `agent` field too** (#9587). The `detail` string and the typed `repo` were already scrubbed of tokens, JWTs, keys and `Authorization` values, but the typed `agent` field was copied through as given, and on relay requests and proxied calls that value comes from the caller. Every audit record builder (relay writes, hive-internal writes, allowlist refusals and proxy-refused direct writes) now masks it the same way. A new test sends each credential shape through every argument of every builder and checks that none of it appears in any field. Ordinary agent names are unchanged.
