- Activity Monitor display mode (`?display=1`) gains wall-screen options ([#15931](https://github.com/hivecommons/hive/issues/15931), part of [#15860](https://github.com/hivecommons/hive/issues/15860)). `density=tv` uses larger type and shows only each row's stage, title and actor. It shows only the rows that fit the screen, with a "+N more" footer instead of the pager. `shift=1` moves the board 1–2 px every 4 minutes to protect OLED screens from burn-in. With *reduce motion* on, a display plays no row movement and no shift. Both options are ignored without `display=1`, so the ordinary Activity Monitor and `?kiosk=1` render exactly as before. The TV layout adds nothing that changes state.
