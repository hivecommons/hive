- Documented the `HIVE_BRANDING_CSS` and `HIVE_BRANDING_JSON` overrides, which the dashboard has always read but neither `src/docs/env-vars.md` nor `src/docs/branding.md` mentioned ([#5807](https://github.com/hivecommons/hive/issues/5807)). Operators whose data volume layout is unusual — a read-only `/data`, a branding bundle delivered as a Secret — had no documented way to discover that the branding paths are relocatable, or that setting only `HIVE_BRANDING_CSS` also moves `branding.json`, which is resolved relative to it. `branding.md` gains an operator section with the real lookup chain, a Secret-mounted example, and the security properties the code does *not* provide: the override stylesheet is read with no ownership, mode, or size check, so an agent-writable branding directory is a CSS-injection path into the operator dashboard — and with `img-src 'self' data: https:` in force, an exfiltration beacon.
