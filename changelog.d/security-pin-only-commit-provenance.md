- The `auto_merge.human_merge_pin_only` exception now verifies the commits behind the head, not only the PR author login: every commit must be authored by a `trusted_authors` login and carry a GitHub-verified signature, and the list must end at the current head. Before, anyone with write access could push a pin-shaped commit onto a trusted author's branch (a `dependabot/...` branch keeps `dependabot[bot]` as PR author) and have the sweep or `/approve` waive the human-merge-path hold on it. Unsigned or foreign commits, an unreadable or empty commit list, or a list that does not end at the head now hold the PR as before; the commit list is read only once the diff already qualifies, so refused PRs cost no extra API call.
