- The hub has a read-only **Fleet activity** page at `/activity`, linked as **📡 Fleet activity** next to **🔬 Evidence**. It shows the open issues and PRs of the hives you can see, from `GET /api/hub/activity`, which scopes every hive to you server-side. It polls every 15 s with `If-None-Match` and redraws only when the ETag changes. A **Hive** column carries a colour chip that opens the hive's own tracker; rows link to GitHub, titles render as text, and there are no action menus. Group-by-hive draws a header per hive with its item count and freshness (`stale` after two missed heartbeats, "upgrade to report activity" for hives that send no activity, missing hives). A list above the board always names truncated items, dropped events and stale or missing hives. Rows use the shared tracker row asset, and the page is served with its own Content-Security-Policy (no inline scripts, handlers or styles). Display mode follows separately ([#16063](https://github.com/hivecommons/hive/issues/16063), part of [#15965](https://github.com/hivecommons/hive/issues/15965), RFC [#15861](https://github.com/hivecommons/hive/issues/15861)).
