- The dashboard no longer lists a PR as Merge-eligible ("it merges on its own") when its base branch only accepts merges through GitHub's merge queue. Hive merges over REST and cannot enqueue, so the sweep skips such PRs with `merge-queue-required`; the merge classifier now reads the same memory of merge-queue bases the sweeps keep, gives the PR a hand-merge verdict naming `merge-queue-required`, and leaves it out of `merge-eligible.json`. The queued, trusted-author and contributor-lane sweeps now share that memory with the self-authored sweep instead of losing it every tick.
