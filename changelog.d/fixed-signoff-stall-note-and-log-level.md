- The sign-off attribution notes on an adopted or hive-caused `stage/085` PR (`adoption-stalled:hive-signoff-attribution` and the maintainer sign-off note) no longer say the `Sign-off survives the squash` gate "stays red" on repositories that do not run `.github/workflows/dco-squash-attribution.yml`. They now say the hive will not squash-merge the head, and name that check only when the head's required or reported checks include it. The adopted-PR stall escalation ("adopted PR sits with nothing the hive can push") is logged at INFO instead of WARN, so designed escalations no longer add up to an `unclassified_error_repeated` fleet self-report ([#14466](https://github.com/hivecommons/hive/issues/14466)).
