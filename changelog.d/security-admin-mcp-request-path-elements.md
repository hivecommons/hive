- Admin MCP: a name of `.` or `..` can no longer steer a request to a different endpoint. Agent, run, repository, contributor and plan names go into the request path, and `.` and `..` survive URL escaping. The hive's router answers such a path with a redirect to the cleaned path, which is another route: `/api/kick/../status` is `/api/status`, and `/api/model/../<name>` is `/api/<name>`. The stdio binary (`hive-admin-mcp`) followed that redirect with the same method, body and token, so with writes enabled a registered operation such as `agent.model` could be previewed and confirmed into a `POST` the admin MCP does not offer, including ones its exclusion catalogue refuses, and a read tool could return another endpoint's data under the wrong name. Over the HTTP endpoint the redirect was not followed and the caller only saw "HTTP 307". Both transports now refuse a request path with an empty, `.` or `..` element before anything is sent, for every read and write, and `write_confirm` refuses a stored confirmation that carries one. Re-extract or rebuild `hive-admin-mcp` to get the fix on stdio.
