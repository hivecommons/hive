- The dashboard's upgrade animation now plays for every pod roll, not only self-upgrades ([#15788](https://github.com/hivecommons/hive/issues/15788)): the hub announces hub-managed rolls through the heartbeat (`upgrade_announce`), operators can announce theirs with `POST /api/upgrade/announce` (owner-only; one-liner in `dashboard-standalone-upgrades.md`), and a SIGTERM with no announce still publishes an SSE `upgrading` event with `phase: restarting` before the stream drops. The banner survives the reconnect, shows the new pod's boot phase from `/api/version.startupPhase`, and reads **Upgraded to `<sha>` ✓** or **Restarted ✓** by comparing build hash and process `startedAt`. Preview it any time with `?demo=upgrade` or Settings → Diagnostics → *Preview upgrade animation*.
