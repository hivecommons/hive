- Review evidence no longer fails with "permission denied" when a PR's evidence directory was created by another user: the bundle is written to a writer-owned `<pr>.uid<N>` sibling directory that the evidence readers (API, dashboard, `hivectl evidence`) also consult. New evidence directories are created group-writable (`0o2775`), and existing ones the writer owns are widened to match ([#13836](https://github.com/hivecommons/hive/issues/13836)).
