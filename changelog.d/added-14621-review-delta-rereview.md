- `review.delta_rereview` (default on), `review.delta_trivial_lines` (default 20) and `review.delta_max_age` (default 72h): a PR already judged at an earlier head is re-reviewed by its diff since that head, with the previous verdict and findings in the kick; an empty or trivial delta in files the previous verdict passed re-stamps that verdict onto the new head without a model call. Aggregates record `delta.previous_head` / `delta.trivial` so the cost dashboard can split delta reviews from full ones ([#14621](https://github.com/hivecommons/hive/issues/14621)).
