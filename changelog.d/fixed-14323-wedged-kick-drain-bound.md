- A wedged agent kick can no longer hold a hub-instructed self-upgrade for the full drain window. A kick whose turn-end signal never arrived stayed "in flight" forever, so the drain could never finish and every upgrade waited `hub.upgrade_drain_timeout_s` before it went ahead. Now a kick left unsettled for longer than the agent's `continuous_turn_ceiling` (45m by default, and also when the ceiling is unset or disabled) no longer counts toward the drain. Hive logs one warning per wedged kick with the agent name and kick age, and the drain's deferred, timed-out and complete log lines list the ignored agents as `ignored_wedged` ([#14323](https://github.com/hivecommons/hive/issues/14323)).
