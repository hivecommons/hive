- Search engines no longer crawl or index the hub's auth-gated and API routes. Google Search Console had been reporting hub pages as "Blocked due to unauthorized request (401)" / "access forbidden (403)" because `robots.txt` said `Allow: /` and hosted hives' `/robots.txt` 302'd to the hub login. `GET /robots.txt` on the public hub now disallows every gated route group (`/api/`, `/login`, `/dashboard`, `/metrics`, `/openapi.json`, …) while keeping the landing pages and sitemap crawlable, any other host gets `Disallow: /`, every 401/403/login-redirect and every `/api/*` response carries `X-Robots-Tag: noindex, nofollow`, the login pages carry a `noindex` meta tag, and hosted spoke dashboards serve `/robots.txt` (`Disallow: /`) ahead of the auth gate and mark all their responses `noindex`.
