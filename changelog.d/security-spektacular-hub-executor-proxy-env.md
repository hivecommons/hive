- Spektacular hub executor: when the hub-launched agent CLI runs as its own executor UID, it now gets the same egress proxy environment as regular agents — `HTTP(S)_PROXY` pointing at the local proxy (replacing any value forwarded from the hive process), `HIVE_PROXY_AGENT`, `GIT_TERMINAL_PROMPT=0`, and the proxy CA in `NODE_EXTRA_CA_CERTS`/`GIT_SSL_CAINFO` — so traffic the `:443` redirect does not catch is still routed through, and attributed by, the per-agent proxy ([#10054](https://github.com/hivecommons/hive/issues/10054)).
