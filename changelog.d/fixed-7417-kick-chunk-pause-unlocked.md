- Kick delivery no longer holds the agent-manager lock while it waits between keystroke chunks. A large kick could hold it for minutes — measured at 209 seconds on a 350-PR kick list — during which the dashboard was unresponsive, the hub heartbeat timed out and reported stale cached stats, and the LLM proxy dropped other agents' in-flight requests. Delivery still paces itself the same way; it just no longer blocks the rest of the server while doing so.
