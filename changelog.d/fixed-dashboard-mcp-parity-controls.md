- 🐛 **Owners could not see or change some settings from the dashboard that the admin MCP could already change.** Settings → Features → Auto-merge → **Per-repository merge policy** now has **Merge with no CI** (`auto_merge.no_ci_ok`: a listed repository's pull requests can merge with no CI checks at all) and, while it is set, the deprecated `auto_merge.allow_unprotected_base` list marked as having no effect. Settings → Features → **Let hive decide** now has a per-repository on / off / hive-wide table (`decisions.delegate.repos`) and an **Effect timeout** (`decisions.delegate.effect_timeout`); a table edit saves every repository's override, so overrides set in hive.yaml or through the admin MCP are kept. An agent whose mode is `NO_GITHUB` (a legacy alias for ADVISORY) now shows that mode in Agent → Operating Mode instead of "use level default". No endpoint changed. See [hive-merge.md](src/docs/hive-merge.md) and [Let hive decide](src/docs/dashboard-sections/activity-monitor.md#let-hive-decide).
