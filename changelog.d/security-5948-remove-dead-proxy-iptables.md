- Removed `bin/setup-proxy-iptables.sh` and its `bin/README.md` "Enforcement" listing ([#5948](https://github.com/hivecommons/hive/issues/5948)). The script was dead code — no Dockerfile, systemd unit, or entrypoint invoked it — yet it advertised itself as making the ACMM proxy "un-bypassable". Its gate was trivially bypassable (it only redirected the IPv4 addresses `dig` returned at startup, GitHub rotates IPs, and it never touched IPv6), fail-open (every rule append ended in `|| true` and a missing `dig` produced zero rules while still reporting success), and its root-only owner exemption would have looped a non-root proxy's own upstream dials back into itself. The maintained, fail-closed enforcement lives in `src/deploy/entrypoint.sh` (`HIVE_PROXY` chain with proxy-UID + packet-mark exemptions and an IPv6 REJECT gate); keeping a second, weaker copy in `bin/` invited operators to deploy an egress gate that only pretended to contain the write path.
