- CI Go jobs (`v2-ci`, `v2-tests`, `go-security-analysis`, `testutil-guard`) now pre-fill the module cache through a shared `go-mod-download-retry` action that retries `go mod download` with exponential backoff, so a transient `proxy.golang.org` stream reset (`INTERNAL_ERROR`) no longer fails golangci-lint, govulncheck, gosec or the sharded tests; this completes the Docker builder-stage retry from #14990 ([#14976](https://github.com/hivecommons/hive/issues/14976)).
