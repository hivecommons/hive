- `GET /api/search` on the spoke ([#14637](https://github.com/hivecommons/hive/issues/14637), part of [#14491](https://github.com/hivecommons/hive/issues/14491)): owners and maintainers can search the local portfolio index by text, `kind`, `repo` and date range, and get highlighted hits plus facets by kind, repo, verdict and sentinel rule. It answers `404` unless `search.enabled` is set, rejects the reserved `semantic=true`, withholds injected text behind visible ioscan redaction markers, and audits each query string with actor and role but never the results.
