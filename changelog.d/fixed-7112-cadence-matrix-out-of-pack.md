- The Governor cadence matrix no longer drops the row for a running agent outside the ACMM pack ([#7112](https://github.com/hivecommons/hive/issues/7112)). #7110 restored the sidebar nav item and card for an agent the API deliberately surfaces (running/enabled but outside the level's pack roster — e.g. a custom `review` agent at ACMM L5), but `renderCadenceMatrix` still filtered its rows against `acmmPackAgents`, the **raw** pack roster published by `buildACMMPackAgents`. That roster iterates `pack.Agents` and never consults `activeOutsidePack`, so it cannot contain a running out-of-pack agent — while `status.agents`, built by `buildAgentsWithHidden` **with** that exception, does. The operator could reach the agent's terminal but the matrix showed no cadence for it: silently absent from the table rather than shown, and invisible to the `hiddenAgents` diagnostic (#6581/#6652) because the suppression was client-side. The matrix now follows `status.agents` — the set the server already gated with the pack rule and its escape hatch — instead of re-deriving the raw roster, so it can no longer disagree with the cards and nav, and genuinely pack-inactive "ghost" agents (never in `status.agents`) stay suppressed. `acmmPackAgents` keeps its raw-roster meaning for its other consumer, the delete-confirmation `_packAgentNote`, so the field is not overloaded and no third copy of the pack-exception rule is introduced.
