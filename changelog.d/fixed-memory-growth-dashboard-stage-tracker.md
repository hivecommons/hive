- Stopped the unbounded memory, thread and connection growth in the hive process that OOM-killed hosted hives ([#14681](https://github.com/hivecommons/hive/issues/14681)): `/api/stage-tracker` held its cache mutex across the whole tracker build (one review-evidence lookup per open PR, each a glob of the repo's evidence directory on NFS — tens of seconds), and every webhook delivery and every status publish invalidated that cache through the same mutex, so webhook handlers, the governor's publish and every dashboard poll queued behind back-to-back rebuilds that never drained. Invalidation is now a flag flip that never waits, at most one rebuild runs at a time outside the lock, concurrent polls get the previous body as `source: stale`, a poll whose client went away stops waiting, and the evidence-directory sibling listing is memoised per repo directory for 60 s instead of re-read per PR.
