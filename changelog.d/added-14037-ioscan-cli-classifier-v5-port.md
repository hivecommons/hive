- v5: the semantic prompt-injection classifier can run through the Claude CLI, launched with no tools, no MCP servers, no GitHub token and an empty working directory, on hives without a model endpoint: set `ioscan.classifier.backend: claude` (or pick it in Settings → Security → Input Defense). A CLI backend makes at most `ioscan.classifier.cli_budget_per_eval` calls per scheduler pass (default 8) and `ioscan.classifier.cli_daily_quota` calls per UTC day (default 500); backends that cannot run without tools (copilot, codex, gemini) are refused at boot. Port of [#14060](https://github.com/hivecommons/hive/pull/14060) and [#14070](https://github.com/hivecommons/hive/pull/14070) from v6 ([#14059](https://github.com/hivecommons/hive/issues/14059), part of [#14037](https://github.com/hivecommons/hive/issues/14037)).
