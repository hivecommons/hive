- **Prior-art gate searches past reviews (#14639).** With `search.enabled: true`, the Governor prior-art gate adds a lexical `search` source over the portfolio search index, so past review verdicts, findings, sentinel hits and beads that already cover an issue are ranked alongside merged PRs, closed issues, docs and code. Gate thresholds and parking are unchanged, re-surfaced text passes through ioscan, and an index error or timeout only drops that source's candidates. With search disabled the gate behaves exactly as before.
