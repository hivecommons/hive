- The `NOTICE matches the module graph` check no longer reports a timed-out go-licenses source lookup as NOTICE drift. go-licenses resolves `gopkg.in/*` source URLs with a live HTTP `?go-get=1` fetch and, on timeout, silently renders `Source:   Unknown`; the byte-exact drift gate then failed unrelated PRs and told contributors to commit the degraded file. `generate-notice.sh` now retries the walk when any source is unresolved, `validate-generated-notice.sh` refuses such a file so notice-autofix never commits it, and `check-notice-drift.sh` names the failure as a generator problem to re-run rather than drift to commit (#11486).
