- Admin MCP `log_read` and `log_sources` gain the `proxy`, `hive-output`, `litellm` and `requests` sources: the dashboard auth proxy's output and the hive's pre-log output (both still on the container's stdout/stderr), the local litellm proxy's output (kept, not added to container output), and a dashboard request log (method, query-free path, status, `duration_ms`, auth `public`/`ok`/`failed`/`none`; auth-proxy terminal traffic and gateway-refused requests excluded). Files are 0600 in a 0700 `HIVE_OUTPUT_LOG_DIR` (default `/data/.hive/logs`), at most 5 × 10 MiB and 7 days per source; on a deployment where a process does not run (hub image, litellm local proxy off) the source is not available with a reason (#11944).
