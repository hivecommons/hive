- A kick's log is now archived to `/data/logs/kicks/<agent>/` as soon as its turn ends, not only when the next kick, a restart or a graceful shutdown rotates the scrollback out. A daily-cadence agent whose container crashed hours after its turn finished (exit code 17, OOM — no SIGTERM, so the shutdown snapshot never ran) used to lose the run entirely and show nothing under 🕘 past kicks. The later rotation snapshot of the same kick replaces the `turn-end` archive, so each kick still has exactly one file and retention still counts kicks.
