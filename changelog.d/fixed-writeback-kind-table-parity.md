- Saving the write-back per-kind matrix under Settings → Features no longer wipes overrides it could not show. The table edited only `min_level` and `require_label` but rebuilt the whole `writeback.kinds` map on save, so any edit there silently dropped every kind's `unlabeled_min_level` and `own_only` (and an own-only kind's `min_level`), undoing what hive.yaml or the admin MCP `writeback.kind_policy` operation had set. The table now has *Without label* and *Hive-authored only* columns for those two fields, and saving sends each kind's override with every field nobody changed on the page kept as it was; the `writeback.kind_policy` preview no longer warns about the dashboard dropping them (#17555).
