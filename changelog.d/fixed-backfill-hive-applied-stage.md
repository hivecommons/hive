- A pull request older than the write-back gate's backfill cutoff no longer keeps a stage label the hive no longer believes. The backfill guard refused every stage-label write on such a PR, so a stage label the hive itself had applied stayed frozen (for example `stage/100-merge-queue` on a PR that was not queued) while the hive's own comments and dashboard tracked another stage. When every `stage/*` label on the PR was last applied by one of the hive's own accounts, the stage labeler now states that fact and the gate lets the hive move or remove its own label (decision reason `hive-applied-stage`). Only the backfill guard is lifted: the opt-in label, level, pause, repo mode and `own_only` still apply, a person's stage label stays untouched, and the 085 escalation note describes the move the same way.
