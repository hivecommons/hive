- **Admin MCP: change merge settings through preview and confirm.** The new `auto_merge.update` write operation wraps `PATCH /api/config/auto-merge`, so an owner can change `squash_only`, `require_current_base`, `human_merge_paths`, the native merge queue, trusted authors, the contributor lane and the other merge settings without opening the dashboard. Lists take `add`/`remove` and `human_merge_paths` takes one repository at a time; the preview reads the current settings and sends each changed list or map whole, so entries you did not name are kept, shows every change before and after, and says when a change lets the hive merge more on its own. `write_confirm` refuses if any of those settings changed after the preview. The operation never merges a pull request, and `human_merge_pin_only` (not on the endpoint) is still set in the configuration file.
