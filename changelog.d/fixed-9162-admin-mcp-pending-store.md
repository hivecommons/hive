- The admin MCP pending-confirmation store (`/data/admin-mcp-pending-confirmations.json` on the dashboard, `~/.config/hive/…` for stdio) no longer grows without bound or wedges admin writes ([#9162](https://github.com/hivecommons/hive/issues/9162)). It now keeps at most 64 unconfirmed previews (oldest evicted first), persists only the request `write_confirm` executes instead of the whole human-facing preview, and replaces the file through a synced temp file + rename so a crash mid-write can no longer leave truncated JSON. A file that is already unreadable is moved aside as `<file>.corrupt-<timestamp>` and the store starts empty, so a torn write costs at most a re-issued `write_preview` instead of disabling every admin write until an operator deletes it.
