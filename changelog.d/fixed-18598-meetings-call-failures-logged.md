- **A failed meetings call now names its error in the hive log.** Every meetings API failure (join, approve, decline, leave, schedule, actions) is logged with its method, path, status and error, and a Discord `/hive join` request whose approval fails keeps the reason on the request and stays approvable. Before, a Quorum refusal such as `blocked: the bot has no permission to connect to that voice channel` reached a hosted owner only as the ingress's generic "hive unavailable" page and left no line in the spoke log ([#18598](https://github.com/hivecommons/hive/issues/18598)).
