- Local-mode contributors no longer start with a sandbox that cannot run anything, and `just contribute-stop` now stops local relays. `just contribute-hive claude local` (and `litellm`) runs a sandboxed `true` through bubblewrap before the relay connects; on Ubuntu, where the `bwrap-userns-restrict` AppArmor profile or `kernel.apparmor_restrict_unprivileged_userns=1` makes every agent command fail, it stops with that cause and points to container mode. A `HIVE_VERDICT` whose reason says the agent's own environment is broken (for example "environment failure", "Bash tool broken", `apply-seccomp`) is classified `blocked` and handed back as an `environment` task failure instead of being booked as a completed task. `just contribute-stop` also stops the relay named in `~/.config/hive/contributor-relay.pid` and its tmux session, and a local start refuses to run beside a live local relay instead of starting a second one under the same contributor ID ([#14832](https://github.com/hivecommons/hive/issues/14832), [#14833](https://github.com/hivecommons/hive/issues/14833)).
