- The admin MCP `agent.resume` preview now discloses that resuming claims operator ownership of the agent's pause state when the agent is paused (`pause_owner: operator`, which exempts it from the ACMM pack visibility sweep) unless the agent already owns it, so `agent.pause` followed by `agent.resume` is no longer a silent config change; `/api/agents` reports `pauseOwner` for this. The admin MCP docs and v6 readiness runbook now also state that token-authenticated writes are audited as the configured owner's login (or `owner`), not `local`, and note the `pause_owner` side effect of resume.
