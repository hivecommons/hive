- Activity tracker: the lit chevron no longer says "Merge queued · 1st" for a PR whose CI is still running or whose review verdict is pending ([#15580](https://github.com/hivecommons/hive/issues/15580)). The headline is stage-first ("CI / Review"), the merge-train slot becomes a trailing suffix ("· queued 1st once ready") until the PR reaches merge-ready, the gate reason reads "merges first once it is ready", and the server marks such train members `merge_train.provisional: true`.
