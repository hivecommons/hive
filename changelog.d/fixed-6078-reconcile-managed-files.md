- Podman/Quadlet deployments no longer keep serving the gateway config they were installed with ([#6078](https://github.com/hivecommons/hive/issues/6078)). A Quadlet install copies repo files onto the host and runs from there — `nginx.conf` is bind-mounted into the gateway, and the four Quadlet units and two boot units are read from the host — but updating Hive replaces only the *image*, so a fix to `src/deploy/nginx.conf` shipped, released, and never reached a deployment that was already running. Measured: the WebSocket-upgrade fix in [#5200](https://github.com/hivecommons/hive/issues/5200) merged on 2026-08-30, and a host installed on 2026-08-22 was still rejecting the contributor handshake with HTTP 400 six days later, while `/api/contribute/status` reported a `served_sha` that *contained* the fix — because that SHA describes the binary, not the gateway. `bin/hive-podman-update.sh reconcile` now compares the eight repo-owned files against a checkout, and `reconcile apply` re-copies the stale ones; `hive.yaml`, `hive.env` and `secrets/` are never touched, which is why this exists rather than `setup --force` — that path regenerates `hive.env` and takes `HIVE_DASHBOARD_TOKEN` with it. `pin` now carries the gateway config forward with the image it ships beside, and `status` reports drift unasked, which is the only cover available to the `podman auto-update` path — a systemd timer calling podman directly, with no script in it to hook. `reconcile` exits 78 on drift so a monitor has something to read: a frozen host was otherwise byte-identical to a current one, which is also how a `hive.container` still naming the retired `ghcr.io/kubestellar/hive` path reports `UPDATED=false`, exit 0 and a green timer while updating nothing. **Existing deployments need one manual run** — this fix ships inside the very files that were never refreshed, so it cannot reach them on its own: from a checkout, run `bin/hive-podman-update.sh reconcile apply` (add `--rootful` for a system install), then restart `hive.service` if it reports a rewritten unit.
