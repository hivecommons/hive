- With `review.combined_perspectives: true`, review kicks are now spread across every eligible reviewer instead of always going to the first one in name order. Each combined kick goes to the reviewer with the fewest PR heads still pending on it, counting kicks planned in the same cycle. Before this, every combined review queued on one agent, so additional reviewers and `replicas:` copies sat idle and raising `review.max_parallel_reviews` only lengthened that agent's queue.
