- The inference translator on `127.0.0.1:18444` now names its caller from the socket owner's UID, the way the GitHub proxy path and the decision endpoint already do, instead of from the `x-api-key` header the caller chose. That header is `sk-hive-<agent name>` and the name is public inside the pod, so any local process could previously borrow a different agent's inference route — backend, model, upstream credential and usage attribution. A mapped agent UID is authoritative (a header naming someone else is logged and overridden), the hive's own control plane keeps the header name, and an unidentifiable caller is refused with 401 unless `HIVE_PROXY_ADVISORY_OK=true`. The translator server also gained a `ReadHeaderTimeout` ([#14439](https://github.com/hivecommons/hive/issues/14439)).
