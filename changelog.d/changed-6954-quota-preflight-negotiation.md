- Contributor quota preflight is now capability-negotiated end to end (kubestellar/hive#6954). The relay advertises `quota_preflight_v1` back to the hub in `capabilities.relay_capabilities` on `auth_response`, and the hub gates the auto-accept credential hold on that advertised token instead of proxying on the relay's declared protocol version — which previously withheld the credential from every relay that declared any version (#6931 never bumped `RELAY_PROTOCOL_VERSION`). Mixed-version behaviour is backward compatible: a relay that does not advertise the token gets pre-#6833 immediate credential delivery, and an old hub that does not advertise the capability leaves an older relay unchanged. The new field is optional, so no protocol-version bump is required and `RELAY_PROTOCOL_VERSION` stays in step with the hub.
