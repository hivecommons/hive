- `crux serve --hive-callback ADDR` (default `$CRUX_HIVE_SOCKET`, token from `$CRUX_HIVE_TOKEN`) dials hive's capability endpoint and feeds the runtime's seams from it (Crux sidecar plan, stage 3): the manager's condition reporter, sandbox pull-request creator, Linear credential resolver and push-token minter, and the process-wide tool-approve text scanner, all through `crux/hivecap` so each fails closed when hive is unreachable. The endpoint's reachability is reported as `hive_callback` on `GET /v1/health` and as the `hive_callback_unavailable` condition on `GET /v1/events` (`hivecap.Watch`, `serve.Server.Conditions`).
