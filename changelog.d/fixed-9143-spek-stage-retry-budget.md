- Spektacular's `runs.max_stage_retries` now takes effect for hub-executed spec and plan stages. Before, the lease keepalive re-armed the hub executor's lease on every cleanup tick, so a stage whose agent exited with the document still draft, or failed, was never retried or escalated. The hub executor now owns the budget: each spent generation mints a retry generation until the budget runs out, then raises a `decision` escalation. The escalated run stays in `/api/runs` as `waiting_on=human` (`waiting_reason=stage_budget_exhausted`), and both the escalation and the generations spent survive a restart ([#9143](https://github.com/hivecommons/hive/issues/9143)).
