- Fixed copilot-backend agents hanging idle after an intermittent model/transport failure. When the Copilot CLI exhausts its own retry budget it prints `Failed to get response from the AI model` and drops back to an empty prompt, but the transient-API-error watchdog could never nudge it: detection required Claude Code's `API Error:` chrome, which copilot never emits, and the idle-prompt check required the prompt marker to be the pane's last non-empty line, which copilot's hint footer makes impossible. Either bug alone stranded the agent until its next cadence kick — on an hourly cadence that is up to an hour of lost work per blip. Both predicates now understand copilot's pane shape, with the copilot error branch still requiring a transport-level cause so non-retryable auth and quota failures are not nudged.
