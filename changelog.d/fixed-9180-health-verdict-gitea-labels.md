- The hub health verdict no longer lets a run waiting on a human mask a real red: "advisory posting failing", "advisory stale", and stale create/merge output now stay the headline instead of reading amber "run waiting on human", and the stale-output red can again be re-explained by the model-error-streak detector. `HIVE_FLEET_RUN_WAIT_AMBER_SECONDS=0` now means "use the default" like `fleet.run_wait_amber_seconds: 0` instead of ambering every waiting run, and the "since" time is anchored to the heartbeat that reported the wait so it no longer drifts between beats. The Gitea forge's `RemoveLabel`/`SetHold(false)` now resolves the label from the labels on the PR itself, so an organisation-level hold label is actually removed instead of silently left in place ([#9180](https://github.com/hivecommons/hive/issues/9180)).
