- An unclaimed hosted placeholder slot (no repos, `available-<id>` or empty `project.org`) no longer files a fleet `github_app_not_installed` self-report; the missing installation is expected before the slot is claimed and the dashboard onboarding banner already surfaces it. The report behind [#17600](https://github.com/hivecommons/hive/issues/17600) is the same condition fixed in v6.13.1 by [#17594](https://github.com/hivecommons/hive/pull/17594) ([#17593](https://github.com/hivecommons/hive/issues/17593)), where `fleetreport.onboardingOnlyCondition` keys on `config.IsPlaceholderOrg`; that one org-based predicate owns the policy, so the agent token minter keeps observing the runtime condition unchanged rather than adding a second repo-based gate that could disagree with it.
