- CI now reads the Go toolchain version from `src/go.mod` (`go-version-file`) instead of hard-coding `go-version: '1.25'` in every `setup-go` step. Twelve pins across `coverage-hourly.yml`, `go-security-analysis.yml`, `testutil-guard.yml`, `v2-ci.yml`, and `v2-tests.yml` had drifted below what dependency bumps require, so every dependabot PR whose module declared `go 1.26` (for example golang.org/x/sys 0.48.0 in #6253) failed at load with `go.mod requires go >= 1.26.0` rather than on the code under test. Bumping the module's `go` directive now propagates to CI automatically ([#6260](https://github.com/hivecommons/hive/issues/6260)).
- The `go` directive in `src/go.mod` moves from `1.25.6` to `1.25.14`. Reading the toolchain from go.mod means CI now uses exactly the pinned patch level instead of "latest 1.25.x", and 1.25.6 carries three stdlib advisories govulncheck flags (GO-2026-6090, GO-2026-6091, GO-2026-6218 in `net/url` and `html/template`). 1.25.14 is the current patched release.
