- The Linear work-tracker section of every kick now tells agents two things it left out before. First, which credential to use when both are present: `LINEAR_ACCESS_TOKEN` (the connected Hive app's own grant, so writes are authored by the Hive app user) always wins over `LINEAR_API_KEY` (a personal key that attributes writes to its human owner) — agents given both had been picking the personal key, and every issue they filed showed the operator as its creator. Second, how to label: a bare `issueCreate` lands unlabeled, so the section now shows the `issueLabels` lookup, `labelIds` and `priority` on create, and `issueAddLabel` after, mapping whatever labels the policy applies to GitHub issues onto Linear labels of the same names.
