- The public knowledge address shown to the owner under Settings → Knowledge is now one readers can reach. It uses `dashboard.public_url` when set, then `X-Forwarded-Host`, then the request host. A standalone hive reached through its built-in proxy used to show the internal `http://127.0.0.1:3002/mcp/knowledge`; it now shows the `/mcp/knowledge` path alone when the real address is not known.
