- Agents can now carry a per-agent `reasoning_effort` (e.g. `low`/`medium`/`high`/`xhigh`) for the `codex` and `agy` backends: it is configurable per agent in hive config, surfaced and editable in the dashboard, and passed through to the CLI at launch, so an operator can dial individual agents up or down without changing the hive-wide default ([#6163](https://github.com/hivecommons/hive/pull/6163)).
