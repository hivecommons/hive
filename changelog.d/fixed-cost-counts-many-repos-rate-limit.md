- The dashboard Cost panel's cost / PR and cost / issue tiles no longer show "—" (or fall back to the merged-by-hive counter, which is 0 at ACMM L5) on hives with many repos: the hive-attributed count reconciled every configured repo in one burst — 38–76 Search API calls for 19 repos against GitHub's 30/minute limit — so it failed every hour and never produced a baseline. The reconcile now asks about a budgeted slice of repos per paced pass, direct search counts batch `repo:` qualifiers into a few queries, partial progress is served and labelled (`count_partial`) instead of discarded, a refusal keeps the last attributed count stale, and the reason is surfaced as `count_error` in `/api/cost` and the tile tooltip.
