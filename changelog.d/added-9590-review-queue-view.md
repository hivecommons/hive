- **Dashboard "Review queue" view** ([#9590](https://github.com/hivecommons/hive/issues/9590)). A new dashboard section (sidebar: Review queue, ACMM L2+) renders `GET /api/review/queue` in rank order: position, PR link, author (hive agent or contributor), triage class and priority, confidence band (or *unreviewed*), CI state and age, with each row expandable to the reasons it sits where it does. 25 rows per page. Read-only and visible to any dashboard session, like the API. The API response now carries `version`, a fingerprint of the whole ranked queue that changes exactly when a rank input it reflects changes (new head SHA, CI flip, a verdict for the current head, merge conflicts, hold, a PR opening or leaving); the view polls every 30s and re-renders only when it changes. `src/docs/review-queue-triage.md` now documents when the queue re-ranks: verdicts on the next request, everything else on the next eval cycle, which is the earliest the hive can know without GitHub webhooks.
