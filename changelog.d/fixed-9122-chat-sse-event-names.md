- The chat notification bridge now honours SSE `event:` names on `/api/events` ([#9122](https://github.com/hivecommons/hive/issues/9122)). Previously every `data:` line was decoded as a full status snapshot, so the dashboard's lightweight `event: agent-status` frames (every agent poll, 10 s by default) blanked the cached governor, inception and runs state between eval cycles: governor mode changes were never announced, inception clarification questions were re-posted every eval cycle while the owner's plain-language answer typed in between was silently dropped, and the channel topic flapped between the real summary and an empty one (hitting Discord's topic edit rate limit). `agent-status` frames now only announce agent transitions and refresh the cached agent list; governor, inception, runs and the topic are driven by full frames alone. The topic update is a real debounce — a single timer per window, latest topic wins, cancelled on shutdown — instead of one sleeping goroutine per change.
