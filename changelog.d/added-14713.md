- `python3 src/scripts/check-docs-citations.py --fix` now repairs drifted `src/docs` line-range citations into `.go` files instead of only delegating to the `api-reference.md` route fixer: it resolves the first backticked symbol anchor on the citing line to a single top-level Go declaration (`func X(`, `func (recv) X(`, `type X`, `const X`, `var X`) and rewrites the range to start at that declaration and end at the first line that covers every anchor. It fails closed — zero or several matching declarations, an anchor outside the declaration, a non-`.go` target, or a line without anchors leaves the citation untouched and still reported as `DRIFT` with a non-zero exit — and a second `--fix` run is a no-op.
