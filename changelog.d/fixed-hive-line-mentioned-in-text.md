- **A PR whose description mentions `— hive:` in its text is signed now.** The PR-request watcher skipped the `— hive: agent=… backend=… model=…` line whenever the body contained `— hive:` anywhere, so a PR that described the repositories' monthly agent audit (Danathar/arch-bootc#473, Danathar/atomic-image-builder#640 and #678) was opened unsigned, and that audit, which reads only a line beginning with `— hive:`, then failed. The watcher, `ReconcilePRAttribution`, the issue and review relays that use the same trailer, and the `gh` wrapper's body-edit guard now treat only a line that starts with `— hive:` as a signature. See [hive-open-pr](src/docs/hive-open-pr.md).
