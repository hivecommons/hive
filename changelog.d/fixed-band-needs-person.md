- The Merge-eligible band ("nothing needed; it merges on its own") holds only pull requests Hive will merge. The auto-merge label used to put a PR there whatever its verdict, so projectbluefin/server#583 (a red check) and #613 (GitHub refusing the merge) sat there. Now the label counts only before the sweep has a verdict and only when nothing blocks the PR; the sweep's own eligible verdict still decides. In a repo whose auto-merge is off, a PR held only by a Hive-side gate (a contributor-lane refusal, a red check nobody declared required) is a hand merge in the your-turn inbox, its reason naming both. projectbluefin/documentation#1668 and projectbluefin/actions#697 had shown no reason at all.
