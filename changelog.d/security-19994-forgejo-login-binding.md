- The Forgejo close-on-merge sweep no longer trusts `forgejo.login` on its own. It still asks `GET /user`, uses the configured login only when Forgejo answers 403 (a token limited to specific repositories), and refuses a login that differs from the token's user. Before it honours its own pull requests or treats its own issues as hive-authored on a repository, it checks that this user holds write there, so a `forgejo.login` naming another user closes nothing ([#19994](https://github.com/hivecommons/hive/issues/19994)).
