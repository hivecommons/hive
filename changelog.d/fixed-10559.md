- Pull-only clusters (such as a firewalled GPU pool registered `pull_only: true`) get their node stats from spoke heartbeats again ([#10559](https://github.com/hivecommons/hive/issues/10559)). Spokes now attach cluster node health whenever a cluster id is configured, whether it comes from `hub.cluster_id` in hive.yaml or from `HIVE_CLUSTER_ID`. Before this fix only the environment variable counted, so a spoke configured through hive.yaml never sent node stats, and the hub card showed `0 nodes` under a red "cluster is pull-only: not reachable" banner. A pull-only cluster with no heartbeat health yet now shows a neutral `pull-only · awaiting spoke heartbeat (last seen: never/<age>)` line. The card turns red only when a spoke that was reporting has gone stale.
