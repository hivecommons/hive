- Overview open issue / PR totals are read from the ForgeState cache (`pkg/forgestate`) when it is ready, and the merged-PR / closed-issue counts behind cost-per-PR and cost-per-issue are incremented from `pull_request closed` (merged) and `issues closed` webhook events and reconciled against GitHub search once an hour (`forgestate.CountsReconcileInterval`) instead of on every 5-minute collection ([#13376](https://github.com/hivecommons/hive/issues/13376), Phase 2b of [#13373](https://github.com/hivecommons/hive/issues/13373)). A rate-limited or failed reconcile keeps the last good counts: `/api/status` carries `staleSince` and per-repo `countsStale` / `countsStaleSince`, `/api/cost` carries `count_stale_since` / `count_source`, and the Overview tiles and cost labels show "stale since <t>" rather than zeros.
