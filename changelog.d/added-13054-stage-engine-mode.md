- `governor.labels.stage.engine.mode` (`off` / `shadow` / `enforce`, default `shadow`; Settings → Labels) switches the ADR-0025 central stage engine at runtime ([#13010](https://github.com/hivecommons/hive/issues/13010), part of [#12999](https://github.com/hivecommons/hive/issues/12999)): one reconciler is shared by the issue and PR sweeps, `off` is legacy pass-through, `shadow` counts every legacy/engine disagreement, `enforce` lets the engine write. `/api/status.stageEngine`, the activity tracker's status strip and the `hive_stage_*` series on `/metrics` report mode, derivations, mismatches and anomalies; the shadow → enforce rollout runbook is in `operator-reference.md`.
