- RFC lifecycle notices gain opt-in rich-mode keys under `notifications.discord`: `rfc_format` (`line`, the default, or `card`; an unknown value is a config error), `rfc_threads`, `rfc_announcer` and `rfc_backlink_comment`. All default off, so today's one-line posts are unchanged. Card and thread rendering land later. For now, rich mode switches on the designated-announcer gate: a hive set to `rfc_format: card` or `rfc_threads: true` without `rfc_announcer: true` posts nothing and logs `rfc notify: rich mode requires rfc_announcer; not posting` once. Its detector state still advances, so turning on the announcer later does not backfill. This stops several hives sharing a channel from racing to publish (#15926, part of #15869).
