- The GitHub forge adapter implements `forge.Merger` and passes the shared merge contract (#14107): the hold gate refuses with `ErrHoldActive` and a head that is not the pinned commit with `ErrConflict`, both before the merge call; an already-merged change reports `ErrAlreadyMerged`, GitHub's 405/422 map to `ErrNotMergeable`, and `MergeOptions.DeleteBranch` removes the merged head branch. The merge delegates to `pkg/github.MergePR`, so it keeps the mutation boundary, forward-merge guard and merge audit.
