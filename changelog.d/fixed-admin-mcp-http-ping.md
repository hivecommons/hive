- Admin MCP HTTP endpoint (`POST /api/admin/mcp`): `ping` is answered with an empty result, as MCP requires, instead of "method not found", so a client that pings to check the server is alive no longer reads the hive as gone. Notifications other than `notifications/initialized` (for example `notifications/cancelled`, which a client sends after it gives up on a tool call) are acknowledged the same way `notifications/initialized` always was, instead of being answered with a "method not found" error. Unknown request methods are still refused with `-32601`. The stdio binary was not affected.
