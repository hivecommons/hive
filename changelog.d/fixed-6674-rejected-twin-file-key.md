- The re-file gate added in [#6463](https://github.com/hivecommons/hive/issues/6463) now keys on the files a finding actually names, so a scanner can no longer slip a rejected finding past it by rewording the prose around them ([#6674](https://github.com/hivecommons/hive/issues/6674)). The gate identified a finding by every dotted token in its text, which swept in the verification command the run happened to use (`ast.parse` one day, `py_compile.compile` the next), version strings like `3.x`, and a bare `client.py` mentioned in one extra sentence — and since the sets had to match exactly, any one of those was enough to miss. A false positive a maintainer had closed four times had been filed a sixth time with the gate live. Identity is now the set of real paths: dotted attribute and module chains are excluded, a slashless token must carry a known source extension, and a basename folds into the fuller path for the same file when the finding quotes both.
