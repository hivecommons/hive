- Hive Chat `/prs` now lists the actual open pull requests instead of a per-repo count: one row per PR under each repo (`owner/repo#N — title (@author · stage labels · age · ✅/❌/⏳ CI · approved/changes requested · needs decision · hold · mergeable)`), read from the status snapshot's cached PR rows — no extra GitHub call — and capped at 25 with an "… and N more" footer. The command remainder is now honoured as filters: `waiting on review`, `needs decision`, `hold`, `failing ci`, `mine` / `by <login>`, `repo <owner/repo>`, `stale` / `older than Nd`; unrecognised words are reported and the hint lists the filters. `/prs waiting on review` used to answer only "hivecommons/hive: 12 open PR(s)" (hivecommons/hive#14408).
