- Quiet notification mode (`github.notifications.mode: quiet`, the default) now folds the remaining per-event comments the hive posted into the single edited `<!-- hive:status -->` comment: the post-merge evidence pointer, the `hive:unblocked` note (now also idempotent per issue and settled PR in either mode, and skipped when the same merge closes the issue), the review backlog summary, the contribute hub's claim marker and an agent's relayed `hive/awaiting-ci`, `Parking on stage/045…` and `Already fixed` status notes. Closing an issue leaves one closing comment: the close-on-merge sweep and the issue-stage lane no longer both post `Fixed by #N`. The GitHub client logs `github notifications created=N edited=M suppressed=K` once an hour so the effect can be measured ([#15918](https://github.com/hivecommons/hive/issues/15918)).
