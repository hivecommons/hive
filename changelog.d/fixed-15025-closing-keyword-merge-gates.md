- Stop the merge lanes from merging a PR whose merge would close the wrong thing: a body that says an issue stays open (`Refs #N — partial`) but also `Closes #N` is held as `closing-contradiction:#N` until the body is fixed, and a closing keyword in the body or a commit message that names another open pull request (`fix #1036`) holds the merge as `closing-keyword-targets-pr:#N`. Both gates apply only to PRs into the repository's default branch, the one place GitHub acts on closing keywords.
