- **Activity Monitor display playlists.** A display-mode URL can rotate between views: repeat `am.view=<url-encoded am.* query>` and set `interval=Ns|Nm` (10 s–1 h, default 60 s), e.g. `?display=1&am.view=am.needsHuman%3D1&am.view=am.kind%3Dpr&interval=2m`. Invalid views are skipped and fewer than two means no rotation. The current view follows the wall clock, so it survives reloads and reconnects; rotation is in memory only (no navigation, refetch or local storage), with a thin progress bar or a static "next in Ns" label under reduced motion. Playlists live only in the URL — no `hive.yaml` presets — and kiosk mode is unchanged ([#15932](https://github.com/hivecommons/hive/issues/15932)).
