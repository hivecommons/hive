- The admin MCP can now read model effectiveness, which only the dashboard showed until now. `pr_models_read` returns Governor → "PRs by model" (merged, closed-unmerged and open PRs per model, rework, effectiveness rank, per-agent counts and the fixer queue) for `window` `7d`, `30d` or `all`. `contributor_model_stats_read` returns the contributor run stats by model (runs, verified-PR share, failure rate) for `days` 0-365. Both are read-only, need no write access, return the dashboard's own answer, and refuse an unknown window with its reason instead of quietly reading the default one.
