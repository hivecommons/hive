- The hold guard no longer re-holds a PR whose branch was rebased earlier during the hold when a human (not a Hive account or bot) removed the gate label after the current head arrived on the branch: that lift reviewed the current head, so the snapshot clears without the integrity comment or a fresh `hold`. The head's arrival is dated only by server-stamped signals (the `head_ref_force_pushed` event that produced it, else the earliest check suite or commit status GitHub created for the SHA), never by the commit's client-set committer date; a push after the lift, a lift by the hive or a bot, a failed lookup, or a head with no server signal still re-holds as before ([#13603](https://github.com/hivecommons/hive/issues/13603)).
