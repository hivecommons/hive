- The dashboard upgrade button is now deployment-runtime aware for standalone Podman/Quadlet and Docker Compose hives ([#7008](https://github.com/hivecommons/hive/issues/7008), [#7011](https://github.com/hivecommons/hive/issues/7011)). Unknown or incompletely configured runtimes no longer relay `Upgrade now` through the Hub/Kubernetes path; they show an honest manual-update state until an explicit runtime and host upgrade helper are configured.
