- The "What triggers notifications" table in `src/docs/notifications.md` is back in step with the code ([#6240](https://github.com/hivecommons/hive/issues/6240)). It gains the `Convergence mode changed` page (default priority, sent once per runtime transition of the convergence rollout mode from `applyConvergenceKickAdmission`), and every existing row now names the Go symbol that emits it - `selectSLABreachNotifications`/`runEvalCycle` for the SLA cap (with the `maxSLANotificationsPerCycle` and `doubleSLAMinutes` constants the "three per cycle, older than 60 minutes" wording came from), `runEscalationSweep` for the fix-loop escalation, and the `ActionNotify`/`notifierAdapter` pair for hook `notify` actions - so an operator filtering on a title can find the sender without grepping. No provider rows changed: `NotificationsConfig` still fans out to ntfy, Slack, and Discord webhooks only.
