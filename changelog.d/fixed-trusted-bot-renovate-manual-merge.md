- **The trusted-bot lane no longer merges a Renovate PR whose lock file or other artifact Renovate could not update.** The lane merged a trusted bot's PR on green CI alone, so a branch Renovate had flagged with "⚠️ Artifact update problem … You probably do not want to merge this PR as-is" merged like any other bump (projectbluefin/testsuite#1230: a TypeScript major merged three minutes after that comment, leaving `package.json` and `package-lock.json` out of step and the Pages workflow red at `npm ci`). A Renovate PR (a `renovate/` branch or Renovate's footer link, whatever account runs it) with that comment from its own bot now parks at 090 Ready for human merge (`renovate-artifact-problem`) until Renovate removes the comment; no approval releases it. A new opt-in, `auto_merge.trusted_bot_honor_renovate_automerge` (default off; Settings → Auto-merge and the `auto_merge.update` MCP operation), also holds a Renovate PR whose description says `🚦 **Automerge**: Disabled …` (`renovate-automerge-disabled`), for hives where Renovate's `automerge: false` always means "a person merges"; it is off by default because many configs set `automerge: false` so that the hive does the merging.
