- **The trusted-bot lane no longer merges a Renovate PR that Renovate itself says a person should merge.** The lane merged a trusted bot's PR on green CI alone, so a Renovate major that the repository's Renovate config kept out of automerge, and a branch whose lock file Renovate could not update, merged like any other bump (projectbluefin/testsuite#1230: a TypeScript major merged three minutes after Renovate's "Artifact update problem" comment, leaving `package.json` and `package-lock.json` out of step and the Pages workflow red at `npm ci`). A Renovate PR (a `renovate/` branch or Renovate's footer link, whatever account runs it) now parks at 090 Ready for human merge when its description says `🚦 **Automerge**: Disabled …` (`renovate-automerge-disabled`) or the bot commented `### ⚠️ Artifact update problem` (`renovate-artifact-problem`); no approval releases either, the owner merges it. A hive whose Renovate config leaves automerge off everywhere because the hive does the merging can turn the first check off with `auto_merge.trusted_bot_honor_renovate_automerge: false` (Settings → Auto-merge, and the `auto_merge.update` MCP operation); the artifact check always applies.
