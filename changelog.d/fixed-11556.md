- Issue comments and label adds/removes refused by GitHub before anything was applied (403 `Resource not accessible by integration`, 404, 410, 422, rate limits) are now journaled NotApplied instead of Unknown, so the same write retries once the cause is fixed — e.g. after a repo is added to the GitHub App installation ([#11556](https://github.com/hivecommons/hive/issues/11556)). Writes already stuck as Unknown (from a timeout, 5xx, or the old behaviour) are now reconciled against the issue's comments/labels on the next attempt instead of failing with `needs reconciliation before retry` forever, so no hand-editing of `journal.json` is needed.
