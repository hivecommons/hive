- "Let hive decide" (its model step, `decisions.delegate.llm`) and the dashboard's grounded chat answers now work on a hive that runs its agents on a Claude subscription and has no OpenAI-compatible reviewer endpoint. The new `governor.reviewer_backend` setting (`auto` by default, or `http`, or `claude-cli`) runs the turn through the official Claude CLI on the hive's own Claude login when no endpoint is configured; with an endpoint, nothing changes. Because the prompt carries untrusted issue and comment text, the CLI runs with every tool, MCP server and hook off, one turn, no saved or resumed session, an empty temporary working directory and HOME, the prompt on stdin, no GitHub or hive token in its environment, at most two at once, and as its own user (`hive-hive-turn`) under per-agent UID isolation. Settings → Features → *Let hive decide* and the admin MCP now say which path the turn takes and, when it cannot run, why (`llm_reviewer_path`, `llm_reviewer_reason`). The other reviewer users (trajectory and advisor lanes, intent alignment, Jam replies, written-spec refinement) still need the endpoint.
