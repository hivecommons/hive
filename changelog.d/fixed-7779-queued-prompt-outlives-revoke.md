- The contributor relay no longer types a revoked or failed task's prompt into the agent ([#7779](https://github.com/hivecommons/hive/issues/7779)). A prompt that arrived while the CLI was still starting is queued until the CLI is ready; if the hub revoked the task (or the relay failed it) before then, the queued prompt survived and was typed into the fresh CLI once it came up — the agent started working an issue the hub had already taken back, possibly handed to someone else, while the relay believed it held no task. The queue is now tied to the task it was queued for: every task-exit path discards it, and the ready-time flush refuses a prompt for any task the relay no longer holds.
