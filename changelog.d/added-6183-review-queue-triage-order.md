- The review queue is now ordered by triage class instead of purely by age ([#6183](https://github.com/hivecommons/hive/issues/6183)). At ACMM L5 hold-gated, agent PR throughput permanently exceeds human review throughput, and the undifferentiated queue left production bug fixes aging behind dozens of test-coverage PRs of identical apparent urgency. `last-actionable.json` and the dashboard's PR list and on-hold tooltip now sort fixes (`🐛` / `🔒` / `fix:` / scanner, ci-maintainer and sec-check lanes) ahead of refactors and docs (`📖` / `refactor:` / `docs:` / architect, guide and strategist lanes) ahead of tests (`🧪` / `test:` / quality lane), oldest first within each class, so the previous age order is preserved for PRs of one class. Each PR and held item carries a new `review_class` field and the PR pill shows it as a small badge. This is option 1 of the issue (presentational sort only): no label is written, and no agent or governor behaviour changes. The `review-priority` label (option 2) and the per-lane queue cap (option 3) remain open maintainer decisions.
