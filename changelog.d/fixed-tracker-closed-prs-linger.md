- A PR or issue closed on GitHub no longer reappears on the Hive activity monitor for minutes after the webhook re-read had already removed it. The eval cycle in flight at the time of the close published its status snapshot from the enumeration it started with (listing the item open), overwriting the webhook patch until the next full enumeration re-listed the repo (pluk#313 came back 4 s after closing and left again ~5 min later; up to `governor.eval_interval_webhook_s` plus a cycle in the worst case). Webhook re-reads are now remembered for `dashboard.stage_tracker.webhook_refresh_replay_window_s` (default `1800`) and re-applied to every status snapshot published meanwhile, monotonic on GitHub's `updated_at` so a later reopen still wins; repo issue / PR totals follow the patched lists, and a closed PR also takes its issues-feed copy with it. Closed items now leave within one dashboard poll.
