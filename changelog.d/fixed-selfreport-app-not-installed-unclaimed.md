- **Unclaimed hives no longer file `github_app_not_installed` self-reports** — a hosted "available slot" hive that has not been onboarded yet (no `project.org`) legitimately has no GitHub App installation, so the runtime `github_app_not_installed` condition is now kept out of fleet self-reports for it. The local warning log and the dashboard onboarding banner are unchanged, and a hive that *does* have an org configured but no App installation still self-reports it as a real misconfiguration. ([#17593](https://github.com/hivecommons/hive/issues/17593))
