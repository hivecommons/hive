- `TestProxyHTTPUpstreamReadError` and `TestProxyHTTPResponseWriteError` now join the `proxyHTTP` goroutine before returning instead of sleeping ([#6110](https://github.com/hivecommons/hive/issues/6110)). A leaked handler read `responseBodyStallTimeout` while the next test's `shortenBodyStall` wrote it — the data race that failed v4 CI run 33979236903. The v4 fix was dropped from the v4→v5 sync (#6309) to clear a merge conflict with #6233's dead-test deletion; this restores exactly that test-side join on v5.
