- The hub **Fleet activity** page (`/activity`) takes the spoke Activity Monitor's display parameters, read by the spoke's own code: `?kiosk=1` hides the chrome and cursor for an unattended screen, `?display=1` gives an attended chrome-less wall view that **Esc** or **d** leaves, `am.*` describes the board's view with the spoke's keys (kind, repo, q, author, sort, dir and `am.group=none`), and in display mode `am.view` + `interval` rotate `hub-activity` views with the spoke's wall-clock dwell. `am.*` keys the activity digest has no data for stay in the URL and are named on the board as not applied. A copy of the spoke's URL-view and playlist helpers is served byte-identical from `/activity/assets/` (`pkg/webassets/trackerview`), and a compatibility test fails if it drifts. The spoke tracker's display mode is unchanged ([#16064](https://github.com/hivecommons/hive/issues/16064), part of [#15965](https://github.com/hivecommons/hive/issues/15965), RFC [#15861](https://github.com/hivecommons/hive/issues/15861)).
