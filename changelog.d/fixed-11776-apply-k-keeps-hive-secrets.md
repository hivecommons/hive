- Running `kubectl apply -k` again on the Kubernetes base or any overlay no longer deletes the keys in `hive-secrets`. The base used to ship an empty `hive-secrets` Secret, so each re-apply's three-way merge removed the keys an operator had added with `kubectl apply`, and the next restart refused to start without `HIVE_DASHBOARD_TOKEN`. `src/deploy/k8s/secret.yaml` is now only a commented template outside the kustomization, and operators create the Secret themselves, as the docs already describe. The Deployment already treats every `hive-secrets` reference as optional ([#11776](https://github.com/hivecommons/hive/issues/11776)).
