- `just contribute-hive <backend> local` now launches the CLI with `AGENT_MODEL` and `AGENT_REASONING_EFFORT` ([#16222](https://github.com/hivecommons/hive/issues/16222)). The local launch line added `--model` only for litellm and pi and never added an effort flag, and the relay reuses that line verbatim on every relaunch — so a claude contributor who asked for `claude-sonnet-5-5` at `medium` ran their Claude Code default (`xhigh` from `~/.claude/settings.json`) for the whole session, while the relay still reported the requested model and effort to the hub. Standby model tiers and the PR attribution trailer read that report. The launcher now takes both flags from `backend_selection_flags_shell` in `config/backends.conf`, which emits exactly what the relay's own builder adds (claude `--effort`, codex `-c model_reasoning_effort`, agy `--effort` with its model, muse `--reasoning-effort`, `--model` for every backend that takes one). The relay also reports a model or effort only when the launch line carries its flag, and logs once when it does not, so the hub never records a configuration the CLI is not running.
