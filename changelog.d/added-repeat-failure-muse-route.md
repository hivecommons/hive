- **The repeated-failure check now sees commands run by muse agents** ([#14749](https://github.com/hivecommons/hive/issues/14749), part of [#14559](https://github.com/hivecommons/hive/issues/14559) and [#14550](https://github.com/hivecommons/hive/issues/14550)): with `repeat_failure.enabled` on, Hive reads the append-only session logs Muse Code keeps under `$XDG_DATA_HOME/muse/sessions` and records each finished `bash` call with its exit code (route `muse_sessions`), writing nothing into Muse Code's settings, hooks or launch; muse is marked covered with a committed, re-runnable real-CLI harness (Muse Code 1.4.1).
