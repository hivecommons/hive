- fix(pushbroker): the trailing-blank-line normaliser now keeps an agent's staged (index) state for a touched path. `git add` of the normalised blob used to replace the staged entry, so an uncommitted edit the agent had already staged came back on disk but silently unstaged; the broker now snapshots the index entry and puts it back with `git update-index --cacheinfo` after the amend (#16158, #16196).
