- Contributor quota guard (Agy): a silently-broken Agy adapter is now distinguishable from an unconfigured or absent CLI (kubestellar/hive#6986). Before, a schema drift that stopped the adapter mapping a real, authenticated `/usage` payload reported `unknown` forever — indistinguishable, from the outside, from a host with no agy credentials, so the adapter was dead code that looked alive. Probe failures now carry a cause: `unrecognized_schema` (a `SUCCESS` envelope the adapter cannot map — a dead adapter on a credentialed host), `no_credentials` (a non-`SUCCESS` envelope: the CLI ran but is not serving usage), and `not_installed` (no `agy` on `PATH`). The cause is surfaced in the Headroom's `probe_error_cause` diagnostics and in the published contributor reading's `cause` field. Every cause remains an `unknown`/hold — the categorization never turns a hold into an admit, so the fail-safe direction is intact and `TestAgyHeadroomRejectsUnrecognizedSchema` is unchanged.
