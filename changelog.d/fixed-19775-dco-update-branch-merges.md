- The post-merge DCO monitor no longer fails a contributor's private-email squash because the pull request also held GitHub "Update branch" merges made by the hive App. The merged-PR evidence rule from #19660 required every PR commit to belong to the PR author, so the squash of #19766 (69794fd) was reported as `pr-commit-not-by-pr-author`; it now ignores only verified web-flow merge commits authored by a Bot account, which carry base-branch content and none of the change. Human merges, unverified or single-parent bot commits, and PRs with no commit of the author's own still fail. (#19775)
