- ioscan's hidden-markup and data-carrying-URL rules no longer flag ordinary content ([#19452](https://github.com/hivecommons/hive/issues/19452)). Fill-in markers are matched against decoded query values only, so bracketed parameter names such as `filter[key]=1` and words such as `yourself` or `insertion` no longer count, while placeholders such as `YOUR_TOKEN` or `{{secrets}}` still do. Long values of AWS, GCS, CloudFront, Azure SAS and JWT-signed image URLs are no longer read as exfiltrated data when the URL carries that scheme's signature. A Medium phrase inside a `<details>` section stays Medium; only HTML comments and CSS-hidden elements still raise it to a blocking High.
