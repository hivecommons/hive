- Signing in to Claude from the dashboard now stores the plan behind the token. After the token exchange hive reads `GET /api/oauth/profile`, the same call Claude Code makes after its own login, and writes `subscriptionType` (`max`, `pro`, `team` or `enterprise`) and `rateLimitTier` into `/data/home/.claude/.credentials.json`. Before this, sessions on a dashboard-signed-in subscription token showed "Claude API" / "API Usage Billing" in the Claude Code banner, which operators read as API billing. If the profile read fails, the sign-in still succeeds: the token is written without the two fields and a `WARN` is logged. The plan already on file is carried over only when hive recorded it for the same account and organization, so a different account never inherits a stale plan. See [agent-configuration.md](src/docs/agent-configuration.md).
