- Sandboxed kicks no longer push a branch and open a PR just because commits exist: `.hive/agent-report.json` gained an optional `status` (`success`, `failed`, `blocked`), and when the report says `failed`/`blocked` or the sandbox exited non-zero hive keeps the commits local, records the run as failed with the reason (`prWithheld`, shown on the card as "no PR opened: …"), and writes a `sandbox_pr_withheld` audit line instead of a PR that can only fail CI. Reports without a `status` publish as before. Reported-by: @joerunde (a1-vllm-spyre spoke).
