- Issues that already have an open pull request closing them (`Fixes #N`) are no longer claimed or dispatched again: every automated claim now checks open PRs live, labels such an issue `has-open-pr` and logs `claim skipped: open PR already linked`, instead of waiting for the next claim-ledger scan. Disable with `scanner.skip_issues_with_open_pr: false` ([#14804](https://github.com/hivecommons/hive/issues/14804)).
