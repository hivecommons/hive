- Fixed the tool-approval guardrail-path check never seeing the target of a Copilot CLI `apply_patch` call ([#16979](https://github.com/hivecommons/hive/issues/16979)). The tool carries its paths in the patch text (`*** Update File:`, `*** Add File:`, `*** Delete File:`, `*** Move to:`) instead of a path argument, so `ToolRequest.GetFilePath` returned an empty string and a patch touching `.github/workflows/**`, `OWNERS`, `hive.yaml` or `policies/**` auto-approved at L5/L6. `GetFilePath` now falls back to the first path in the patch body, and the new `GetFilePaths` returns every path the request names.
