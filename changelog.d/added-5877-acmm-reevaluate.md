- The ACMM Evaluation panel gained a **🔄 Re-evaluate** button, and `GET /api/acmm/evaluation?refresh=1` bypasses the hour-long result cache ([#5877](https://github.com/hivecommons/hive/issues/5877)). The panel drives a fix-and-verify loop — read the failing criteria, commit the missing file, confirm the criterion flips — but the evaluation was cached in memory for an hour with no invalidation and no refresh, so the confirmation half was unavailable short of restarting the dashboard, and nothing said the numbers were stale. The forced refresh is debounced server-side (a refresh within a minute of the last evaluation returns the cached result), so the button cannot spend the GitHub API budget, and the `Evaluated:` line now renders as a relative age ("Evaluated 43m ago", absolute timestamp in the tooltip) so staleness is legible even without clicking anything. Without `refresh=1` the endpoint behaves exactly as before.
