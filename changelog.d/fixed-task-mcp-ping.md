- Task MCP endpoint (`POST /api/contribute/mcp`): `ping` is answered with an empty result, as MCP requires, instead of "method not found", so an agent's MCP client that pings to check the server is alive no longer reads the hive's task server as gone. Notifications other than `notifications/initialized` (for example `notifications/cancelled`, sent after a client gives up on a tool call) are acknowledged the same way `notifications/initialized` always was, instead of being answered with a "method not found" error. Unknown request methods are still refused with `-32601`. Authentication is unchanged: the endpoint still answers only a caller that presents a valid lease token, launch token or the dashboard token.
