- On a repository whose auto-merge is off, a trusted bot's PR (an `auto_merge.trusted_bot_authors` login such as a Renovate or merge bot) no longer flips between `stage/050-review-pending` and the stage its review verdict routes to. The observe-only pass gives an observation the head's reviewer verdict when a drain by the other driver took the lane's note ([#19380](https://github.com/hivecommons/hive/pull/19380)), but it skipped trusted bots, so their `repo-auto-merge-disabled` observation fell back to 050 while the drain that kept the note routed the approved verdict to 060 or 090. The pass now reads the same verdict the trusted-bot lane notes, advisory downgrade included (`auto_merge.trusted_bot_skip_review`), so both drivers reach the same stage for the same head and verdict. [projectbluefin/common#1721](https://github.com/projectbluefin/common/pull/1721) flipped this way for two days.
