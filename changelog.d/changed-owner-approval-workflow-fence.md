- Contributor-lane auto-merge: a hive owner / trusted merger's explicit approval on the current head — a GitHub `APPROVED` review on that commit, or a dashboard `/hive decision approve` bound to it — now releases the `contributor-lane:workflow-path` fence, so the hive merges an approved PR editing `.github/workflows/**` / `.github/actions/**` itself instead of parking it at `stage/090-ready-for-human-merge` (`auto_merge.contributor_lane.owner_approval_releases_workflow_fence`, default on). Approval on an older head does not count; a merge refused for want of the App's `workflows: write` marks the PR `hive:unauthorized` (`merge-workflow-path`) and parks the approved head at 090 as before. The 085 note for an unapproved workflow-path PR now reads "awaiting owner approval" (#14664).
