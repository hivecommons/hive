- Dashboard chat now keeps its poll cursor honest across reloads, hive restarts and busy channels ([#9135](https://github.com/hivecommons/hive/issues/9135)). `GET /api/chat/messages` returns `{messages, next, epoch, gap, viewer}` instead of a bare list; the browser persists `{epoch, seq}` with the transcript, so a reload no longer replays every retained reply with fresh unread badges, a restart (new `epoch`, or `next` below the cursor) resets the cursor and re-polls instead of silently dropping the next N replies, and a ring eviction (`gap`) renders a marker instead of pretending the tail is complete. Polling runs every 2 s while the panel is open, 10 s while closed, pauses in hidden tabs, and backs off exponentially (60 s cap) on non-2xx or network errors instead of hammering a 401. The panel is documented as one shared channel: another operator's input is rendered as a labelled peer line and kept out of the viewer's own `history`, so it no longer appears as if the viewer typed it.
