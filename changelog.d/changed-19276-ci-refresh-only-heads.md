- CI no longer reruns the heaviest jobs on a pull request head that is only the hive App's base refresh. When the new head is a GitHub-verified App merge of the base whose three-dot diff is unchanged, the same workflow already passed on an earlier head of the refresh chain, and the base delta touches no dependency manifest, Dockerfile, `src/deploy/` or CI definition, the Docker multi-arch build jobs, the FOSSA scan and the Mutation run skip with a `skipped: refresh-only head` step summary. Required contexts (`gate` included) still report success, and `build-and-test`, the test shards and `coverage` always run. Any doubt runs everything. Each refresh used to cost about 38 runner-minutes across 16 workflows. See `src/docs/ci-refresh-only-heads.md` (#19276).
