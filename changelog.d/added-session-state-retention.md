- Hive now prunes CLI session-state directories older than a retention window (7 days by default, `data.session_retention_days`; set it to `0` to disable). Every Copilot CLI invocation creates a session directory under `/data/home/.copilot/session-state`, every agent on a spoke shares that directory because they all run with `HOME=/data/home`, and nothing ever deleted them — one long-lived spoke had accumulated ~9,400 directories spanning three months, at a steady 150-200/day. That is an unbounded leak of the shared `/data` PVC, and because the directory is read on session start it made every agent slower as it grew. The janitor runs at startup and every 6 hours, and decides age from the newest write anywhere inside a session rather than the directory's own mtime — on NFS a directory's mtime does not change when a file inside it is appended, so trusting it would delete sessions that are still live. Note that `data.session_retention_days` shorter than the token scanners' 30-day window necessarily truncates dashboard token history, since a deleted session cannot be counted.
