- Crux stage 4: sidecar agents now get the same credentials as in-process ones. The hive callback gains `agent_mint` (`POST /v1/tokens/mint`) and `bob` (`GET /v1/bob/credential`) families; `crux serve` installs callback-backed `SetAppAuth` (tier-scoped App installation tokens minted by hive over `POST /v1/tokens` and written in place to the per-agent cache), `SetAgentMint`, and the Bob key resolvers, all failing closed (no credential) when hive is unreachable; `sidecarHost` carries every remaining credential setter. Tokens are never logged.
