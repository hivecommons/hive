- Boot and live-rewire wiring of the Project Inception stage observer now goes through the planning-engine registry selected by `runs.engine` ([#10356](https://github.com/hivecommons/hive/issues/10356), part of [#10293](https://github.com/hivecommons/hive/issues/10293)). With `runs.engine` unset and `runs.spektacular.enabled: true` the probe, status card, stage runner and hub executor install are unchanged; `/api/status`'s `spektacular` block additionally reports the selected `engine` name. If a dashboard edit live-rewires to an unknown engine, Hive logs the error and removes the stage runner instead of falling back to another engine.
