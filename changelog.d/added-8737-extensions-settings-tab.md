- The dashboard gains a Settings → Extensions tab covering Spektacular, Flue, Wavefront/Crustify, and relay connection details, so hosted hives with no config file can configure built-in and external extensions entirely from the UI ([#8737](https://github.com/hivecommons/hive/issues/8737)). Spektacular runs can now also be driven from chat and the Runs card: `POST /api/runs/spec` plus new `!runs spec`, `!runs status`, and `!runs list` chat verbs, with Spektacular artifact/status/step attribution shown on run cards.
