- **A forge token is only sent to its own forge block's host.** A `project.repo_policies[].forge_url` on a different host than `gitlab.gitlab_url`, `gitea.gitea_url` or `forgejo.forgejo_url` used to receive that block's token. Config load now rejects the mismatch with an error naming the repo policy and both hosts, and the governor's comment, label and merge paths build no writer for such a repo, so no request leaves. A block with no URL of its own, and a repo whose `forge_url` matches its block, behave as before.
