- **Security:** contributor adoption no longer moves a fork pull request's commits into a `hive/adopt-<n>` branch of the base repository (supersede, DCO re-home, or in-place-stalled re-home). The re-homed PR was a same-repository PR, so the fork's unreviewed code ran with the repository's trusted CI and skipped its fork-only guards; one such run published and signed a canary image. A fork PR the hive cannot finish on the fork's own branch now parks at `stage/085-needs-decision` (`adoption-stalled:fork-rehome-refused`) with a maintainer ask. PRs from branches of the base repository are re-homed as before.
