- A dependency bot's branch name is no longer read as an issue claim. When a pull request names no issue, the hive recovers one from its head branch, and the trailing number of a Renovate or Dependabot branch is the version it bumps: `renovate/registry.fedoraproject.org-fedora-43` claimed issue 43 of its repository, so the supersession sweep posted a "superseded by" notice naming the unrelated pull request that had closed that issue and listed the digest bump to close ([projectbluefin/utah#1494](https://github.com/projectbluefin/utah/pull/1494)), and close-on-merge could have closed an open issue with that number. A `renovate/` head ref, or a Renovate, Dependabot or Mergeraptor author, now makes no branch-name claim in the claim scan, the webhook claim path, the supersession sweep or close-on-merge. A closing keyword or issue reference in the bot's own pull request text still counts, and the branch names of hive agents and people are read exactly as before. There is no new setting.
