- A new `version-absent` drift signal ("Heartbeat without a version") flags a hive whose heartbeats keep arriving with an empty `git_hash` ([#6025](https://github.com/hivecommons/hive/issues/6025)). The hub decides whether to instruct an upgrade by comparing the reported hash against the branch target, so a hive that beats without one is never told to upgrade - it freezes at whatever build it happens to run while still counting as online, and no surface an operator looks at tells that apart from health. Two hives sat in this state for hours: one beat every 120s for hours with 0 successful stats collections behind it, sending last-good cached stats with no version and running digest `14c75aa0` while `:stable` was `ef5a603a`; another showed "No heartbeat for 8h29m" and "Upgrading 29m" at the same time because the hub had no fresh version to update the row with. The signal is critical, fires only after three consecutive version-less beats (about six minutes, so a normal spoke start-up cannot trip it), resets the moment a beat carries a version again, and skips offline hives and pool placeholders exactly as the other fleet-relative signals do.
