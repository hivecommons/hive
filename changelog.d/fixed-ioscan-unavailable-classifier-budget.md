- An ioscan classifier that could not be constructed (no model endpoint for the hive's CLI, e.g. a Copilot-only hive at ACMM L5+) no longer consumes the per-eval classifier budget ([#14629](https://github.com/hivecommons/hive/pull/14629)). Previously the first 64 strings per governor eval were withheld under fail-closed and every later string passed on unclassified as `budget_exhausted`, so whether an agent's kick survived depended on its render position. The fail-open path now also logs the classifier error once per distinct error instead of once per string, which stopped a hosted hive from self-reporting 64 "ioscan classifier failed open" warnings every eval.
