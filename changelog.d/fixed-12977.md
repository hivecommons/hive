- The dependency-bot red-CI hand-off no longer blames the bump for a failure Hive already triaged as transient ([#12977](https://github.com/hivecommons/hive/issues/12977)). An agent that diagnoses a red check as transient or infrastructure-related, not caused by the diff, now ends its triage comment with `<!-- hive-ci-transient head=<sha> check=<encoded name> run=<check run id> -->`, pinned to the head and failing run like `hive-ci-external`. While every failing run at the current head carries one, the hand-off comment says the failure was not caused by the bump and asks for a re-run of the failed check. Without a marker, the comment now lists re-running a transient failure as an option before fixing, pinning or closing the bump. A push or a re-run (a new run id) makes the marker stale.
