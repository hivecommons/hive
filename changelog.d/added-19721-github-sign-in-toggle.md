- **Settings → Dashboard has a GitHub sign-in toggle** (#19721). `dashboard.github_sign_in` (#19618) could only be set by editing `hive.yaml.runtime` on the data volume; it now has a switch next to Hub-proxied auth, and `GET`/`PUT /api/config/dashboard` read and write `github_sign_in`. Turning it off swaps the login page's "Sign in with GitHub" button for a "Sign in through the hub" link and makes the device-flow endpoints (and `hivectl login`) refuse, without a restart. The toggle shows the hub link the login page will use, or warns when `hub.url`/`dashboard.hub_sign_in_url` and `hive_id` are missing. The default stays on.
