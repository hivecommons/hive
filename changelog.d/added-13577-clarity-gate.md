- `runs.triage.clarity_gate` (default off; `enabled`, `threshold` 0-100, default 60; Settings → Features → Incoming issue triage) scores each human-filed, unclaimed issue for goal, acceptance criteria, scope and detail before an agent is kicked on it. An issue under the threshold gets one `<!-- hive:clarity-gate -->` comment with concise questions for its author and the `needs-spec` label (stage/045) instead of a claim; removing `needs-spec` resumes the normal pipeline ([#13577](https://github.com/hivecommons/hive/issues/13577)).
