- The semantic prompt-injection classifier can run through the Claude CLI, launched with no tools, on hives without a model endpoint: set `ioscan.classifier.backend: claude` (or pick it in Settings → Security → Input Defense). A CLI backend makes at most `ioscan.classifier.cli_budget_per_eval` calls per scheduler pass (default 8) and `ioscan.classifier.cli_daily_quota` calls per UTC day (default 500); backends that cannot run without tools (copilot, codex, gemini) are refused at boot.
