- A contributor PR is no longer called "Ready for a human merge" while a required check has never reported on its head. projectbluefin/utah#1074, utah#1072 and utah-packages#873 read "N/N checks green … Ready for a human merge" because they were opened with `GITHUB_TOKEN`, so the ruleset-required checks never ran and GitHub would refuse the merge. The stage pass now reads the base branch's required checks (cached per repo and branch), names the ones with nothing reported ("required not reported: contract"), and keeps the PR at `060-reviewed` until they report.
