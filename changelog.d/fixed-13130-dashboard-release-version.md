- The dashboard now shows the release semver the hive is running ([#13130](https://github.com/hivecommons/hive/issues/13130)). `/api/version` returned only a hard-coded legacy `version` constant and the commit, so the build-stamped semver (`hive --version`, already sent to the hub) never reached the UI. It now exposes it as `release` (omitted when the build has no version), and the sidebar version chip and menu show it next to the commit.
