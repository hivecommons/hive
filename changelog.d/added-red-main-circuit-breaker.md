- Red-main circuit breaker (#13630): when a required check has been red on a repo's default branch for longer than `red_main_threshold` (default `6h`, configurable per repo under `project.repo_policies`), PRs that fix main (the `fixes-main` label, `Fixes` on the `[shared-ci]` tracking issue, or files overlapping the failing check) rank first in the review queue, `hive-open-pr` refuses new PRs in that repo with a message naming the check and the fix PR (existing PRs and issue filing are unaffected), and the repo card shows "main red since <time> on <check>; fix: #N waiting on <who>". A check counts as green only once a run on the tip completes green, so pushes to a red branch do not restart the clock, and a PR naming a just-filed `[shared-ci]` tracking issue opens without waiting for the next sweep. Everything lifts automatically once main is green.
