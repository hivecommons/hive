- Merge-hotspot advisor (`governor.hotspot_*`): the merge train's own PR file lists and rebase conflicts now feed a per-file score of how often concurrent PRs collide on the same file. Files above `hotspot_min_prs` / `hotspot_min_overlaps` in a `hotspot_window_days` window are reported on `GET /api/hotspots` (`hivectl governor hotspots`, `/api/status.hotspots`); a code file of at least `hotspot_min_lines` with two or more top-level symbol groups gets one `refactor: <path> is a merge hotspot — split into <N> units` issue (labels `agent/ci-maintainer`, `kind/cleanup`) through the writeback gate, deduped by `<!-- hive:hotspot file=<path> -->` and refiled no sooner than `hotspot_refile_days` after close. Docs are only ever recommended for a by-section split, generated files point at their source, and the ci-maintainer prompt gains a "Merge Hotspots" section describing the mechanical, no-behaviour-change split.
