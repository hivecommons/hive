- The ACMM panel's bulk **Open All** now reports WHY issue creation failed instead of a bare count followed by template text about the `acmm` + `ai-fix-requested` labels ([#5873](https://github.com/hivecommons/hive/issues/5873)). The server has always returned the underlying GitHub error in the response body — `410 Issues has been disabled in this repository`, a `403`, a `422` — and the single-criterion Open Issue button has always shown it; the batch path discarded the body unread, collapsed every failure mode into `failed++`, and then printed the label note unconditionally, which reads as a diagnosis and pointed operators at labels that were never the problem. Failures are now collected per repo:criterion, deduplicated by reason, and shown in the summary dialog exactly as the single path shows them; the label note appears only when something was actually created, since it describes what a successful create did.
