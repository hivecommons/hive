- Custom agents are no longer invisible in the dashboard's Agents section ([#6488](https://github.com/hivecommons/hive/issues/6488)). The ACMM pack filter in the status builder exists to hide "ghost" pack agents left over from another maturity level, but it also swallowed every operator-defined agent whose name no pack materializes — the agent ran, consumed tokens, and rendered no card. The filter now admits agents present in the live config under a non-pack name, while pack-named agents from other levels stay hidden.
