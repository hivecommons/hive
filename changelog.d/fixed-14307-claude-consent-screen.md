- `claude` agents no longer stop on Claude Code's "WARNING: Claude Code running in Bypass Permissions mode" screen with "No, exit" selected. Hive seeds `skipDangerousModePermissionPrompt` into the shared Claude settings that `claude` agents read, so the screen does not appear. If it appears anyway, a kick selects "Yes, I accept" instead of restarting the CLI into the same screen, and the watcher's consent-stuck dismissal now covers `claude` agents as well as inference backends ([#14307](https://github.com/hivecommons/hive/issues/14307)).
