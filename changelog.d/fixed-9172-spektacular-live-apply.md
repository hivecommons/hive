- **Dashboard → Extensions → Spektacular settings now apply without a restart** (#9172). Enabling, disabling or retuning Spektacular or its hub executor re-probes the binary and rewires the stage runner and executor in the running hub; a hub executor mid-stage keeps running and picks up the change once that stage finishes. The save response carries `spektacularApply` (`live` / `deferred` / `restart`) and the dashboard warns when the change is not yet live. `PUT /api/config/governor/features` now returns 500 when the config cannot be persisted instead of reporting success.
