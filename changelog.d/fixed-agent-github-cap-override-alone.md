- **A replica takes its base agent's GitHub API hourly cap even before the next reload.** A replica or review head (`reviewer-2`, …) with no `agents.<name>.github_api_hourly_cap` of its own now takes its base agent's override directly, so an override set on the base applies to its replicas at once instead of after the config is next reloaded. The lookup order is the agent's own value, then the base agent's, then `agents.github_api_hourly_cap`, then the default of 300; `0` means no cap at either level. See [Runtime and quota](src/docs/operator-reference/runtime-and-quota.md).
