- The Hub's GitHub browser-login contract tests now cover PKCE end to end ([#14598](https://github.com/hivecommons/hive/issues/14598)). The tests check that the authorize redirect carries the S256 challenge of the `hive_oauth_pkce` cookie and that the token exchange sends that exact `code_verifier` in the form body. A missing, expired, malformed or truncated verifier must fail with `400` before the code is redeemed. A verifier GitHub rejects must not create a session or user record. The verifier must never appear in a request URL or the logs. `src/docs/hub-login-token.md` now documents the PKCE step and the fail-closed behavior. Login behavior is unchanged.
