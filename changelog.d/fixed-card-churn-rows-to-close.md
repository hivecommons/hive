- **Overview card: an issue several pull requests have not settled is Yours to close, not Triage.** The contributor queue withholds such an issue (reason `issue_churn`). A person ends that by closing it or adding the label `hive: churn-triaged`; otherwise it lapses about 14 days after a scan last saw its pull requests. Nothing reads a comment, so the row's old advice to "say what is left" did not clear it, and the Triage count looked like triage work it was not. The row now sits in Yours to close and reads, for example, "3 PRs merged (#1236, #1240, #1251) and it is still open; close it if it is done, or add hive: churn-triaged to give it back to agents." The Triage rule now reads "Confirm the gap, or triage it.", and the Yours to close rule reads "The hive thinks it may be done or no longer needed but won't close it itself. Close it, or keep it open." The old `card_band=your-turn` filter on the exports and the `issues_by_band` MCP tool still returns these rows, as it did before the Your turn split. This is display only: the churn guard, the queue, the inbox, ownership and labels are untouched.
