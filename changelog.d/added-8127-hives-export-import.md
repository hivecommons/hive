- `hivectl hives export <name>` / `hivectl hives import <bundle>` move one hive profile to another machine as a passphrase-encrypted bundle (AES-256-GCM over PBKDF2-HMAC-SHA256, no plaintext token in the file), replacing the documented `scp ~/.config/hive/contributor.env`; `hivectl hives session <name> --label <x>` copies a profile under a session label so two relays can run against one hive as two hub sessions, and the generated `contributor.env` now removes a stale `HIVE_SESSION` when you switch to a hive that has no label ([#8127](https://github.com/hivecommons/hive/issues/8127)).
