Fixed: contributor-protocol generation fencing is no longer opt-in. Omitting `task_gen` decoded to `0`, the exact value that disabled the kubestellar/hive#2568 stale-generation Gate, so any client could bypass fencing at every call site. The legacy `clientGen == 0` escape is now ratcheted per connection: once a connection has echoed a real generation it may not downgrade itself back to unstamped. Genuinely unversioned relays are unaffected.
