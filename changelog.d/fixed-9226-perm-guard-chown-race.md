- The shared-home permission sweep no longer locks agents out of the session files they just created ([#9226](https://github.com/hivecommons/hive/issues/9226)). It ran chmod and `chown dev:node` as separate walks, so a file an agent created between them was handed to `dev` while still owner-only (`0600`). The creating agent then got `Permission denied` until a later repair, and copilot's `session.send` failed with "Failed to append to JSONL file …/events.jsonl". The sweep now does a single walk. Files owned by an agent keep their owner and are only regrouped to `node` and opened to the group. Only root-owned entries are still handed to `dev`, and only after that entry's own chmod has succeeded.
