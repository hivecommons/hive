- The shared-home permission sweep no longer locks agents out of the session files they just created ([#9226](https://github.com/hivecommons/hive/issues/9226)). It used to run chmod and chown as separate walks, so a file an agent created between them was re-owned to `dev` while still owner-only (`0600`). The creating agent then got `Permission denied` until the next sweep, and copilot's `session.send` failed with "Failed to append to JSONL file …/events.jsonl". Each sweep now does one walk and chmods every entry before and after it chowns it, so every entry it repairs ends group-writable.
