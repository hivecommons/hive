- Both dashboards now show scheduled-upgrade progress ([#14950](https://github.com/hivecommons/hive/issues/14950)). The hub hive card and the spoke's version menu render the upgrade state as a pill — `Draining · 2/5 agents in turn: reviewer 38m, scanner 12m · 14m left`, `Missed window · drain lapsed` — and list the hub's recent upgrade attempts so a missed window is visible on both sides. `/api/version` carries `upgradeProgress` and `upgradeHistory`. Owners get an **Upgrade now (interrupt turns)** action on the hub card while a hive is draining or missed; it is the normal upgrade request with `?interrupt=1`, audit-logged, delivered on the next heartbeat as `upgrade_interrupt`, and makes the spoke skip its drain and restart immediately.
