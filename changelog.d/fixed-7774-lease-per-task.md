- A contributor identity that holds more than one task at a time (allowed for the contributor tier and above) no longer loses an earlier task's lease when a later one is assigned: the hub keeps one lease per task, so a brief disconnect on any of them resumes that task instead of revoking a healthy agent mid-turn and requeueing its issue as failed. Persisted lease files from before this change load unchanged ([#7774](https://github.com/hivecommons/hive/issues/7774)).
