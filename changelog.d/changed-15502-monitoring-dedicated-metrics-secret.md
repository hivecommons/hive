- `HIVE_METRICS_TOKEN` now lives in a dedicated `hive-metrics-token` Secret instead of `hive-secrets`: the base Deployment (`src/deploy/k8s/deployment.yaml`), the opt-in monitoring component's Deployment patch and its `ServiceMonitor` all read it from there, so the scraper never needs read access to `hive-secrets`. Before upgrading, copy the existing value into the new Secret (`kubectl -n hive create secret generic hive-metrics-token --from-literal=HIVE_METRICS_TOKEN="$(kubectl -n hive get secret hive-secrets -o jsonpath='{.data.HIVE_METRICS_TOKEN}' | base64 -d)"`), then optionally drop the key from `hive-secrets`; see `src/docs/monitoring.md` and the component README. A new `kustomize-render.yml` workflow renders every kustomize overlay, plus the k8s/-based overlays with the monitoring component, in CI.
