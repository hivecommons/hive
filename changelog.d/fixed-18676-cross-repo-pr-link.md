- A PR opened in another managed repository that references a hive issue (`Refs owner/repo#N`, e.g. a quorum-companion PR for a hivecommons/hive issue) now gets the issue's PR-link stage note naming the PR's repository, looked up where the PR lives, and the issue's stage reason carries the PR's stage. The hive agent's claim on the issue is held while that cross-repo PR is open and released when it merges or closes, so the issue no longer looks abandoned and re-dispatchable once the agent TTL lapses ([#18676](https://github.com/hivecommons/hive/issues/18676)).
