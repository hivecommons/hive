- Sandboxed agents (`sandbox.runtime: job` or Podman) no longer render as "Stopped — see the agent's log" / "session down" with a red dot and empty TOKENS/SESSIONS between kicks. Their health now derives from the last run: green when it succeeded and the next cadence occurrence is still ahead, amber while a kick is in flight, red only when the last run failed/timed out or a scheduled occurrence was missed past a grace. Each run's outcome, summary and token usage are persisted under `<work_dir>/sandbox-runs/`, restored on restart, and ingested by the token collector so tokens, sessions, cost and the activity summary reflect sandboxed work.
