- `just contribute-hive` now refuses an unknown backend or mode before pulling or starting anything, accepts `krun` as a mode equivalent to `HIVE_CONTAINER_OCI_RUNTIME=krun`, and no longer suggests `just contribute-hive <backend> local` for a backend that does not exist (#13249).
- The v6 launcher now defaults `HIVE_CONTRIBUTOR_IMAGE` to `ghcr.io/hivecommons/hive-contributor:edge`, the image built from v6, so interactive krun sessions reach the CLI through the VM console instead of starting a v5 image nobody can attach to (#13248).
