- `GET /api/agents` returns agents in name order. It walked the agents map, so the order changed on every call. The admin MCP `agents_list` tool keeps only the first `limit` entries (20 by default, 50 at most), so on a hive with more agents than the limit each call returned a different, random subset and no call could be relied on to show a given agent; `agent.resume` previews, which look an agent up in that list, were affected the same way. `hivectl agent list` output is now stable too.
