- Branch updates and review submissions left `Unknown` in the mutation journal no longer refuse retries indefinitely: the next attempt reconciles the operation from GitHub (the PR head for `branch_update`, the PR's reviews for `review_submit`) and, when GitHub cannot be read, expires it after one hour so the retry can run ([#13870](https://github.com/hivecommons/hive/issues/13870), [#13873](https://github.com/hivecommons/hive/issues/13873)).
