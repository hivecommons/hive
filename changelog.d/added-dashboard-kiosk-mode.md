- The dashboard accepts `?kiosk=1` for an unattended display mode ([#15596](https://github.com/hivecommons/hive/issues/15596), part of [#15594](https://github.com/hivecommons/hive/issues/15594)): only the Hive activity monitor renders, full viewport, with the sidebar, topbar, notices and every other section hidden and no Welcome or feedback dialog opening on its own, so a headless browser can stream it. Without the parameter the dashboard is unchanged.
