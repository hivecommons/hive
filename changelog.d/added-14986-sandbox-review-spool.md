- A sandboxed reviewer can now post reviews ([#14986](https://github.com/hivecommons/hive/issues/14986)). Every sandbox kick (Podman or `sandbox.runtime: job`) gets a review spool at `.hive/review-requests` in its workspace, and `hive-review` inside the sandbox writes there via `HIVE_REVIEW_REQUEST_DIR`. The review relay picks spooled requests up through the same policy path as the pod-local drop box, attributing each one to the kick's agent from a hive-owned manifest under `<work_dir>/sandbox-review-spools`, never from the file's contents. Because the spool is group-writable, each kick also gets its own random spool key (`HIVE_REVIEW_SPOOL_KEY`, passed only through the sandbox environment), and the relay accepts only requests that carry a valid HMAC under that key and haven't been accepted before, so another agent can't post a review as the sandboxed reviewer by dropping a file into its spool. A reviewer on an accelerator spoke can now run the change on the card node and post its verdict from there.
