Skipping the dashboard `/lgtm` + `/approve` commands after a Prow rejection now believes only the Prow bot (`kubestellar-prow[bot]`), not any installed bot quoting the rejection phrase ([#15263](https://github.com/hivecommons/hive/issues/15263)).
