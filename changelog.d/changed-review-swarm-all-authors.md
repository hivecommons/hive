- The review swarm now reviews **every open PR regardless of author** — hive agent, human, clanker at either trust tier, dependabot and any other bot — whenever PR review is on (`review.require_approval` + `review.fan_out`); the only switch is the review feature itself. `review.all_authors` is a deprecated no-op (still accepted, logged once). The automerge review gate now also covers the `trusted-bot` and `trusted-author` lanes, so a human's PR waits for the swarm verdict the same way the App's own does; previously human PRs merged through the trusted-author tier with zero swarm reviews ([#12974](https://github.com/hivecommons/hive/issues/12974)).
