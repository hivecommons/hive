- **Weekly competitor and SWOT report to Discord `#related-research`.** A new GitHub Agentic Workflow, `.github/workflows/weekly-competitor-report.md` (compiled to `.lock.yml` with the pinned gh-aw `v0.89.21`, Copilot engine, `copilot-requests: write`), runs every Monday at 13:00 UTC and on manual dispatch. It researches projects adjacent to Hive (OpenHands, SWE-agent, Devin, Copilot coding agent, Codex, Claude Code, Sweep, Factory, Jules, Gastown, Dagger, Kilo, Cline/Roo, Mentat, Aider, GPT-Engineer, Potpie, Agentless, public fleet-orchestrator write-ups) with read-only GitHub tools and proxy-aware `curl` inside a network allowlist, then writes a 600-900 word plain-language report with "What changed this week", a "Who does what" table, a cited SWOT for Hive, and "One thing to watch". The report is appended as a comment to tracking issue [#14613](https://github.com/hivecommons/hive/issues/14613) and posted to Discord in 2000-character chunks through a custom safe-output job that reads the `DISCORD_RELATED_RESEARCH_WEBHOOK` repository secret. The workflow commits nothing and has no repository write permission ([#14612](https://github.com/hivecommons/hive/issues/14612)).
