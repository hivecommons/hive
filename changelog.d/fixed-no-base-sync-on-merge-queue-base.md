- With `auto_merge.require_current_base` on, the hive no longer merges the base into a PR whose base branch only accepts merges through GitHub's merge queue (projectbluefin/finpilot#599). The hive cannot enqueue and the queue tests base plus PR itself, so each `base-moved` update only moved the head off its review and the PR waited for a fresh one, three times in a day. The gate now skips the update for 24 hours after the last `merge-queue-required` refusal on that base, and the PR holds at `100-merge-queue`; the 30-minute merge-queue memory no longer has to stay fresh between refusals for that.
