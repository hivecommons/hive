- Fix owner-only hand-offs never reaching the "Your turn" inbox ([#12329](https://github.com/hivecommons/hive/issues/12329)). A pull request not written by Hive whose review verdict on the current head is `requires_human` is now your turn (`REVIEW`, reason code `review_requires_human`), matching the `human_hold` stage `/api/review/pipeline` already showed; a newer push with no verdict yet clears it, and Hive-authored PRs keep their `needs-human` / adjudicator rules. Agents can now park an existing issue whose remaining step only the owner can take with `hive-open-issue comment --needs-decision`, which applies the configured needs-decision label before posting the comment, and every scanner policy tells them to do so instead of leaving the issue unlabelled for its claim to lapse.
