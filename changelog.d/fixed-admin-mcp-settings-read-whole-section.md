- Admin MCP: `settings_read` returns a Settings section whole. It went through the list tools' row cap, which keeps the first 20 entries of a list by default, although `settings_read` has no `limit` argument to raise it. On a hive with more than 20 agents the governor settings came back with 20 agents (`agents_truncated: true`), and a section that is itself a list, such as `backends`, was cut to 20 entries, with no way to read the rest. A section is now bounded only by the 256 KiB text cap. The list tools (`agents_list`, `runs_list` and the others) keep their cap.
