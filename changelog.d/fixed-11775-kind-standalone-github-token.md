- The `kind` and `standalone` Kubernetes overlays now wire the GitHub PAT into `hive.yaml` with `github.token: ${HIVE_GITHUB_TOKEN}`, matching `src/hive.yaml.example`. Before this, a pod set up by following `try-hive-on-kind.md` crash-looped with `github.token, github.app_id or github.forge is required` even though `hive-secrets` held the token. The kind smoke test (`src/deploy/test_kind_quickstart.sh`) now creates `hive-secrets` with placeholder tokens so the rollout can succeed, and the kind guide explains that fixing the config after a failed first boot also means deleting the `hive-data` PVC or `/data/hive.yaml.runtime` ([#11775](https://github.com/hivecommons/hive/issues/11775)).
