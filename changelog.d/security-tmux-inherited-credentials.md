- Credentials the hive process holds in its own environment no longer reach agent panes. Every per-agent tmux server inherits the hive's environment into its global environment, and the creation-time strip used `set-environment -u`, which only deletes the session entry and lets the global value show through — so the Linear work-source key (`LINEAR_API_KEY`, the operator's personal key), the Linear OAuth app's `LINEAR_CLIENT_SECRET` and `LINEAR_WEBHOOK_SECRET`, and the full installation token `HIVE_GITHUB_TOKEN` were present in every agent shell. Observed: an agent holding the sanctioned OAuth `LINEAR_ACCESS_TOKEN` used the personal key instead, so every issue it filed was created by the operator rather than by the Hive app user. Session creation now records a `-r` removal for each inherited credential before setting the tier's sanctioned pair, and the downgrade refresh tick removes with `-r` too; a real-tmux regression test forks a pane and asserts what it sees.
