- A contributor websocket that ends without a close frame (code 1006 — relay killed, laptop slept, NAT timeout) is now logged at INFO as a dropped connection instead of a WARN `[contribute-ws] read error`, so routine contributor network drops no longer surface as `unclassified_error_repeated` fleet self-reports; close codes that name a protocol or policy problem still log at WARN ([#14163](https://github.com/hivecommons/hive/issues/14163)).
