- Agents: the coding CLIs' own persistent auto-memory is now off by default. Hive seeds Claude Code's `autoMemoryEnabled: false` and Codex's `[features] memories = false` at launch, and an operator's explicit setting still wins. The new fleet block `agents.cli_memory` takes `auto_memory: true` to leave memory on and `clear_on_kick: true` to remove the agent's own memory store before every kick; stores shared with other agents are skipped ([#17032](https://github.com/hivecommons/hive/issues/17032)).
