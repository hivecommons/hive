- RFC lifecycle notices no longer post RFCs from private repositories (titles and links) to `notifications.discord.rfc_channel_id` unless `notifications.discord.rfc_include_private: true` authorizes it. The gate applies in every mode, line mode included. Repo visibility is resolved once per repo and cached for an hour. A repo whose visibility cannot be resolved, or that is `internal`, counts as private (fail closed). Withheld RFCs still advance the detector state, so they never replay later (#15926, part of #15869).
