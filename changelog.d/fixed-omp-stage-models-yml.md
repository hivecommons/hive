- **omp container mode now stages `models.yml`.** Custom providers (a self-hosted llama.cpp/vLLM/OpenAI-compatible server, a gateway) live in `~/.omp/agent/models.yml`, which `just contribute-hive omp` never copied, so a `modelRoles` default or advisor naming one did not exist in the container and omp fell back to another model. `bin/omp-backend.js --stage` now ships `models.yml`/`models.yaml` narrowed to the selected providers' blocks (another provider's literal `apiKey` or headers never travel), refuses a file it cannot narrow, and `--describe` no longer asks you to sign in to a provider that `models.yml` configures with `auth: none` or its own `apiKey`.
