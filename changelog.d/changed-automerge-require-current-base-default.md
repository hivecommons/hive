- **Breaking (merge behaviour):** the auto-merge current-base gate (`auto_merge.require_current_base`) is now on for every repository by default. A green head whose base has moved is brought up to date with GitHub update-branch and merges once CI is green on the new head; a stale-green merge (#15236) had broken `v5` for every open PR for 20 minutes. Opt a repo out with `auto_merge.skip_current_base: [owner/repo]`, or set `auto_merge.require_current_base_default: false` to return to opt-in only. Repos listed explicitly in `require_current_base` are strict; repos gated only by the default merge a head the App cannot update (fork without maintainer edits, branch protection) as tested, with one WARN per PR ([#15335](https://github.com/hivecommons/hive/issues/15335)).
