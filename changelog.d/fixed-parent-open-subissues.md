- An issue with open sub-issues is no longer offered to contributors, and is no longer labelled done or closed on a contributor's word while a sub-issue is open. A maintainer moved an approved design issue's remaining work into three native GitHub sub-issues. The parent had no tracker label, no tracker title prefix and no child list in its body, so the contributor queue treated it as ordinary work and offered it; the contributor answered `no_work_needed` / already done, citing the merged design PR; the relay put `hive/already-done` on the parent, and the hub recorded the merged PR as settling it, added `hive/likely-done` and went on to close it as completed, with all three sub-issues still open. Now: the contributor offer path treats an issue whose sub-issues are not all closed as a tracker on both the assignment path and the queue (`tracker` in the Withheld list, detail `has N open sub-issues`), using the sub-issue count the enumeration already puts on the row, with no extra GitHub call; a webhook re-read of the issue keeps that count on its row, which it used to drop until the next enumeration. Before the hub records a merged-PR settlement from a verdict it checks the issue's sub-issues, from the row when it shows an open one and otherwise from one fresh read of the issue, and with an open sub-issue (or a read that fails) it records no claim, applies neither `hive/likely-done` nor the already-done label, posts no "already resolved" comment and does not close; it logs `parent has open sub-issues; not marking done` once and leaves the `no_work_needed` offer hold in place. The PR-claim label sync no longer adds `hive/likely-done` to such a parent and removes one it carries. The relay reads the issue's `sub_issues_summary` before it applies the already-done label and skips the label when a sub-issue is open or the read fails. An issue with no sub-issues, or with every sub-issue closed, is offered, labelled and closed exactly as before, and a parent still closes through the existing sweep once all its sub-issues are closed.
