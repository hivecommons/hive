- Added `PATCH /api/hub/v1/registrations/{id}` (rollout step 1 of [#18642](https://github.com/hivecommons/hive/issues/18642)): a self-hosted hive's owner can change `repos` (a full list or `{add, remove}`) and `dashboard_url` in place without re-registering, so the running spoke keeps its heartbeat key. Only added repos get the read-only GitHub ownership check, `If-Match` with the registration's strong `ETag` is required (`428` when missing, `412` when stale), a refused proof leaves the record unchanged, and `org` is not editable. Still behind `HIVE_HUB_SELFSERVICE_REGISTRATION`.
