- Task MCP: `related_work` and `history` judge citations of the task's issue correctly. An item counted as related when its title or body held `#N` followed by a boundary, whatever stood before it, so issue 42 of any other repository (`kubernetes/kubernetes#42`) and text such as `abc#42` counted as a citation of this repository's issue 42 and unrelated items were served as related work. A full link to the issue (`https://github.com/owner/repo/issues/42`) did not count at all. A bare `#N` now counts only at the start of the text or after a character that cannot end a repository name or a word; `owner/repo#N` must be this repository; and a link to the issue or pull request in this repository counts (including GitLab's `/-/issues/N`).
