- `hivectl tui --hives` gains the Hub → Hive → Repository contribution tree (press `t`) with staged *Apply* and truthful receipts, at parity with `hivectl hives web`. The tree is built from the same credential-free read model and edited through the same staged-edit session as the web page: select/deselect current, follow, exclude/clear exclusion, enable/disable, hub enable/disable and legacy *Review and restrict* are staged in the overlay and written only on `A`, which lists the complete diff first and then reports *saved* / *relay reload* / *acknowledged* separately so a saved-but-not-yet-adopted change is never shown as live. Discovery outages are labelled per branch and never rendered as an empty or wildcard hive; a save by another surface since the tree opened is reported as stale with a fresh tree instead of being overwritten. The repository discovery call and the diff review lines moved into `pkg/hivectl` so `hives repos`, the web page and the TUI share one implementation. Refs #13153.
