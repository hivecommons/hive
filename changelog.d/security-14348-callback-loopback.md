- The hive capability endpoint (`callback.Listen`, bound from `$CRUX_HIVE_LISTEN`) now refuses a TCP address off loopback, the same fail-closed rule `crux serve --listen` has applied since #13967. The listener is plain http gated by `$CRUX_HIVE_TOKEN`, and it serves `POST /v1/tokens`, which mints GitHub App installation tokens — a routable bind would have carried both the bearer token and every minted token across the network in cleartext. The k8s sidecar-container option is unaffected: the containers share the pod's network namespace, so `127.0.0.1` reaches the sidecar. Remote access goes through a TLS-terminating proxy. (#14348)
