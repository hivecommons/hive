- **Claude/litellm local mode can now actually write where it was told it could** (#6082, #6087). Two compounding defects left `just contribute-hive claude local` agents denied on nearly every write. First, the `permissions.allow` rules #5147 added spelled absolute paths with a single leading slash — but Claude Code anchors `/path` rules at the settings source, with `//path` as the true absolute form — so `Edit(/var/home/u/workspace/**)` matched nothing and Edit/Write inside the granted workspace were denied under `dontAsk` (37 denials in one observed session). Second, `HIVE_AGENT_CWD`, the directory the launcher cd's the agent into, appeared in the sandbox comment's stated intent but in none of the actual grants — not `filesystem.allowWrite`, not `permissions.allow`, not `--add-dir` — so every relative-path scratch write was denied too. The rules now use the `//` absolute spelling, `HIVE_AGENT_CWD` is a second write root in all three grants (exported before the permission flags resolve, degrading gracefully to workspace-only when unset), and the pinned test asserts the exact rule spelling so an inert-rule regression fails in CI rather than in a contributor's pane.
