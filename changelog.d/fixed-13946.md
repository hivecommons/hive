- **Contributor quota guard now scopes to the active model's provider pool** (hivecommons/hive#13946). The contributor relay's quota guard evaluated every agy quota window regardless of which model the contributor actually runs, so an exhausted Claude/GPT (`3p-*`) window paused Gemini contributors that never draw from it. The guard now keeps only the windows of the effective model's pool (Gemini → `gemini-*`, Claude/GPT → `3p-*`); unknown models, non-agy backends and unrecognised window ids are still evaluated conservatively, and the hold message continues to name the triggering window.
