- Contributor dispatch honours the target branch an issue declares — a `[vN]` title prefix or a `**Target: <branch>.**` body line — checking it against the repository's branch list (cached per repo per sweep) and telling the agent to base on and open the PR against it, falling back to the default and saying so when the branch does not exist (`hub.contribute_honour_target_branch`, default `true`; `task_assign` now carries `base_branch`). A new contributor verdict form, `HIVE_VERDICT: no_work_needed — wrong_base: <branch> — <reason>` (`verdict_reason_kind: "wrong_base"` with `evidence.branch`), replaces `already_done` when the code simply lives on another branch: the hub never applies `hive/already-done` or closes the issue for it, re-offers the issue against the named branch when it exists (recorded in the contribute ledger), and parks it under the needs-decision label through the stage engine when it does not ([#13146](https://github.com/hivecommons/hive/issues/13146)).
