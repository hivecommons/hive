- A GitHub 5xx on an issue stage-label write (`issue stage labels: write failed`) no longer files an `unclassified_error_repeated` fleet self-report ([#19887](https://github.com/hivecommons/hive/issues/19887)). The stage engine marks the write uncertain and the next sweep re-reads the issue and reconciles its labels, so a transient upstream error is not a hive defect; the warning stays in local logs, and 4xx or non-label failures remain reportable.
