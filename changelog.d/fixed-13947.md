- **Review-backlog hosts closed before the split sweep shipped are now split too** (hivecommons/hive#13947). The closed-host split sweep from #13914 only lists issues updated inside its 48h window, so a review-backlog host closed earlier (e.g. #13823, #13629) kept its still-unchecked folded findings closed with it. A one-off `BackfillReviewBacklogSplits` pass now runs after each split sweep: it walks the review-backlog ledger's host index, fetches each host directly and splits every closed one through the same idempotent path (ledger `split_keys`). Once a pass visits every host without hitting the per-pass cap or a transient error, the ledger records `split_backfilled` and later passes are no-ops.
