- A contributor-lane PR on a hive whose review swarm is off no longer waits at `050-review-pending` forever. `auto_merge.contributor_lane.require_reviewer_verdict` (default on) wanted a reviewer verdict whenever a reviewer agent existed, but the review planner only asks reviewers when `review.require_approval` and `review.fan_out` are both on. On a self-hosted spoke with the swarm off, twelve green docs PRs sat at "Review swarm requested; waiting for a verdict" with the Review track reading "0/5 · in progress" and nothing dispatched. Such a head now skips as `contributor-lane:review-off` and parks at `085-needs-decision` with that cause, and the Activity Monitor's Review track says a person must review instead of "in progress".
