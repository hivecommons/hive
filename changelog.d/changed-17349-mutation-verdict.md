- CI mutation report (`src/scripts/mutation-report.sh`): the `<!-- hive-mutation -->` PR comment now also lists NOT COVERED mutants in changed files and tells a zero-mutant run apart from a broken one — a SKIPPED mutant on a line the PR added is flagged as a diff-matching fault, while added lines with nothing gremlins can mutate (a unary `!`, a bare `return`) are reported as such instead of "no surviving mutants". A new `verdict` phase exits non-zero on `lived`/`misrouted` and warns on `uncovered` unless the PR carries `mutation/acknowledged`, so a workflow can block on it (#17349, Phase 2).
