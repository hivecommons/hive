- RFC lifecycle notices to Discord: with `notifications.discord.rfc_channel_id` set (env `HIVE_DISCORD_RFC_CHANNEL_ID`; default empty, off) and a bot token, the hive posts one line to that channel when an RFC issue in a managed repo is opened (`RFC opened: #N <title> - <url> (by @author)`), closed (`RFC closed (completed|not planned): ...`), or taken off hold so it can be implemented (`RFC ready to implement (hold removed): ...`, on `hold` coming off an open RFC or a held RFC reaching `stage/010-actionable`, once per hold episode). An RFC is an issue with the `rfc` label or an `RFC`-prefixed title. The detector (`pkg/rfcnotify`) polls issues updated since its last pass and keeps per-issue records in `/data/rfc-notify.json`, so restarts never re-post and the first pass only records the baseline. Operators see each post in the audit log as `rfc-notify` (#14616).
