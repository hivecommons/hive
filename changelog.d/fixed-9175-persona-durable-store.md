- Chat personas now survive a restart ([#9175](https://github.com/hivecommons/hive/issues/9175)). `!persona setup` answers, learning signals, pending suggestions and accepted-adjustment history used to live in a per-transport in-memory map, so every spoke restart silently reset run summaries to the defaults. The spoke now keeps them in `/data/chat-personas.json`, one file shared by the dashboard, Discord, Slack, Telegram, Matrix and Microsoft Teams transports and keyed by transport and author ID. If the file cannot be read at startup the spoke logs `chat persona store unavailable`, leaves the file untouched and keeps personas in memory until the next restart. The hub **Persona profile** section and `GET /api/persona/profile` are removed: nothing ever wrote a persona to a hub user record, so the section never had anything to show, and the docs no longer say personas are stored on the hub.
