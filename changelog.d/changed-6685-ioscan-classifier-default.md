- The `ioscan` semantic classifier is now on by default at ACMM L4–L6 (off at L1–L3; `ioscan.classifier.enabled` overrides). A new `ioscan.classifier.fail_mode` says what happens when the classifier cannot answer: `open` passes the rule-cleaned text on, `closed` withholds it. Unset, it follows `ioscan.fail_mode`, so it is closed at L5–L6. At L5–L6 a hive with no model endpoint configured withholds untrusted text until one is set or the classifier is turned off; the boot log says so. Cost is one cached model call per untrusted text per pass, documented in `docs/ioscan.md` ([#6685](https://github.com/hivecommons/hive/issues/6685)).
