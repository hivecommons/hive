- **Activity Monitor Matrix: bounded, scrub-drop line source behind `dashboard.matrix`** (#15934, part of #15862). When `dashboard.matrix` is enabled with an allowlist, the sentinel's existing patch fetch now feeds an in-memory source of pushed lines — no new GitHub calls, nothing written to disk. Only hive-identified authors on public, allowlisted repos are admitted; secret-shaped and generated paths are skipped before parsing; any line that `logscrub` would change, that already carries a redaction marker, that looks high-entropy or exceeds 160 runes is dropped rather than masked. Ingest is non-blocking (a full 64-slot channel drops and counts), with dedup per PR, 200 lines per head, a 2,000-line backlog and a per-minute rate cap. Default off: with the flag off no observer is registered and nothing is retained. No HTTP surface yet; the endpoint follows in #15935.
