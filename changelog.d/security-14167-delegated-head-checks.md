- "Let hive decide" (`POST …/items/{number}/decide-delegated`) no longer reads a pull request head as CI-green from `mergeable_state` alone. GitHub reports `blocked` both for a missing required review and for red required checks, and `unknown`/`behind` say nothing about the head, so the delegate could approve a PR whose required checks were failing or had never run and record it as a "green head" decision. The gatherer now settles those states from the head's combined status and check runs — no red, nothing pending, at least one green — the same way it already judged a competing PR, and such heads get the `fix-then-merge` direction instead of an approval ([#14167](https://github.com/hivecommons/hive/issues/14167)).
