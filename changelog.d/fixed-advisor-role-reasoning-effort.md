- The advisor lane now uses the reasoning effort of the model role it names. With `advisor.model: "@<role>"`, each review sends the role's `reasoning_effort` to the reviewer endpoint as `reasoning_effort`, on every backend; before, only the model was sent and the endpoint's default effort applied, whatever the role said. The review record, the agent's advisor list and the Advisor Lane settings view (`resolved_reasoning_effort`) now show the effort beside the model. A literal model id sends no effort, as before. A review that asks for an effort may use up to 16 000 output tokens so the model's reasoning does not crowd out the verdict.
