- Public knowledge MCP (`/mcp/knowledge`): on a running hive, a `GET` or `HEAD` is answered `405` with `Allow: POST`. The path was registered for `POST` only, and the dashboard's static file server takes every `GET` no other route claims, so a `GET` on the endpoint came back `404` from the file server. The MCP transport lets a client ask for an event stream with a `GET` and says a server with no stream answers `405`; a `404` reads as "no such endpoint". `POST` behaves as before, other methods were already answered `405`, and a switched-off endpoint still answers `404`.
