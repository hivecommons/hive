- A pack agent such as the L2 `reviewer` now follows the hive's inference gateway even when the operator's agents were put on that gateway without a `backend_owner` stamp (set in `hive.yaml`, on a hive older than ownership stamping, or via `POST /api/config/governor/agents`). Before, only operator-owned backends counted, so no gateway was found and the reviewer stayed on copilot. An unowned CLI backend still neither picks nor vetoes the gateway, and `POST /api/config/governor/agents` now stamps an explicitly named backend/model as operator-owned (#14678).
