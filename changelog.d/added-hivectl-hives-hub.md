- `hivectl hives hub add|list|show|remove` tracks hubs in a new optional `hubs:` key of `profiles.yml` and reads each hub's federation registry (`GET /api/hives`) to list its advertised Hives, marking which ones you have already onboarded. Tracking is discovery only: no credentials are stored and nothing is registered. A redirect, error status or malformed registry reports the hub as unavailable instead of empty (#13174).
