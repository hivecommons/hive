- Fix the Microsoft Teams chat backend (v6) so notifications, command replies, and checkpoint approvals keep working. Outbound messages now go to a Teams **Workflows** webhook as an Adaptive Card envelope, because Microsoft retired the Office 365 Incoming Webhook connectors the backend used to post to. Point `notifications.msteams.webhook_url` at a Workflows "Post to a channel when a webhook request is received" URL ([#9155](https://github.com/hivecommons/hive/issues/9155)). An expired Graph delta token (HTTP 410 / `resyncRequired` / `syncStateNotFound`) now triggers a fresh delta baseline, with a WARN that shows the gap, instead of retrying the dead link forever and silently dropping all inbound commands ([#9156](https://github.com/hivecommons/hive/issues/9156)). Thread replies under the bot's recent posts are now polled via `/messages/{id}/replies`, so replying `approve` to a checkpoint prompt works. The inbound dedupe set is capped at 1024 IDs, the same limit Matrix uses, so it no longer grows without bound ([#9157](https://github.com/hivecommons/hive/issues/9157)).
