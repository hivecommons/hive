- The blocked sweep now waits on every blocker a blocked-on comment (or the issue body) names, not just the first. An issue blocked on two issues was unblocked and called "actionable again" as soon as the first one closed while the second was still open. `blocked` now comes off only once every named PR has merged or closed and every named issue has closed, with one note naming them all; `pr=` and `issue=` markers in the same comment are both honored, and a re-target of one blocker carries the others' markers forward. A single marker behaves as before.
