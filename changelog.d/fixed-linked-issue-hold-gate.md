- Merge lanes no longer merge a PR whose linked issue is on hold or parked for a decision. The self-authored, trusted-author, queued and contributor lanes read every open same-repo issue the PR body closes once the head is otherwise ready to merge, and refuse with `linked-issue:hold:#N:<label>` (hold labels, `hive-pause/<id>`, `do-not-merge*`) or `linked-issue:needs-decision:#N:<label>` (`stage/045-needs-decision`, `needs-human`, retired decision labels). The PR stages `085-needs-decision` with an entry comment naming the issue and the label to remove; removing it lets the next sweep merge. A failed issue read withholds the merge for that tick (`linked-issue-check`). Prompted by projectbluefin/utah#874, which merged while the maintainer was still waiting on #551; a `hold` on #551 would now have stopped it.
