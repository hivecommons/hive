- The serialized merge lane no longer stops merging when CI is backlogged ([#12952](https://github.com/hivecommons/hive/issues/12952)). Its front timeout was fixed at 60 minutes and a front whose required checks were only queued was rotated out, so the next pull request needed a new branch update and CI run; with a queue longer than an hour no pull request ever merged. The timeout is now configurable hive-wide (`project.merge_front_timeout`) and per repository (`project.repo_policies[].merge_front_timeout`), and a front whose required checks are all still queued or in progress gets its deadline extended, up to 4x the timeout, with a `front-extend` lane decision recorded for each extension.
