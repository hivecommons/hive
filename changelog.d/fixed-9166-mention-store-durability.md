- GitHub mention triggers (v6): the mention store (`/data/github-mention-triggers.json`) is now written atomically, so a pod killed mid-save no longer leaves a torn file. A store that still fails to parse is moved aside to `*.corrupt-<unix-nanos>` and replaced with an empty one, logged at Error, instead of silently disabling mentions, the poller, the webhook and the responder at boot. The seen-key set now ages entries out after 45 days instead of growing forever, and existing stores migrate on first load. Actions OIDC dispatch (`POST /api/contribute/actions/dispatch`) now refuses with 503 when the store is not loaded, instead of deduping `run_id`/`run_attempt` against a throwaway in-memory store that accepted every retry ([#9166](https://github.com/hivecommons/hive/issues/9166)).
