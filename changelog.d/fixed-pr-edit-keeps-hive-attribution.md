- An agent's `gh pr edit --body` (or `--body-file`, or `-F -`) on a PR the hive opened no longer deletes the PR's `— hive: agent=… backend=… model=…` line. The PR-request watcher appends that line when it opens the PR, but gh replaces the whole body, so an agent that rewrote its description seconds later removed it (Danathar/arch-bootc#625, removed 28s after creation; Danathar/atomic-image-builder#795, where the only other change was "18 failures" → "16 failures"). Nothing put it back. The repos' monthly Agent audit trail then failed on those PRs as "opened by the Hive app with no `— hive:` signature line" (atomic-image-builder#834, arch-bootc#627). The `gh` wrapper now re-appends the PR's current line when the new body has none of its own, on the hive's own PRs only. PRs whose line is already gone are not repaired.
