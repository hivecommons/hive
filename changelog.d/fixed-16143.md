- The `min_head_age` merge gate no longer stalls green merges for an hour when GitHub's server-generated timestamps (`created_at`/`updated_at`/`pushed_at`) run ahead of the host clock: a head time in the future is now treated as clock skew, so the age hold is skipped instead of clamping to "head pushed 0s ago". Heads whose age is zero or positive but below `min_head_age` still wait as before ([#16143](https://github.com/hivecommons/hive/issues/16143)).
