- Claude credential bridge: on a per-UID hive the hive server cannot read the private `0600` file an agent's token refresh leaves in place of its credential link, and the repair took that read error for "no token". It kept the shared file, whose grant the refresh had just rotated, and moved the agent's fresh token aside, so every Claude agent logged out when the shared access token expired. The container entrypoint's root permission guard now runs the same repair every 5 seconds: it judges both files without printing any token, promotes the private copy only when it is complete (access token, refresh token, `expiresAt`), usable and newer, writes it as the shared file's owner and group with the shared file's mode (world bits removed), and restores the link. The hive server's own repair no longer moves aside or relinks a private file it cannot read; it logs one ERROR per agent and file version instead. A failed refresh's empty-token, `expiresAt` 0 file never replaces the shared login, and `claude.WriteCredentials` refuses a credential with no access token (#17253, #17590).
