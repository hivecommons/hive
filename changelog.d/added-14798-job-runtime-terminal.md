- The dashboard's **▶ terminal** now works for agents with `sandbox.runtime: job` ([#14798](https://github.com/hivecommons/hive/issues/14798)). Those kicks run as a Kubernetes Job in another pod, so there was no tmux session to attach and the pane waited forever. For a job-runtime agent the link now opens a read-only viewer at `/terminal/job/<agent>` that streams the newest Job pod's log through the launcher's existing in-cluster client and `pods/log` RBAC: it follows the pod while the kick runs (waiting while it is `Pending`), prints the container exit code when it ends, and between kicks shows the last run's persisted sandbox transcript — which now ends with an `exit code: N` line — or a clear "no sandbox run yet" state. Podman-sandboxed and tmux agents are unchanged.
