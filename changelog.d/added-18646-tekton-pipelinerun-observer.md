- Workflow models can now observe Tekton PipelineRuns as post-merge runs ([#18646](https://github.com/hivecommons/hive/issues/18646)). A Tekton pipeline's new `tektonRuns` block names the cluster (`context` or `inCluster`), `namespace` and `labelSelector` explicitly (nothing is auto-discovered); each run's revision is read from the `pipelinesascode.tekton.dev/sha` annotation, then the `revision` param (both renameable), and fed through range attribution. A run whose revision is not a full commit SHA leaves the column `unknown` with the reason recorded instead of guessing. Existing models are unchanged.
