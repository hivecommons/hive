- The `crux` module README (published as `docs/MODULE.md` in hivecommons/crux) now shows `crux logs -n 50 scout` instead of `crux logs scout -n 50`; `crux logs` parses flags with a standard `flag.FlagSet`, which stops at the first positional argument, so the documented order exited with the usage error instead of printing output ([hivecommons/crux#72](https://github.com/hivecommons/crux/issues/72)).
