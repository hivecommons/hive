- The advisory issue lookup reads the ForgeState cache when a store is bound (`forgestate.enabled`): a memoized advisory issue costs zero GitHub calls on a healthy cycle, a cache miss one targeted GET, and the search/list path runs only when the cache cannot answer. The review-request watcher is event-driven: request-dir notifications and `issue_comment`/`pull_request_review`/`pull_request_review_comment`/`issues` label deliveries wake it, the unprompted scan is a 5-minute reconcile while webhooks are healthy, and the 10 s poll returns only when webhooks are degraded. A `--revise` request for a repo outside `review.revise_repos` is denied once instead of retried every tick (#13252).
