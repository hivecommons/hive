- Fork PRs that allow edits by maintainers no longer read as forks the hive cannot push to. The GraphQL PR batch (`graphql_pr_batch`, on by default) stored each PR's detail without `maintainerCanModify`, and the scan reused that detail in place of a REST read, so every fork PR came out "not editable". The hold guard then stopped keeping held fork PRs current without asking GitHub, and posted "a fork the Hive app cannot push to" on projectbluefin/gutenprint-printer-app#196 and projectbluefin/hplip-printer-app#199, whose forks both allow maintainer edits. The repair queue's push-or-comment-only choice and the dashboard's adopted-PR push check read the same field. The batch query now asks for `maintainerCanModify` and carries it into the stored detail.
