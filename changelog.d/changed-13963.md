- Crux module API: the `crux/types` leaf package is folded into the `crux` root package, so the runtime's value types (process states, kick dispatch and outcomes, restart events, start-failure classes, turn loss, provider status, audit vocabulary, `ConditionReporter`, `PRResult`, `CanaryLeak`, `ProofProvenance`) are defined as `crux.<Name>`; `watchdog.Condition`, `ConditionType` and `ConditionStatus` and their constants are now defined in `crux` and aliased by `crux/watchdog`, so the root no longer imports `crux/watchdog` ([#13963](https://github.com/hivecommons/hive/issues/13963), [#13536](https://github.com/hivecommons/hive/issues/13536)).
