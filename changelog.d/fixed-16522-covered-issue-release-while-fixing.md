- The claim-release valve no longer drops a covered issue to `stage/010-actionable` while the hive is still repairing its red covering PR ([#16522](https://github.com/hivecommons/hive/issues/16522)). A red+stale PR releases its issue only once the fix loop has given up on that head: escalated to a human, re-engagement budget spent, or red for the whole re-engagement window (`escalation.ClaimReleaseAfter`) with no owner reachable. Until then the issue stays `stage/040-covered-by-pr` narrating the PR's `070-fixing`, and the scanner is not offered work a live PR already owns.
