- A hub that provisions no hive can now say so with `HIVE_HUB_MODE=self-hosted` ([#20189](https://github.com/hivecommons/hive/issues/20189)). Without a `clusters.json` such a hub no longer gets an invented `OKE (default)` cluster with NFS, nginx, arm64 and `v4-latest` settings; it gets a neutral in-cluster entry named `Hub cluster` instead. Its dashboard hides the hosted-fleet controls: `+ Add Hosted Hive`, `Request a hive`, Cluster Health, Scale Controls (including the Customers profile sharing and Ask AI off-state panels inside it), the hosted-hive Quota column in the Users table, the NPS feedback card, and the per-cluster split in the Usage panel. `Register your own hive` remains as the only path. Hubs that leave the variable unset behave exactly as before.
