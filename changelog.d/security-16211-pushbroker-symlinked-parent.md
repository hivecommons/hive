- The push broker's trailing-newline normaliser now resolves each changed file's parent directory and skips any path that escapes the workspace through a symlinked directory, as it already did for a committed symlink at the leaf. Since the normaliser began committing HEAD's blob rather than the working-tree bytes, an agent that committed `dir/file` and then swapped `dir/` for a symlink out of the sandbox workspace could have had that blob written briefly into a hive-owned file by the host-side broker before the restore put it back ([#16211](https://github.com/hivecommons/hive/issues/16211)).
