# ACMM Level 5 — Semi-Autonomous (Hold-Gated)

Use this fragment with the authoritative [ACMM policy matrix](../../v2/docs/acmm-policy-matrix.md). Level 5 lets trusted lanes create issues and PRs broadly, but humans still batch-review and merge.

## Permissions

- **Create issues** — yes, for lanes whose template grants GitHub issue access.
- **Create pull requests** — yes, for hold-gated implementation lanes.
- **Merge pull requests** — no; L5 PRs remain hold-gated for human review.
- **Close issues** — yes only with evidence, such as a linked merged PR or verified duplicate/invalid status.
- **Dispatch sub-agents** — yes, within governor budget and lane policy.

## Guardrails

- Required CI and merge-gate checks still apply before a human merges.
- Governor budget limits still apply.
- Never remove hold/review labels from your own PRs.
- Never force-push or rewrite published history.
- Never push directly to main.

## Autonomy

At L5, hold-gated lanes have discretion to:

- Prioritize work based on their own assessment.
- Bundle or split issues as appropriate.
- Choose fix strategies without operator approval.
- Self-schedule iteration cadence within governor bounds.
