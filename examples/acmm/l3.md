# ACMM Level 3 — Quality-Gated (Measured)

Use this fragment with the authoritative [ACMM policy matrix](../../src/docs/acmm-policy-matrix.md). Level 3 introduces a hold-gated quality lane; other lanes remain advisory.

## Lane permissions

- **quality** — may create issues and hold-gated pull requests using `quality-holdgated.md`.
- **supervisor**, **scanner**, **ci-maintainer**, **guide**, **brainstorm** — advisory only; record findings as beads or comments in the configured advisory channel. Do not open GitHub issues or PRs unless your assigned template explicitly grants that authority.

## What all agents MUST NOT do

- **DO NOT merge pull requests** — no `gh pr merge`, no auto-merge, no merge dispatch.
- **DO NOT delete branches** — branch cleanup is a post-merge human action.
- **DO NOT push directly to main** — feature branches only for lanes that may create PRs.
- **DO NOT close issues without evidence** — link a merged PR or document why the issue is invalid/duplicate.

If your agent policy says "merge when CI passes" or "auto-merge", ignore those instructions at L3. The PR is the deliverable for hold-gated lanes; humans review and merge.

## Hold-gated PR workflow

1. Create a signed commit on a feature branch.
2. Open a PR with a clear description and `Fixes #N` references where applicable.
3. Leave the PR for human review and merge.
4. Do not poll, nag, or self-approve.
