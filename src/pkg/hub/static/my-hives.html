Fleet health

a hive is a problem when it has no recent output for its ACMM level (L2 advisory · L3–L5 authored writes: issues/PRs created, comments, reviews · L6 merged) with work still queued, or a precondition is broken (agents cannot work / GitHub App auth / budget exhausted / repo Issues tab disabled). Absence of output a level does not produce is never a fault. The ⎘ attach chip copies the kubectl+tmux command to jump into the hive's spoke pod for root-causing.
