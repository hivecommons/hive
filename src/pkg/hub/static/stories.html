Raúl Méndez on Hive | Bluefin

first-time contributor

@mendezr Hive | Bluefin first-time contributor PR #10201 2026-10-05

I started as a Bluefin user and wanted to contribute back, but I had little experience contributing to open source. Hive made it much easier to get started with real issues while using coding agents to help me along the way.

Since then, I've contributed to both Bluefin and Hive and learned a lot about CI, containers, automation, and Linux. The agents help me move faster, but I still try to understand and review what I'm contributing.
