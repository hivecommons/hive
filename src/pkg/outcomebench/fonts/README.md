# IBM Plex Mono

Regular and Bold faces from the IBM Plex project, distributed under the SIL
Open Font License 1.1 in [OFL.txt](OFL.txt). The copyright and reserved font
names are recorded in that license. The generator embeds these unmodified
files; it never loads fonts from the network or the host.

Source mirror: https://github.com/google/fonts/tree/main/ofl/ibmplexmono

The SVG source includes each font's SHA-256; changing a font invalidates the
PNG source hash and requires rerendering the cards.
