# Strategy Lab (renamed)

The Strategy Lab was renamed to the **Experiment Lab** (RFC #11585 part 2,
#11695). This page is kept as a redirect stub so existing links keep working.

→ **[Experiment Lab (Nous) operator guide](experiment-lab.md)**

The config key moved from `dashboard.strategy_lab` to `dashboard.experiment_lab`;
the old key is accepted as a deprecated alias for one release. The
`/api/nous/*` endpoints and `NousState` are unchanged.
