# Every non-test .go file that was over the 800-line limit when the ratchet

# its number; an unlisted file may not exceed 800 lines.

# adding a new file here, defeats the gate: split the file instead.

# The Go code is synced from hivecommons/hive src/crux; splits land there and
# reach this tree through the sync.
#
# A PR that (re)generates this file must be rebased on main right before it
# merges: PR checks run against the merge ref at push time, not at merge time,
# so syncs that land in between can push files past a baseline captured
# earlier and turn main red (crux#22 did exactly that).
