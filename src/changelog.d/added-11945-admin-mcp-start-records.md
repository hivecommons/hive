- Admin MCP can now tell whether the hive crashed, was killed or ran out of memory, without host access ([#11945](https://github.com/hivecommons/hive/issues/11945)). Each start is recorded with how the previous run ended (`clean`, `not-closed`, `self-upgrade-failed` or `unknown`), its last-seen-alive time and its last memory reading, and can be read through the new `starts` log source. Every hive log line carries the short start identifier. The Go runtime's fatal-error trace is kept per start as the `crash` source (last 10, at most 1 MiB each; SIGKILL and out-of-memory kills leave none). `fleet_status` reports the container's memory limit (`memLimit`, `unlimited` when none) and out-of-memory kill count (`oomKillCount`). The admin MCP docs now list the evidence that still needs a host shell, with its in-container substitute.
