Every kick now opens with a **house style** section — how changes are to be made — identical across agents and backends. A managed repo's root `HIVE_STYLE.md` overrides the hive-wide `project.style` / `project.style_file`, which overrides the built-in text (smallest complete diff, follow existing patterns, tests for behaviour changes, DCO). Candidates are capped at `project.style_max_bytes` (4096) and skipped whole when oversize; the repo file is untrusted and is refused whole on an ioscan block, with a `house_style_skip` audit line. The agent card and detail pane show a **style** field naming the source; `/api/status` exposes `agents[].styleSource`. See docs/house-style.md.
