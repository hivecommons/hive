- Spek continuous-convergence recheck is enabled again on v6 and now rewinds the campaign's existing run in place: `POST /api/campaigns/{id}/recheck` and the cadence tick keep the same campaign ID and run key, bump `revision`, reset the stage to `spec` on the run's own lease key, and append the closed generation to the campaign's `history` log, instead of minting a sibling revision and a second `spek-recheck-*` lease. A second recheck while one is in flight returns `409` ([#10800](https://github.com/hivecommons/hive/issues/10800), ADR 0020 v6 addendum).
