- Editing `hive.yaml` on a busy hive now takes effect: a config hot-reload no longer waits behind a whole governor cycle, it is applied before that cycle ends, and that cycle's state persist (which also saves `hive.yaml`) no longer writes the config it started from over the edit. If any other save (hub heartbeat, dashboard, agent pause) wrote the pre-reload config to `hive.yaml` while the reload was waiting, the reloaded config is saved back once it is applied ([#17467](https://github.com/hivecommons/hive/issues/17467)).
