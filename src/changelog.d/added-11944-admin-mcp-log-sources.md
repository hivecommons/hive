- Admin MCP `log_read` / `log_sources` can now read four more sources ([#11944](https://github.com/hivecommons/hive/issues/11944)): `proxy` (everything the dashboard auth proxy prints), `hive-output` (what the hive prints before its own log is set up), `litellm` (the local litellm proxy's output, discarded before) and `requests` (a dashboard request log with method, path without query values, status, duration and auth outcome `public`/`ok`/`failed`/`none`). Each keeps at most 5 files of 10 MiB and 7 days under `HIVE_OUTPUT_LOG_DIR` (default `/data/.hive/logs`); proxy and early hive output still reach the container's output unchanged, and a source whose process does not run is reported not available with a reason.
