# Adopters

Listed below are organizations that have adopted, or benefitted from, KubeStellar Hive in one way or another. We are delighted to welcome them to the KubeStellar community. If you are using KubeStellar Hive in your organization we would love to add you to the list below. You can open a pull request against this file directly.

## How to Add Yourself

1. Fork this repository
2. Add your organization to the table below using the schema: `| Organization | Description | Maturity Level | Further Information |`
3. Open a pull request with the title: `📖 docs: add <Organization> to ADOPTERS.md`

> ⚠️ **Maintainer note**: When opening PRs that restructure this file, always preserve existing adopter entries. Do not replace the file with a blank template.
